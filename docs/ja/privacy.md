## **2. 個人情報の取得および利用**

当社は、適法・公正・必要最小限の原則に従い、機能提供、運用上の安全確保、体験向上等の目的で情報を取得・利用します。ログインの有無や利用機能により、取得する情報の種類は異なります。

### **2.1 お客様からご提供いただく情報**

1. アカウント・本人確認情報（該当する場合）

● 第三者アカウント（例：Appleでサインイン）でログインする場合、ログインおよびアカウント管理のために、当該第三者から必要な識別情報を受領することがあります。

2. 利用中に入力／インポートされるデータ

● 本アプリに記録した明細、カテゴリ、タグ、メモ、インポートしたファイル内容などが含まれます。これらのデータは、通常お客様の端末に保存されますが、同期機能を有効にした場合（該当する場合）には、サーバー側にアップロード・保存されることがあります。

### **2.2 自動的に取得される情報**

本アプリの正常な動作の確保、統計分析、安定性・安全性の向上のため、当社は以下の情報を自動的に取得する場合があります（関連 SDK は、お客様の同意取得後にのみ正式に初期化され、送信を開始します）。

● 端末情報：端末モデル、端末名、OS バージョン、アプリバージョン、言語設定など

● 端末識別子：Android ID、IMEI（OS から取得可能な場合）、IDFA（お客様が許可した場合）、OPENUDID、GUID、IP アドレス、MAC アドレス（OS の制限による）など。統計分析、不正対策、障害解析、セキュリティ確保のために利用します。

● ネットワーク情報：ネットワーク種別、通信事業者情報（OS から取得可能な場合）、通信失敗情報など。接続品質の最適化や安定性分析のために利用します。

● ログ情報：起動情報、クラッシュ／例外スタック、パフォーマンスデータ、画面遷移（閲覧）経路など。問題の特定と性能改善のために利用します。

### **2.3 権限と機能の対応（概要）**

本アプリは特定の機能を提供する際、端末権限を要求または利用することがあります。権限名称や表示は OS バージョンにより異なる場合があります。実際の表示は OS の案内をご確認ください。

● ネットワーク：オンライン通信、同期、統計分析など

● 写真／ファイルへのアクセス（インポート／エクスポート、ファイル選択、共有、画像保存など）：ファイルの選択・保存のため

● 購入／サブスクリプション（アプリ内課金を利用する場合）：支払い、購読状況の確認など

当社は、お客様が選択した機能と無関係な場面で、必要性を超える権限を求めることはありません。

## **3. 第三者 SDK と情報共有**

統計分析やアプリのパフォーマンス監視等のため、本アプリは第三者 SDK を組み込んでいます。第三者 SDK は関連情報を取得する場合があります。当社は、お客様の同意取得後にのみ、当該 SDK の正式な初期化 API を呼び出し、収集・送信を開始させます。同意いただけない場合、正式な初期化は行いません。

### **3.1 友盟+ SDK（利用状況分析／アプリパフォーマンス監視）**

当社は、利用状況分析およびアプリパフォーマンス監視のために「友盟+ SDK」を利用しています。友盟+ SDK は、統計分析サービスの提供、位置情報に基づくレポート精度の補正、基本的な不正対策のため、以下の情報を取得する場合があります。

● 端末情報および端末識別子：MAC アドレス、端末固有 ID（IMEI / Android ID / IDFA / OPENUDID / GUID など）

● ネットワーク情報：IP アドレス

● SIM 関連情報：IMSI（OS から取得可能な場合）

友盟+ SDK の正式な初期化は、お客様が本ポリシーに同意した後に実行されます。同意いただけない場合、当社は友盟+ SDK の正式な初期化 API を呼び出しません。

## **4. 情報の保存と安全管理**

1. 保存場所と保存期間

● 当社は、本サービスの目的達成に必要な期間に限り個人情報を保持します。法令に別段の定めがある場合を除きます。

● 記帳データは主に端末内のローカルデータベースに保存されます。クラウド同期を有効にした場合（該当する場合）、関連データがサーバーにアップロードされ保存されることがあります。

2. 安全管理措置

● 当社は、情報漏えい、滅失、毀損を防止するため、合理的かつ適切な技術的・組織的対策を講じます。

● ただし、インターネット環境は完全に安全ではありません。不可抗力または当社の責に帰さない事由によるセキュリティ事故が発生した場合、当社は法令に従い適切に対応します。
