# よくある質問（FAQ）

このページでは、Koala の利用中によくある質問と対処方法をまとめています。トラブル時はまずこちらをご確認ください。

---

## 明細インポート

### Q：どの明細ソースに対応していますか？対応ファイル形式は？

**A：** 現在、5 つのソースに対応しています。

- **テンプレート**：CSV（`.csv`）
- **WeChat**：CSV / Excel（`.csv` / `.xlsx` / `.xls`）
- **Alipay**：CSV（`.csv`）
- **Pixiu**：CSV（`.csv`）
- **iCost**：Excel（`.xlsx` / `.xls`）— iCost の CSV は非対応

関連ガイド：

- [テンプレート明細インポート（CSV）](../guide/01-template-bill-import-guide)
- [WeChat 明細インポート](../guide/02-wechat-bill-import-guide)
- [Alipay 明細インポート](../guide/03-alipay-bill-import-guide)
- [Pixiu 明細インポート](../guide/07-pixiu-bill-import-guide)
- [iCost 明細インポート](../guide/08-icost-bill-import-guide)

### Q：「解析に失敗しました／開けません／ヘッダーが見つかりません」と出ます

**A：** 多くは次のいずれかです（よくある順）。

1. **インポート元の選択が違う**：例えば WeChat のファイルをテンプレート/Alipay として解析すると失敗したり項目がずれたりします。
2. **ファイルを編集してしまった**：Excel/WPS で開いて表頭を変更、列の削除/追加、区切り文字変更などをすると解析に失敗しやすくなります。
3. **対応していない形式**：例えば iCost を CSV で出力した、Alipay の非標準形式を使った、など。
4. **ファイルが破損している**：ダウンロード途中で切れた、添付が壊れている、共有時に欠けた、など。
5. **ファイルが大きすぎる**：処理が遅くなったり失敗することがあります。期間を分けて書き出し、分割して取り込むのがおすすめです。

おすすめ：元アプリから「未編集の状態」で再エクスポートし、Koala 側のインポート元を正しく選択してから再度解析してください。

### Q：取り込み後の金額が 0 になった／金額が合いません

**A：** よくある原因は以下です。

- **収入/支出の判定が崩れている**：ソースによっては「收入/支出」のキーワードで参照する金額列が決まります（例：Pixiu の流入/流出）。種別列が想定外だと読み取りがずれることがあります。
- **金額欄が空／不正文字が混ざっている**：余計なスペースや見えない文字が原因になる場合があります。
- **千区切り／符号**：`+/-` や千区切りが含まれていても通常は対応しますが、編集・再保存で形式が崩れると失敗することがあります。

対処：プレビュー画面で **収支種別** と **金額** を優先して確認してください。おかしい場合は元ファイルを再エクスポートするのが確実です。

### Q：カテゴリ／口座／タグが期待通りに一致しません

**A：** できるだけ自動一致を試みますが、アプリごとに分類体系が違うため、完全一致は保証できません。

- **カテゴリ**：プレビューで 1 件ずつ修正できます。より一致しやすくするには、Koala 側にエクスポートと同名のカテゴリを事前に作成してから再解析してください。
- **口座**：口座名や支払方法で照合します。見つからない場合は新規口座が作成されることがあります。よく使う口座を先に作っておき、プレビューでまとめて修正するのがおすすめです。
- **タグ**：タグ名で照合します。存在しないタグは作成されることがあります。不要なタグ名（余計な空白や記号）になっていないか確認してください。

### Q：重複（同じ明細の二重取り込み）を自動で防げますか？

**A：** ソースによって挙動は異なりますが、基本は **自動で完全な重複排除はしない** 前提でご利用ください。

- おすすめ：同じファイル/同じ期間を繰り返し取り込まない。分割する場合は期間が重ならないようにする。
- すでに重複した場合：明細一覧で期間を絞り込み、手動で削除してください。

### Q：返金／振替／红包などの特殊な取引はどう扱われますか？

**A：** プラットフォームごとの書き出し項目が大きく異なるため、取り込み後は次をおすすめします。

- プレビューで **収支種別** と **金額の正負** を確認
- 必要ならカテゴリを手動調整（例：返金を「返金/その他収入」へ）
- 取引状態や注文番号などはメモに追記されることが多く、後から参照しやすくなります

### Q：一度にどのくらい取り込むのが良いですか？遅いです

**A：** 期間で分割するのがおすすめです。

- WeChat/Alipay は **3 か月以内**で書き出すと安定しやすく、解析も速くなります
- 大量データは複数ファイルに分けて順番に取り込み
- 取り込み中はアプリを前面にしておくと中断しにくくなります

## 複数帳本（マルチ Ledger）

### Q：帳本を切り替えたらデータが「消えた」ように見えます

**A：** 別の帳本に切り替わっている可能性が高いです。明細・カテゴリ・タグ・統計は帳本ごとに分かれています。

対処：**帳本管理**で現在の帳本を確認してから、明細一覧をご確認ください。

### Q：帳本ごとに分かれるもの／共通のものは？

**A：**

- **帳本ごと**：明細、カテゴリ、タグ、統計
- **端末で共通**：口座（複数帳本で同じ口座を利用できます）

### Q：帳本を削除するとどうなりますか？復元できますか？

**A：** 削除すると、その帳本は端末から削除されます。クラウド同期を利用している場合は、同期後にクラウド側にも削除が反映されます。アプリ内で復元できないため、削除前に必ずご確認ください。

## 通貨と為替レート

### Q：基軸通貨（帳本通貨）とは？何に影響しますか？

**A：** 基軸通貨（帳本通貨）は、現在の帳本で「主に表示する通貨」です。主に次に影響します。

- 金額表示（換算表示）
- 概覧/統計の計算
- 為替一覧（基軸通貨に対するレート表示）

### Q：レート更新後に過去の明細の換算表示が変わりました

**A：** 換算表示は **現在の為替レート** を使います。レート更新や基軸通貨の変更後、過去明細の「換算表示」は変わることがありますが、**元の取引金額**は変わりません。

### Q：オフライン時はどうなりますか？更新に失敗します

**A：** オフライン時は、保存済みのレートをできるだけ利用します。更新に失敗する場合は：

1. ネットワークを確認
2. 少し時間を置いて再更新
3. 手動でレートを変更している場合は、その値が意図通りか確認

## クラウドバックアップと同期

### Q：クラウドバックアップにログインは必要ですか？

**A：** 必要です。現在は **Apple でのログイン**に対応しています。設定画面上部のユーザーカードからログインできます。

### Q：同期されるもの／されないものは？

**A：**

- **同期される**：帳本、明細、口座、カテゴリ、タグ
- **同期されない**：アプリ設定（テーマ/言語など）、キャッシュ、個人設定

### Q：自動同期のタイミングは？手動同期は？

**A：**

- **自動**：アプリ起動時、データ変更後、帳本切り替え時など
- **手動**：設定画面右上の雲アイコンをタップ

手動同期中は、完了までアプリを前面にしておいてください。

### Q：複数端末で同じデータを編集した場合は？

**A：** Koala はできるだけ最新の変更を優先しつつ、まだ同期されていない端末側の変更が上書きされないようにします。複数端末で使う場合は、片方の端末で同期を完了してからもう一方で編集するのがおすすめです。

### Q：再インストール／機種変更後に復元できますか？

**A：**

- **ログイン済みで同期済み**：再インストール後に同じアカウントでログインし、同期が終わるのを待てば復元できます
- **未ログイン**：データは端末内のみのため、アンインストールすると復元できません

## フィードバックとサポート

### Q：問い合わせ時に何を伝えると早く解決できますか？

**A：** 次の情報があると切り分けが早くなります。

- インポート元（WeChat/Alipay/Pixiu/iCost/テンプレート）
- ファイル形式（CSV/Excel）と書き出し期間
- エラー表示のスクリーンショット（あれば）
- 試したこと（再エクスポート、ソース変更、別ファイルで試した等）
