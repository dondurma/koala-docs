# 背面タップガイド

## 1. 「設定」を開き、「アクセシビリティ」を選択

![1|400](./images/1-ja.png)

## 2. 「アクセシビリティ」画面で「タッチ」を見つけてタップ

![2|400](./images/2-ja.png)

## 3. 「タッチ」画面で「背面タップ」を見つけてタップし、「ダブルタップ」または「トリプルタップ」を選択

![3|400](./images/3-ja.png)

## 4. 「ダブルタップ」または「トリプルタップ」画面で、下部にあるショートカットから「考拉快捷记账」を見つけて選択

![4|400](./images/4-ja.png)
