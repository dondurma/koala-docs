# WeChat 明細インポート

## 📋 概要

WeChat から明細をエクスポートし、Koala に取り込む手順です。

## 📤 WeChat 側：エクスポート（簡易）

WeChat → **我** → **服务/支付** → **钱包** → **账单** → **下载账单** → 期間を選択 → ファイルを保存。

> 💡 目安：1 回のエクスポートは 3 か月以内にするとファイルが扱いやすくなります。

## 📥 Koala 側：インポート

1. Koala → **設定** → **明細インポート**
2. **インポート元** を **WeChat** に設定
3. ファイルを選択（`.csv` / `.xlsx` / `.xls`）
4. 帳本を選択 → **解析** → プレビュー → **インポート**

⚠️ エクスポートしたファイルのヘッダーや列を手動で編集すると、解析に失敗する場合があります。
