# 定期記帳

## 1. この機能について

「定期記帳」は、家賃・光熱費・サブスク・給与など、定期的に発生する収支をルールとして登録し、ルールに従って明細を自動生成する機能です。毎回の手入力を減らせます。

## 2. こんなときに便利

- 毎月の家賃、住宅ローン、クレジットカード返済
- 毎週の通勤交通費、固定の手当
- 毎月のサブスクリプション（動画サービス、クラウドストレージ等）
- 毎月の固定収入（給与、補助金等）

## 3. 使い方

1. 「設定」から「定期記帳」を開く
2. 新しいルールを作成し、次を入力する：
   - 種別：支出 / 収入
   - カテゴリ（収支項目）
   - 金額
   - 口座
   - タグ、メモ（任意）
   - 実行周期：毎日 / 毎週 / 毎月（ルールに応じて日付や曜日を選択）
   - 開始/終了：開始日は必須。終了日は任意（期限到来で自動停止）
3. 保存すると、ルールが定期記帳の一覧に表示される
4. 実行タイミングになると、ルールに従って明細が生成される

## 4. ルールと注意点

- 定期記帳で生成された明細は通常の手入力明細と同じ扱いで、一覧表示され、集計にも含まれます。
- 長期間アプリを開かない場合、端末によっては「完全に指定時刻どおり」に生成できないことがあります。その場合でも、次回アプリ起動時に未生成分を補完して作成します（記録漏れ防止）。
- 家賃改定や口座変更などがあった場合に備え、ルールは定期的に見直してください。
- ルールを一時停止/終了すると以後は生成されません。再開すると次の周期から実行されます。

## 5. よくある質問

### Q1：定期記帳で生成された明細が間違っていたら？

通常の明細と同様に編集/削除できます。頻繁に起きる場合は、ルール側（金額/周期/口座など）を調整してください。

### Q2：ルールを変更すると、過去に生成された明細も自動で変わりますか？

変わりません。変更は今後生成される明細にのみ反映され、過去の明細は追跡のためにそのまま残ります。

### Q3：同じ日に複数の明細が生成されますか？

複数のルールを設定している場合、それぞれのルール分が生成されます。同一ルールについては、重複生成をできるだけ避けるようにしています。
