# Pixiu 明細インポート

## 📋 概要

本ガイドでは、**Pixiu** から書き出した明細（CSV）を **コアラ家計簿** にインポートする手順を説明します。

コアラ家計簿は現在、**Pixiu の CSV エクスポート**（CSV のみ）に対応しています。

## 📱 手順 1：Pixiu で明細をエクスポート

Pixiu はバージョンによってメニュー名が多少異なりますが、流れは共通です。「データ書き出し/明細書き出し」から期間を選び、CSV で保存します。

### 手順 1：エクスポート画面を開く

1. Pixiu を開く
2. **「我的」** を開く
3. **「数据导出」/「导出账单」**（表記は異なる場合あり）を探す

### 手順 2：期間を選択

1. 期間（例：直近 1 か月 / 直近 3 か月など）を選ぶ
2. 確定してエクスポートを開始

> 💡 ヒント：
> - 1 回のエクスポートは 3 か月以内をおすすめします（ファイルが大きいと解析が遅くなることがあります）。
> - データ量が多い場合は複数回に分けてエクスポートし、分割してインポートしてください。

### 手順 3：CSV で保存

1. 形式は **CSV** を選択
2. 端末内に保存（共有 → ファイルに保存 など）
3. 保存先を覚えておく

## 📱 手順 2：コアラ家計簿にインポート

### 手順 1：インポート画面を開く

1. コアラ家計簿を開く
2. **「設定」** → **「明細インポート」**

### 手順 2：インポート元を選択

1. **「インポート元」** をタップ
2. **「Pixiu」** を選択

> ⚠️ 重要：必ず Pixiu を選択してください。選択を間違えると検証に失敗したり、列の読み取りがずれることがあります。

### 手順 3：ファイルを選択

1. **「ファイルパス」** をタップ
2. Pixiu から書き出した **CSV** を選択
3. ファイル名が表示されることを確認

### 手順 4：帳簿を関連付け

1. **「関連帳簿」** をタップ
2. 取り込み先の帳簿を選択

### 手順 5：解析 → プレビュー

1. 右上の **「解析」** をタップ
2. 成功するとプレビュー画面へ移動
3. プレビューでは 1 件ずつ編集できます。長押しで複数選択モードに入ってまとめて削除でき、「インポート」時に「有効なデータのみ取り込む」を選択することもできます

### 手順 6：インポート実行

1. 内容を確認したら **「インポート」** をタップ
2. 完了まで待つ

## 📋 Pixiu CSV の形式（参考）

コアラ家計簿の Pixiu 明細 CSV の認識方式：

- ヘッダー行はファイルの先頭から数行以内に含まれている必要があり、システムは**ヘッダー名**で列を自動認識します（列の順番に依存しません）
- 区切り文字は半角カンマ `,`（標準 CSV）
- 下表は Pixiu の書き出しでよく見られるフィールドとその意味です。ヘッダー名が対応していれば、順番が変わっても認識できます

### フィールド定義

| フィールド | 説明 |
|------|------|
| 日付 | `yyyy-MM-dd` / `yyyy/MM/dd` に対応。年は 2016 以上が必要（それ以外は無効な日付として扱われます） |
| 親カテゴリ（収支大分類） | コアラ家計簿の親カテゴリ名との照合に使用 |
| 取引分類 | テキストに「支出」または「收入」のキーワードが必要。「收入」を含む場合は収入として取り込み、それ以外は支出として取り込みます |
| 子カテゴリ | コアラ家計簿の子カテゴリ名との照合に使用 |
| 入金額 | 収入金額の列（`-` が付いていても可。取り込み時に符号は自動で除去されます） |
| 出金額 | 支出金額の列（`-` が付いていても可。取り込み時に符号は自動で除去されます） |
| 通貨コード | 例：`CNY` / `USD`。空の場合は取り込み先帳簿の既定通貨を使用 |
| 口座 | 口座名（コアラ家計簿の口座との照合に使用。存在しない場合は取り込み時に作成を試みます） |
| タグ | 複数タグはカンマ区切り（中国語カンマ `，` も対応） |
| 備考 | 備考テキスト |

### コアラ家計簿への取り込み（概要）

- 日付 → 日付
- 取引分類（支出/収入のキーワードを含む）→ 収入/支出
- 親 + 子カテゴリ → カテゴリ（未一致の場合は「不完全」としてプレビューで修正が必要）
- 入金/出金 → 金額（収入/支出で参照列が決まります）
- 口座 → 口座
- タグ → タグ（名称で照合/作成して紐付け）
- メモ → メモ
- 通貨コード → 通貨（一致しない場合は帳簿通貨にフォールバック）

## ⚠️ 注意事項

1. **自動重複排除なし**：同じファイルを二重に取り込むと重複明細が作成されます。取り込み範囲の重複に注意してください。
2. **カテゴリ一致**：親 + 子の名称で一致させます。未一致の場合はプレビューで修正してから取り込んでください。
3. **口座の有効性**：口座名が空、または記号のみの場合は無効として扱われ、補完が必要になることがあります。
4. **文字化け**：CSV は UTF-8/GBK に対応しています。文字化けする場合は UTF-8 で再書き出し、または文字コード変換してから取り込んでください。

## 🔧 よくある質問

### Q1：「ヘッダーが見つからない」と表示される、または列を認識できない

システムはヘッダー名で列を認識します。よくある原因：

1. Pixiu から書き出した CSV ではない、またはヘッダー名が変更されている
2. Excel/WPS で二次編集してヘッダーを変更したり、列を削除・追加した
3. 互換性のない形式で保存した（例：セミコロン区切り）
4. ヘッダー名が「日付/取引分類/金額」などのフィールドに対応していない

### Q2：金額が 0 になる／おかしい

確認：

1. 「取引分類」列に「支出/收入」のキーワードが含まれているか（入金/出金のどちらを読むかが決まります）
2. 対応する金額列が数値になっているか（`-` があっても可）

### Q3：カテゴリが一致しません

プレビューで 1 件ずつ正しいカテゴリを選択してください。もしくはコアラ家計簿側に Pixiu と同名のカテゴリを事前に作成してから再解析してください。
