# Pixiu 明細インポート

## 📋 概要

Koala は Pixiu のエクスポート明細（CSV）のインポートに対応しています（CSV のみ）。

## 📤 Pixiu 側：エクスポート（簡易）

Pixiu の「我的」から「データエクスポート/明細エクスポート」を開き、期間を選んで **CSV** で保存します。

## 📥 Koala 側：インポート

1. 設定 → 明細インポート
2. インポート元を **Pixiu** に設定
3. CSV を選択 → 帳本を選択
4. 解析 → プレビュー → インポート

## ⚠️ ファイル要件（要点）

- 1 行目はヘッダー
- 列数は 10 列
- 区切りはカンマ `,`
