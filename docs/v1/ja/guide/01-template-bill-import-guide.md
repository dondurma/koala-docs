# テンプレート明細インポート（CSV）

## 📋 概要

Koala は外部ファイルから取引明細（帳簿）をインポートできます。移行や過去データの取り込みに便利です。  
テンプレート / WeChat / Alipay / Pixiu / iCost の 5 つの方式に対応しています。

## 📁 対応ファイル形式

- CSV：テンプレート、Alipay、Pixiu
- Excel：WeChat、iCost

## 🚀 インポート手順

1. Koala → **設定** → **明細インポート**
2. **インポート元** を選択
3. **ファイルパス** でファイルを選択
4. **帳本（Ledger）** を選択
5. 右上の **解析** → プレビュー確認 → **インポート**

> ⚠️ 重要：インポート元を間違えると解析に失敗することがあります。

## 📝 テンプレート CSV のポイント

- 区切り文字：カンマ `,`
- 日付形式：`yyyy/MM/dd`（例：2026/01/01）
- 1 行目はヘッダー必須
