# 精算（立替の精算）

## 1. この機能について

「精算」は、いったん自分で支払い（支出）を記録し、後から会社や相手から立替分を受け取るケース（例：出張、備品購入、立替払いなど）を管理するための機能です。

Koala での基本動作は次のとおりです。

- まず「支出」を記録し、「精算対象（報銷）」としてマークします
- 精算が完了したら、システムが自動で「精算入金」の収入明細を作成し、指定した口座に入金として反映します

この方式のメリット：

- 元の支出が残るため、用途を追跡しやすい
- 入金側も記録されるため、入金口座と日付を照合しやすい
- 集計が分かりやすい（支出と精算入金を別々に記録）

## 2. こんなときに便利

- 会社の精算（交通費、宿泊費、食費、備品など）
- 立替後に相手から送金してもらうケース
- 後日回収する必要がある立替払い

## 3. 使い方

### 3.1 精算対象の支出を作成する

1. 新規で支出明細を作成する
2. 作成/編集画面で「精算（報銷）」（または「精算対象/精算待ち」などの類似オプション）をオンにする
3. 保存後、一覧で「精算待ち/精算済み」などの状態が表示されます

### 3.2 支出を精算する

1. 明細一覧で「精算待ち」の支出を見つける
2. その明細を左にスワイプして「精算」を選ぶ
3. 精算画面で設定する：
   - 金額：初期値は元の支出金額。必要に応じて実際の精算額に変更できます
   - 日付：初期値は今日。必要に応じて実際の入金日へ変更します
   - 入金口座：精算金が実際に入金された口座を選択します
   - メモ：任意
4. 「完了/保存」をタップ

保存後、「精算入金」の収入明細が追加され、入金を記録できます。

## 4. ルールと注意点

- 「支出」かつ「精算対象」にマークされた明細のみ精算できます。
- 分割と精算は併用できません。分割済みの明細（子明細/分割コンテナを含む）は精算フローを開始できず、精算対象にした支出も分割できません。まず精算が必要かを決め、必要なら費用を先に分けたうえで、精算対象部分を別明細として作成してください。
- 「精算入金」が作成された支出は、通常は再度精算できません（重複入金を防ぐため）。
- 「精算入金」の収入明細を削除すると、元の支出は「精算待ち」に戻り、再度精算できます。
- 精算入金は収入として集計され、元の支出は支出として集計されます。資金の流れを明確にするためです。

## 5. よくある質問

### Q1：精算と返金の違いは何ですか？

- 返金：購入の取消/返金で元の明細影響を相殺する（負の金額の返金明細を追加）
- 精算：立替支出に対して後から入金を受け取る（精算入金の収入明細を追加）

### Q2：入金が別の口座に入った場合は？

精算画面で「入金口座」を実際の入金口座に変更してください。

### Q3：一部だけ精算された場合は？

精算額を実際の精算額に変更してください。未精算分は元の支出側に残るため、後からの確認や追加精算に役立ちます。
