# 会員ガイド

## 📋 概要

コアラ家計簿は、複数帳簿・多通貨・明細のエクスポート・明細の分割・定期記帳などの高度な機能を解放する会員サブスクリプションを提供しています。一方で、無料ユーザーも記帳・クラウド同期・クイック記帳・精算などの基本機能を利用できます。

## 💎 会員特典

会員を開通すると以下が解放されます。

- **複数帳簿**：複数の帳簿の作成と管理
- **多通貨**：基軸通貨以外の明細を記録
- **明細のエクスポート**：明細を CSV としてエクスポート
- **明細の分割**：1 件の明細を複数の子明細に分割
- **定期記帳**：周期に応じて明細を自動生成
- **記帳回数無制限**：無料枠の制限を受けません

なお、**クイック記帳・クラウド同期・明細の精算・返金**はすべてのユーザーが利用でき、会員は不要です。

## 🆓 会員 / 無料の比較

| 機能 | 会員 | 無料 |
|------|------|------|
| クイック記帳 | ✅ | ✅ |
| 複数帳簿 | ✅ | ❌ |
| クラウド同期 | ✅ | ✅ |
| 多通貨 | ✅ | ❌ |
| 明細のエクスポート | ✅ | ❌ |
| 明細の分割 | ✅ | ❌ |
| 精算 | ✅ | ✅ |
| 定期記帳 | ✅ | ❌ |
| 記帳回数 | 無制限 | 1,000 件 |

> 📝 無料ユーザーが記帳できる明細の総数は **1,000 件**（帳簿をまたいだ合計）です。上限に達すると、引き続き記帳するには会員の開通が必要です。

## 🚀 開通と復元

### 会員の開通

1. コアラ家計簿を開き、**「設定」** に入る
2. 画面上部のユーザーカードをタップ（未ログインの場合は先に Apple アカウントでログイン）
3. 会員ページに入り、**年額** または **月額** のサブスクリプションを選択
4. App Store の案内に従って支払いを完了

> 💡 **ヒント**：会員価格は App Store の実際の表示と請求に従います。年額サブスクリプションでは通常「月あたり換算」の金額が表示されます。

### 購入の復元

機種変更や再インストール後は、会員ページに入り、右上の **「購入の復元」** をタップし、案内に従って会員状態を復元します（App Store の購読状態に基づきます）。

### サブスクリプションの解約

購読は App Store が管理しており、システムの **「設定 → Apple ID → サブスクリプション」** から解約できます。解約後も、現在支払済みの期間内は会員特典を利用でき、期間満了後は更新されません。

## 🔄 会員ステータス

- 会員の有効期間は App Store の購読状態に基づきます
- 「購入の復元」後も特典が有効にならない場合は、ログインしている Apple アカウントが購入時と一致しているか確認し、しばらくしてから再試行してください

## 🔧 よくある質問

### Q1：なぜ会員は買い切り（一次性購入）ではないのですか？

会員制のほうが長期的な継続運用に適しています。継続的な不具合修正、体験の改善、OS アップデートや新機種への対応、そして同期・データ安全性・パフォーマンスなどへの長期的な投資を続けられます。

### Q2：無料ユーザーにはどのような制限がありますか？

無料ユーザーは記帳・クラウド同期・クイック記帳・精算・返金などの機能を利用できますが、明細の総数は 1,000 件までで、複数帳簿・多通貨・明細のエクスポート・明細の分割・定期記帳は利用できません。

### Q3：機種変更後も会員は続きますか？

購読状態は App Store が保持しているため、機種変更や再インストール後に購入時の Apple アカウントでログインし、「購入の復元」をタップすると復元できます。
