# 会員ガイド

## 📋 概要

コアラ家計簿は、複数帳簿・多通貨・明細のエクスポート・明細の分割・定期記帳などの高度な機能を解放する会員サービス（月額／年額のサブスクリプションまたは買い切り）を提供しています。一方で、無料ユーザーも記帳・クラウド同期・クイック記帳などの基本機能を利用できます。

## 💎 会員特典

会員を開通すると以下が解放されます。

- **複数帳簿**：複数の帳簿の作成と管理
- **多通貨**：基軸通貨以外の明細を記録
- **明細のエクスポート**：明細を CSV としてエクスポート
- **明細の分割**：1 件の明細を複数の子明細に分割
- **定期記帳**：周期に応じて明細を自動生成
- **記帳回数無制限**：無料枠の制限を受けません

なお、**クイック記帳・クラウド同期**はすべてのユーザーが利用でき、会員は不要です。

## 🆓 会員 / 無料の比較

| 機能 | 会員 | 無料 |
|------|------|------|
| クイック記帳 | ✅ | ✅ |
| 複数帳簿 | ✅ | ❌ |
| クラウド同期 | ✅ | ✅ |
| 多通貨 | ✅ | ❌ |
| 明細のエクスポート | ✅ | ❌ |
| 明細の分割 | ✅ | ❌ |
| 精算 | ✅ | ❌ |
| 返金 | ✅ | ❌ |
| 明細の絞り込み | ✅ | ❌ |
| 定期記帳 | ✅ | ❌ |
| 記帳回数 | 無制限 | 300 件 |

> 📝 無料ユーザーが記帳できる明細の総数は **300 件**（帳簿をまたいだ合計）です。上限に達すると、引き続き記帳するには会員の開通が必要です。

## 🚀 開通と復元

### 会員の開通

1. コアラ家計簿を開き、**「設定」** に入る
2. 画面上部のユーザーカードをタップ（未ログインの場合は先に Apple アカウントでログイン）
3. 会員ページに入り、**月額** サブスクリプション、**年額** サブスクリプション、または **永久会員**（買い切り）を選択
4. App Store の案内に従って支払いを完了

> 💡 **ヒント**：会員価格は App Store の実際の表示と請求に従います。年額サブスクリプションでは通常「月あたり換算」の金額が表示されます。

> ⚠️ **永久会員の購入前の注意**：永久会員を購入しても既存のサブスクリプションは自動解約されず、Apple は支払済みの購読料を返金しません。以前に購読していた場合は、先に **「設定 → Apple ID → サブスクリプション」** で解約してください。

### 購入の復元

機種変更や再インストール後は、会員ページに入り、右上の **「購入の復元」** をタップし、案内に従って会員状態を復元します（App Store の購読状態に基づきます）。

### サブスクリプションの解約

購読は App Store が管理しており、システムの **「設定 → Apple ID → サブスクリプション」** から解約できます。解約後も、現在支払済みの期間内は会員特典を利用でき、期間満了後は更新されません。

## 🔄 会員ステータス

- 会員特典は App Store の購入・購読状態に基づきます。永久会員は長期にわたり有効です
- 「購入の復元」後も特典が有効にならない場合は、ログインしている Apple アカウントが購入時と一致しているか確認し、しばらくしてから再試行してください

## 🔧 よくある質問

### Q1：会員にはサブスクリプションと永久会員の 2 種類がありますが、どちらを選べばいいですか？

特典はどちらも同じで、支払い方法だけが異なります。月額／年額サブスクリプションは、しばらく試してから判断したい人やいつでも解約したい人に向いています。永久会員は一度支払えば長期間有効で、長く使うと決めていて更新の管理をしたくない人に向いています。価格は App Store の表示に従います。

注意：永久会員を購入しても既存のサブスクリプションは解約されず、支払済みの購読料も返金されません。先に App Store でサブスクリプションを解約してください。

### Q2：無料ユーザーにはどのような制限がありますか？

無料ユーザーは記帳・クラウド同期・クイック記帳などの機能を利用できますが、明細の総数は 300 件までで、複数帳簿・多通貨・明細のエクスポート・明細の分割・定期記帳・精算・返金・明細の絞り込みは利用できません。

### Q3：機種変更後も会員は続きますか？

購入記録は App Store が保持しているため、機種変更や再インストール後に購入時の Apple アカウントでログインし、「購入の復元」をタップすると復元できます（永久会員も同様です）。
