# Alipay 明細インポート

## 📋 概要

本ガイドでは、Alipay から明細をエクスポートし、コアラ家計簿にインポートする手順を説明します。

---

## 📱 手順 1：Alipay で明細をエクスポート

### 手順 1：明細（账单）画面を開く

1. Alipay を開く
2. 画面下の **「我的」** をタップ
3. **「账单」** をタップして明細画面へ

> 📝 注意：Alipay のバージョンにより入口が異なる場合があります。見つからない場合は、Alipay の検索で「账单」を検索してみてください。

### 手順 2：エクスポートを開始

1. 明細画面で右上の **「...」** をタップ
2. **「开具交易流水证明」** または **「账单导出」**（表記はバージョンにより異なる）を選択
3. **「用户个人对帐」** を選び、**「申请」** をタップ

### 手順 3：範囲と受け取り方法を選択

1. 取引種別：**全部交易** / **收入** / **支出**
2. 期間（例：直近 1 か月 / 直近 3 か月など）
3. 受け取り方法：**支付宝** / **邮箱**

> 💡 ヒント：
> - 1 回のエクスポートは 3 か月以内をおすすめします（ファイルが大きいと処理が遅くなることがあります）。
> - 長期間の履歴は複数回に分けてエクスポートしてください。
> - メール受け取りの場合は、Alipay 側でメールアドレス設定が必要です。

### 手順 4：端末に保存

1. メール受け取りの場合：
   - メールアプリで Alipay からのメールを開く
   - 添付ファイル（CSV）をダウンロード
   - 端末内（ファイルアプリで参照できる場所）に保存
2. 「ファイルに保存」できる場合：
   - ダウンロードフォルダ等に保存
   - 保存先を覚えておく

> 📝 保存先の目安：
> - iOS：ファイル App → ダウンロード
> - Android：ダウンロードフォルダ、または Alipay フォルダ

---

## 📱 手順 2：コアラ家計簿にインポート

### 手順 1：インポート画面を開く

1. コアラ家計簿を開く
2. 画面下の **「設定」** をタップ
3. **「明細インポート」** を探して開く

### 手順 2：インポート元を選択

1. **「インポート元」** をタップ
2. **「Alipay」** を選択

> ⚠️ 重要：必ず Alipay を選択してください。選択を間違えるとファイル形式を正しく解析できません。

### 手順 3：ファイルを選択

1. **「ファイルパス」** をタップ
2. Alipay からエクスポートした **CSV**（`.csv`）を選択
3. ファイル名が表示されることを確認

### 手順 4：レッジ（Ledger）を関連付け

1. **「関連付けレッジ」** をタップ
2. 取り込み先のレッジを選択

### 手順 5：解析 → プレビュー → インポート

1. 右上の **「解析」** をタップ
2. プレビュー画面で内容を確認し、必要に応じてカテゴリ/口座/メモ等を調整
3. **「インポート」** をタップ

---

## 📋 Alipay CSV の列（参考）

Alipay の CSV は通常、次の列を含みます。

| 列名（エクスポートの表記） | 内容 | 例 |
|------|------|------|
| 交易时间 | 取引日時 | 2024-01-01 12:00:00 |
| 交易分类 | 分類 | 餐饮美食/日用百货 |
| 交易对方 | 相手先 | 张三 / 商户名称 |
| 对方账号 | 相手アカウント | xxx@163.com |
| 商品说明 | 内容 | 午餐 / 购物等 |
| 收/支 | 収入/支出 | 收入 / 支出 |
| 金额 | 金額 | 100.00 |
| 收/付款方式 | 支払方法/口座 | 余额宝 |
| 交易状态 | 状態 | 交易成功 / 已退款 |
| 交易订单号 | 取引注文番号 | 20240101... |
| 商家订单号 | 店舗注文番号 | 1234567890 |
| 备注 | メモ | 备注内容 |

> 📝 注意：列名はバージョンによって多少異なる場合がありますが、内容はほぼ同じです。

## ⚠️ 注意事項

### 1. ファイルの条件

- **文字コード**：UTF-8 推奨（Alipay は UTF-8 または GBK の場合があります）
- **形式**：CSV のみ（`.csv`）
- **サイズ**：1 ファイル 10MB 以下を推奨

### 2. 取り込みの扱い（概要）

コアラ家計簿は Alipay の列を自動でコアラ家計簿の項目に変換します。

- 交易时间（row[0]）→ 日付（`yyyy-MM-dd` の日付のみとして取り込み）
- 交易分类（row[1]）→ カテゴリ（親子とも同名で取り込み）
- 收/支（row[5]）→ 収入/支出
- 金额（row[6]）→ 金額
- 收/付款方式（row[7]）→ 口座（名称で照合、存在しない場合は作成されることがあります）
- 交易对方/对方账号/商品说明/交易状态/订单号等 → メモとして結合
- 备注（row[11]）→ 元のメモ（「/」や空は無視され、上記の追記が加わります）

### 3. 重複・返金の扱い

- 取引番号などから重複と判断された場合、スキップされることがあります。
- 返金は「已退款/退款成功」などで表現されることが多いため、プレビューで確認してください。

### 4. ファイルは編集しない

Alipay から書き出した CSV は、**ヘッダー名の変更・列の削除・列の追加** をしないでください。解析に失敗する原因になります。

## 🔧 よくある質問

### Q1：「账单导出」が見つかりません

可能性：

1. Alipay のバージョンが古い
2. 入口が別の場所にある

試すこと：

- 明細画面の右上 **「...」** を確認
- 「我的」から **账单** を探す
- 検索で「账单导出」を検索

### Q2：メールが届きません

確認：

1. Alipay にメールアドレスを設定済みか
2. アドレスが正しいか
3. 迷惑メールフォルダ
4. 「ファイルに保存」方式を試す

### Q3：解析に失敗します

確認：

1. CSV 形式か
2. インポート元が Alipay か
3. ファイルが破損していないか
4. 文字コード（UTF-8 / GBK）

### Q4：カテゴリが期待通りになりません

Alipay の分類とコアラ家計簿の分類が一致しない場合があります。プレビュー画面で修正するか、インポート後にまとめて編集してください。

### Q5：画像を取り込めますか？

現時点では対応していません。

### Q6：どのくらいの期間を取り込めますか？

制限はありませんが、次を推奨します。

1. 1 回の取り込みは 3 か月程度まで
2. 大量の場合はファイルを分割
3. インポート中はアプリを前面にしておく

### Q7：なぜ CSV のみ対応ですか？

現在 Alipay のエクスポート形式が CSV のためです。将来 Excel に対応した場合はガイドを更新します。

## 💡 使い方のコツ

1. 毎月など定期的に取り込むと管理しやすい
2. 取り込み後にカテゴリを整理すると集計が見やすくなる
3. よく使う口座は先に作成しておくと、口座名が自動生成されにくい
4. 念のため、取り込み前にバックアップを推奨
5. 返金明細がある場合は取り込み後に確認
