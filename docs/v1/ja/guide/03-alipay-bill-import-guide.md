# Alipay 明細インポート

## 📋 概要

Alipay から明細をエクスポートし、Koala に取り込む手順です。

## 📤 Alipay 側：エクスポート（簡易）

Alipay → **我的** → **账单** → 右上「...」→ **账单导出/开具交易流水证明** → **用户个人对帐** → 期間を選択 → CSV を保存。

## 📥 Koala 側：インポート

1. Koala → **設定** → **明細インポート**
2. **インポート元** を **Alipay** に設定
3. エクスポートした `.csv` を選択
4. 帳本を選択 → **解析** → プレビュー → **インポート**

⚠️ CSV の表頭や列を変更すると解析に失敗することがあります。
