# iCost 明細インポート

## 📋 概要

本ガイドでは、**iCost** から書き出した明細を **コアラ家計簿** にインポートする手順を説明します。

コアラ家計簿は現在、**iCost の Excel エクスポート**（`.xlsx` / `.xls`）に対応しています。**iCost の CSV は非対応**です。

---

## 📱 手順 1：iCost で明細をエクスポート

iCost はバージョンによってメニュー名が多少異なりますが、流れは共通です。「エクスポート/データ書き出し」から Excel 形式で保存します。

### 手順 1：エクスポート画面を開く

1. iCost を開く
2. **設定 / もっと**（または「我的」の設定）を開く
3. **导出 / 数据导出 / 导出账单**（表記は異なる場合あり）を探す

### 手順 2：形式を Excel にして保存

1. 形式：**Excel（.xlsx / .xls）** を選択
2. 期間を選択（1 回あたり 3 か月以内を推奨）
3. エクスポートして端末に保存（共有 → ファイルに保存 など）

> ⚠️ 重要：CSV で書き出すと、コアラ家計簿側で「CSV は非対応、Excel を使用してください」と表示されます。

---

## 📱 手順 2：コアラ家計簿にインポート

### 手順 1：インポート画面を開く

1. コアラ家計簿を開く
2. **「設定」** → **「明細インポート」**

### 手順 2：インポート元を選択

1. **「インポート元」** をタップ
2. **「iCost」** を選択

> ⚠️ 重要：必ず iCost を選択してください。別のインポート元で解析すると、ヘッダーが見つからない、または列がずれて読み取られることがあります。

### 手順 3：ファイルを選択

1. **「ファイルパス」** をタップ
2. iCost から書き出した Excel（`.xlsx` / `.xls`）を選択
3. ファイル名が表示されることを確認

### 手順 4：帳簿を関連付け

1. **「関連帳簿」** をタップ
2. 取り込み先の帳簿を選択

### 手順 5：解析 → プレビュー

1. 右上の **「解析」** をタップ
2. 成功するとプレビュー画面へ移動
3. プレビューでカテゴリ/口座/時間/金額/タグ/メモなどを編集してから取り込みできます

### 手順 6：インポート実行

1. 内容を確認したら **「インポート」** をタップ
2. 完了まで待つ

## 📋 iCost Excel の形式（参考）

コアラ家計簿の iCost Excel の認識方式：

- 読み取り可能なワークシートが存在すること
- システムは**ヘッダー名**で列を自動認識します（列の順番に依存しません）。ヘッダー行は先頭から数行以内に含まれていれば問題ありません
- ヘッダー名が必須フィールド（日付/種別/金額）に対応しない場合、ヘッダーが見つからない旨のメッセージが表示されるか、「フィールドマッピング確認画面」に移行して手動で指定します

> 📝 **ヒント**：iCost のエクスポートで言語を選べる場合、**中国語ヘッダー**での出力をおすすめします（より自動認識されやすくなります）。

### フィールド定義

| フィールド | 説明 |
|------|------|
| 日付 | `yyyy-MM-dd` / `yyyy/MM/dd` / `yyyy-MM-ddTHH:mm:ss` / `yyyy-MM-dd HH:mm:ss` に対応。Excel のシリアル日付にも対応 |
| 種別 | テキストに「支出」または「收入」のキーワードが必要。「支出」を含む=支出、「收入」を含む=収入 |
| 金額 | `+` / `-` を含んでも可。取り込み時に符号を自動除去し、千区切りカンマも除去します |
| 親カテゴリ（大分類） | コアラ家計簿の親カテゴリ名との照合に使用 |
| 子カテゴリ（小分類） | 空の場合は「親カテゴリ」の値を自動的に使用 |
| 口座 | 空の場合は既定口座をフォールバックとして使用 |
| 備考 | 備考テキスト |
| 通貨コード | 例：`CNY` / `USD`。空または照合失敗の場合は取り込み先帳簿の既定通貨を使用 |
| タグ | 複数タグはカンマ区切り（中国語カンマ `，` も対応） |

### コアラ家計簿への取り込み（概要）

- 日付 → 日付
- 種別（「支出/収入」を含む）→ 収入/支出
- 金額 → 金額
- 大分類 → 大分類（照合/作成）
- 小分類（空なら大分類を使用）→ 小分類（照合/作成）
- 口座（空なら既定口座）→ 口座
- 備考 → 備考
- 通貨コード → 通貨（コードで照合。失敗時は帳簿の既定通貨）
- タグ → タグ（解析/作成して紐付け）

## ⚠️ 注意事項

1. **Excel のみ対応**：iCost の CSV は取り込めません。
2. **自動重複排除なし**：同じファイルを二重に取り込むと重複明細が作成されます。取り込み範囲の重複に注意してください。
3. **ヘッダー名**：解析はヘッダー名が「日付/種別/金額」などのフィールドに対応できるかに依存します。認識できない場合は、ヘッダー未検出のメッセージが表示されるか、「フィールドマッピング確認画面」に移行します。
4. **口座が空の場合**：「口座」列が空だと既定口座に入ります。プレビューで口座を編集するか、iCost 側で口座を補完してから再書き出ししてください。
5. **カテゴリ一致**：親 + 子の名称で一致させます。未一致の場合はプレビューで修正してから取り込んでください。

## 🔧 よくある質問

### Q1：「iCost のヘッダーが見つからない」と表示されます

主な原因：

1. ヘッダー名を認識できない（例：英語ヘッダーで、「日付/種別/金額」などのフィールドに対応できない）
2. iCost から書き出した明細ファイルではない、または二次編集で表構造が壊れている
3. Excel が空、またはワークシートがない

> 📝 ヘッダー名が一部しか認識できない場合、「フィールドマッピング確認画面」に移行して、各列に対応するフィールドを手動で指定してから取り込むことができます。

### Q2：口座が空で、全部同じ口座に入ってしまいました

「口座」列が空の場合の既定動作です。プレビューで口座を編集するか、iCost 側で口座を補完してから再インポートしてください。

### Q3：カテゴリが一致しません

プレビューで 1 件ずつ正しいカテゴリを選択してください。もしくはコアラ家計簿側に iCost と同名のカテゴリを事前に作成してから再解析してください。
