# iCost 明細インポート

## 📋 概要

Koala は iCost の **Excel エクスポート**（`.xlsx` / `.xls`）をインポートできます。iCost の CSV は非対応です。

## 📤 iCost 側：エクスポート（簡易）

iCost の設定/その他から「エクスポート/データエクスポート」を開き、形式を **Excel** にして保存します。

## 📥 Koala 側：インポート

1. 設定 → 明細インポート
2. インポート元を **iCost** に設定
3. Excel ファイルを選択 → 帳本を選択
4. 解析 → プレビュー → インポート

## ⚠️ 注意

- 解析はヘッダー行に「日期」が含まれることを前提にしています。エクスポート言語を選べる場合は中国語ヘッダーでの出力を推奨します。
- 同じファイルを重複してインポートすると重複明細が作成される場合があります。
