# iCost 明細インポート

## 📋 概要

本ガイドでは、**iCost** から書き出した明細を **Koala** にインポートする手順を説明します。

Koala は現在、**iCost の Excel エクスポート**（`.xlsx` / `.xls`）に対応しています。**iCost の CSV は非対応**です。

---

## 📱 手順 1：iCost で明細をエクスポート

iCost はバージョンによってメニュー名が多少異なりますが、流れは共通です。「エクスポート/データ書き出し」から Excel 形式で保存します。

### 手順 1：エクスポート画面を開く

1. iCost を開く
2. **設定 / もっと**（または「我的」の設定）を開く
3. **导出 / 数据导出 / 导出账单**（表記は異なる場合あり）を探す

### 手順 2：形式を Excel にして保存

1. 形式：**Excel（.xlsx / .xls）** を選択
2. 期間を選択（1 回あたり 3 か月以内を推奨）
3. エクスポートして端末に保存（共有 → ファイルに保存 など）

> ⚠️ 重要：CSV で書き出すと、Koala 側で「CSV は非対応、Excel を使用してください」と表示されます。

---

## 📱 手順 2：Koala にインポート

### 手順 1：インポート画面を開く

1. Koala を開く
2. **「設定」** → **「明細インポート」**

### 手順 2：インポート元を選択

1. **「インポート元」** をタップ
2. **「iCost」** を選択

> ⚠️ 重要：必ず iCost を選択してください。別のインポート元で解析すると、ヘッダーが見つからない、または列がずれて読み取られることがあります。

### 手順 3：ファイルを選択

1. **「ファイルパス」** をタップ
2. iCost から書き出した Excel（`.xlsx` / `.xls`）を選択
3. ファイル名が表示されることを確認

### 手順 4：帳本（Ledger）を関連付け

1. **「関連付け帳本」** をタップ
2. 取り込み先の帳本を選択

### 手順 5：解析 → プレビュー

1. 右上の **「解析」** をタップ
2. 成功するとプレビュー画面へ移動
3. プレビューでカテゴリ/口座/時間/金額/タグ/メモなどを編集してから取り込みできます

### 手順 6：インポート実行

1. 内容を確認したら **「インポート」** をタップ
2. 完了まで待つ

---

## 📋 iCost Excel の形式（参考）

Koala の検証ポイント：

- 読み取り可能なワークシートが存在すること
- ヘッダー行に **「日期」** が含まれること（ヘッダー行の特定に使用）

> 📝 ヒント：iCost のエクスポートで言語を選べる場合、**中国語ヘッダー**での出力をおすすめします（少なくとも「日期」を含めてください）。

### 読み取り列（位置で判定）

Koala は iCost Excel の一部列を「列位置」で読み取ります。その他の列は無視されます。

| 列 | フィールド | 説明 |
|------|------|------|
| 1 | 日付 | `yyyy-MM-dd` / `yyyy/MM/dd` / `yyyy-MM-ddTHH:mm:ss` / `yyyy-MM-dd HH:mm:ss`、および Excel のシリアル日付に対応 |
| 2 | 種別 | 「支出」または「收入」を含む必要あり（支出/収入を判定） |
| 3 | 金額 | `+` / `-` を含んでも可。取り込み時に符号を除去し、千区切り `,` も処理 |
| 4 | 親カテゴリ | Koala の親カテゴリ名と照合 |
| 5 | 子カテゴリ | 空の場合は親カテゴリを使用 |
| 6 | 口座 | 空の場合は既定口座（デフォルト）を使用 |
| 8 | メモ | メモ本文 |
| 9 | 通貨コード | `CNY` / `USD` など。空または不一致の場合は帳本通貨を使用 |
| 10 | タグ | 複数タグはカンマ区切り（`,`）。中国語カンマ `，` も対応 |

### Koala への取り込み（概要）

- 日付（row[0]）→ 日付
- 種別（row[1]）→ 収入/支出
- 金額（row[2]）→ 金額
- 親カテゴリ（row[3]）→ 親カテゴリ（照合/作成）
- 子カテゴリ（row[4]、空なら親）→ 子カテゴリ（照合/作成）
- 口座（row[5]、空なら既定）→ 口座
- 7 列目（row[6]）→ 未使用（取り込み対象外）
- メモ（row[7]）→ メモ
- 通貨コード（row[8]）→ 通貨（コードで照合。不一致は帳本通貨）
- タグ（row[9]）→ タグ（照合/作成して紐付け）

## ⚠️ 注意事項

1. **Excel のみ対応**：iCost の CSV は取り込めません。
2. **自動重複排除なし**：同じファイルを二重に取り込むと重複明細が作成されます。取り込み範囲の重複に注意してください。
3. **ヘッダー言語**：「日期」を含む行をヘッダーとして探すため、英語ヘッダー等だとヘッダーが見つからず失敗することがあります。
4. **口座が空の場合**：「口座」列が空だと既定口座に入ります。プレビューでまとめて口座を編集するか、iCost 側で口座を補完してから再書き出ししてください。
5. **カテゴリ一致**：親 + 子の名称で一致させます。未一致の場合はプレビューで修正してから取り込んでください。

## 🔧 よくある質問

### Q1：「iCost のヘッダーが見つからない」と表示されます

主な原因：

1. ヘッダー行に「日期」が含まれていない（英語ヘッダーなど）
2. iCost のファイルではない、または編集して構造が崩れている
3. Excel が空、またはワークシートがない

iCost から再エクスポートし、中国語ヘッダーを優先してください。

### Q2：口座が空で、全部同じ口座に入ってしまいました

「口座」列が空の場合の既定動作です。プレビューでまとめて口座を編集するか、iCost 側で口座を補完してから再インポートしてください。

### Q3：カテゴリが一致しません

プレビューで 1 件ずつ正しいカテゴリを選択してください。もしくは Koala 側に iCost と同名のカテゴリを事前に作成してから再解析してください。
