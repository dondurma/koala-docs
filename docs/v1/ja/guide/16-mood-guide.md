# 気分記録ガイド

## 📋 概要

コアラ家計簿は概観ページに「気分カード」を用意しており、記帳のついでに毎日の気分を手軽に記録し、月表示で振り返ることができます。支出と心の状態を同時に気にかけたい方や、毎日のチェックインを続けたい方に適しています。

## 🚀 気分の記録方法

1. コアラ家計簿を開き、画面下のナビゲーションバーの **「概観」** ページに入る
2. **「気分カード」** を見つける（当月で今日まだ記録していない場合、カード下部に 3 つの選択肢が表示されます）
3. **うれしい / ふつう / かなしい** のいずれかをタップすると、今日の気分を記録できます

> 📝 **注意**：
> - 1 日に 1 回だけ記録できます（自然日単位）
> - その日の気分を記録すると、当日は選択肢が表示されなくなり、**アプリ内での変更・削除はできません**
> - 記録できるのは「当日」の気分のみで、過去の日付への遡及記録や変更はできません

## 📅 月表示の確認

気分カードには当月の記録状況が表示されます。

- 上部に当月の**記録済み日数 / 総日数**と今日の気分を表示
- 下部に当月の各日をグリッドで表示：記録済みの日は気分に応じて色分けされ（うれしい / ふつう / かなしいごとに 1 色）、未記録の日は薄い色になります
- 未来の日付は表示されません

> 💡 **ヒント**：概観ページで他の月に切り替えると、カードにはその月の記録状況が表示されます（「今日」の情報は表示されません）。

## 🎨 カスタマイズ設定

**「設定」→「カスタマイズ」** に入ると、気分に関するオプションを調整できます。

- **気分カードを表示**：スイッチで概観ページに気分カードを表示するかどうかを切り替え（既定は表示）
- **気分の色**：「うれしい / ふつう / かなしい」の 3 つの気分に対応する色をカスタマイズ

> 📝 **注意**：気分の色は「統計ページの共有 → 気分の記録」で生成されるヒートマップにも反映されます。

## 📤 気分記録の共有

1. 画面下のナビゲーションバーの **「統計」** ページを開く
2. ページ下部の **「この画面を共有 >」** をタップ
3. 表示されるメニューで **「気分の記録」** を選択
4. 気分ヒートマップが生成されたら、システムの共有パネルから送信または保存

> ⚠️ **注意**：
> - 「気分の記録」の共有は、時間軸が「月別」または「年別」の場合のみ利用できます（カスタム期間ではこの項目は表示されません）
> - 気分記録と明細データは互いに独立しており、明細の統計には影響しません

## 🔄 マルチデバイス同期

- **アカウントにログイン後**：気分記録はアカウントに紐づいて同期され、複数デバイスで同じアカウントにログインすれば同じ気分記録を確認できます
- **未ログイン時**：気分記録は端末内にのみ保存され、アンインストールや機種変更後は復元できません

> 📝 気分記録はアカウント単位で同期され、帳簿データとは相互に独立しています。

## 🔧 よくある質問

### Q1：間違った気分を記録した場合、変更できますか？

現在、1 日に 1 回のみ記録でき、記録後はアプリ内で変更・削除できません。記録前にご確認ください。

### Q2：数日前の気分を遡って記録できますか？

現在は「当日」の気分のみ記録でき、過去の日付への遡及記録や変更には対応していません。

### Q3：概観ページに気分カードが表示されないのはなぜですか？

**「設定」→「カスタマイズ」→「気分カードを表示」** がオンになっているかご確認ください。

### Q4：機種変更後も気分記録は残りますか？

ログインして同期が完了していれば、再インストール後に同じアカウントでログインするとアカウントに紐づいて復元されます。未ログインの場合、データは端末内にのみ保存されます。
