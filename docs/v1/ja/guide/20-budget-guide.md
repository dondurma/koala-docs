# 予算管理ガイド

## 📋 概要

予算管理は**メンバーシップ機能**です。月ごとの総予算に加えて、カテゴリごとの予算も設定でき、概要ページで「今月あといくら使えるか」を確認できます。

## 🚀 入口

**「設定」→「予算管理」** を開きます。

> 📝 非メンバーが開くと「メンバーシップ機能」の案内が表示されます。メンバーシップを開通すると利用できます。

## 💰 月間予算の設定

1. 「月間予算」の右側の**鉛筆**アイコンをタップ
2. 電卓で金額を入力し「完了」をタップ
3. 0 を入力して完了すると「今月の予算をクリア」の確認が出ます

> 📝 上限は 9,999,999.99 です。予算は月ごとに独立して保存されます。

## 🗂 カテゴリ予算の設定

1. 「カテゴリ予算を追加」をタップ
2. **大分類**または**サブカテゴリ**を選び、カテゴリをタップ
3. 金額を入力して完了

ルール：

- 同じカテゴリツリーでは**1 階層のみ**設定できます（「食費」に設定済みならそのサブカテゴリには設定できず、逆も同様）。競合時はその場で案内が出ます。
- カテゴリ行には「使用額 / 予算」と進捗バーが表示され、タップするとそのカテゴリの当月の明細を確認できます。

## 📊 概要ページの進捗バー

「月間収支の概要」カードの下に予算額・パーセント・進捗バーが表示されます：

- **50% 未満**：安全色
- **50%〜100%**：注意色
- **100% 超**：超過色（「超過」と表示）

この部分をタップすると同月の予算管理へ移動します。3 色はいずれも予算設定で変更できます。

## 🔁 繰り越しと超過分の控除

**「設定」→「予算管理」→ 右上のスライダーアイコン**を開くと 4 つのスイッチがあります：

- **予算スイッチ**：オフにすると概要ページの進捗バーが非表示になります（データは保持）
- **カテゴリ予算を月間予算に含める**：カテゴリ予算の合計を月間予算に加算
- **残額を翌月へ繰り越す**：使い切らなかった分を翌月へ
- **超過分を翌月から控除**：超過した分を翌月から差し引く

> 📝 実際に翌月へ引き継がれるのは**締め済みの月**のみです。当月は「今月の残り ¥xx・月末精算後に翌月へ」という見込み表示になります。
> 📝 繰り越しの起点は**最初にスイッチをオンにした月**で、それ以前の月には遡りません。

## 📱 複数端末

ログインすると予算はアカウントと同期されます：

- アプリの再起動後、および「概要」ページを開いている間に自動同期（手動更新は不要）
- 予算は会員機能のため、未ログインではご利用いただけません

## 🔧 よくある質問

### Q1：概要ページに進捗バーが出ません

予算スイッチがオンか、その月に予算があるか、アカウントがメンバーかを確認してください。いずれかが欠けると表示されません。

### Q2：ある月の予算を変えても他の月が変わらないのは？

予算は月ごとに独立して保存されるため、月ごとに設定が必要です。

### Q3：繰り越しに以前の月の残額が入らないのは？

起点は「最初に繰り越しをオンにした月」で固定です。それ以前から積み上げたい場合は、その月まで遡って設定する必要があります。

### Q4：カテゴリを削除したら予算はどうなりますか？

カテゴリ削除時に予算も削除され、同期後は両端末とも表示されません。
