# 明細インポートの注意点

明細をインポートする前に、中断やデータの欠落を防ぐため、以下の点をご確認ください。

## 一度にたくさんインポートしない

- 1 回のインポートは**1000 件以内**を推奨します。それ以上は**分割してインポート**してください（例：1 回 500〜1000 件）。
- 無料ユーザーは全帳簿の明細合計が **300 件**まで、会員は無制限です。データが多い場合は、インポート前に残りの登録可能件数をご確認ください。

## データが多いときは気長に待つ

- 解析とインポートには時間がかかります。件数が多いほど待ち時間が長くなり、1000 件前後では数十秒以上かかることがあります。
- 「固まった」と勘違いせず、進行が完了するまでお待ちください。

## インポート中はページを離れない

- インポート中は**現在のページにとどまって**ください。戻る、他のアプリへの切り替え、画面ロック、アプリの強制終了はしないでください。
- 途中で離れると**インポートが中断**され、一部だけ取り込まれたり、再度インポートが必要になったりすることがあります。

## インポート完了後

- 完了後は、データがアップロードされているか、一度手動で同期することをおすすめします。
- 明細一覧で数件を確認し、金額・カテゴリ・日付に誤りがないかチェックしてください。
