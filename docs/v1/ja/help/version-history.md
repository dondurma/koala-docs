# 更新履歴

> 本ページは、コアラ家計簿（Koala）の各リリースの更新内容を記録します。新しい順（降順）で管理します（最新を先頭に）。

## 2026-10-28 v1.1.3（36）

### 追加機能

1. 「永久会員」を追加：月額・年額・買い切りの3つから選べ、会員ページからいつでもアップグレードできます。買い切りは一度の購入でずっと有効です。
2. 会員ページに「オファーコードを引き換え」を追加。コードを入力するとすぐに会員を有効にできます。
3. 口座の振替記録を月ごとに表示できるようになり、前月・翌月の切り替えと「今月に戻る」が使えます。
4. クラフト紙テーマのスイッチをレトロな角括弧デザインに変更し、紙の雰囲気に合わせました。

### 修正

1. 明細の分割で「完了」を連打しても二重に分割されなくなりました。1件だけの分割は保存できず、元の明細が書き換わる心配もありません。
2. ある口座のデータに問題があっても、他の口座や振替はそのまま同期され、同期全体が止まりません。同期状態でスキップされた件数も確認できます。
3. 同期は成功しているのに「未同期」のまま何度も再試行される問題を修正しました。
4. 明細・振替・口座を削除したあと、残高や関連データが別の端末に残ったり二重に差し引かれたりしなくなりました。
5. 明細を追加するときの既定日付が表示中の日付に合わせて変わり、過去の月に記録してもすぐ表示されます。
6. 会員購入後の状態確認に失敗してもページが固まらず、「会員ステータスを同期中です」と表示して戻ります。未ログイン時に会員ページを開いても購入には進みません。
7. ダークモードのダイアログ背景とボタンの角丸を統一し、見た目の違和感をなくしました。
8. 設定画面や記帳画面の一部スイッチ行が隣の行より高くならなくなり、行全体をタップしても切り替えられます。
9. 口座の明細・振替記録の読み込みに失敗したときに案内を表示し、タップで再試行できるようにしました。
10. 明細検索で素早く連続入力しても、古い検索結果が新しい結果を上書きしないようにしました。

## 2026-10-14 v1.1.2（34）

### 追加機能

1. 口座アイコンのカスタマイズに対応：口座の作成・編集時にアイコンを選べるほか、絵文字も入力できます。
2. 「キーパッドの振動」スイッチを追加：数字キーパッドをタップすると軽く振動します（設定でいつでもオフにできます）。キーを軽くタップしたときも押下エフェクトが表示されます。
3. プロフィールカードの背景を刷新：「まばらな枝 / 繁る葉 / 無地の便箋 / マットクレイ / クラフト紙 / ライトウッド」などを追加し、「なし」も選べます。

### 修正

1. 明細の編集時に「精算対象」タグを直接解除できるようになりました。
2. 精算入帳が既に作成されている明細では、「精算対象」タグを解除しようとすると、解除できない旨が表示されます（記録の食い違いを防ぎます）。

## 2026-10-12 v1.1.1（33）

### 追加機能

1. グリッド記帳でサブカテゴリを選ぶと、アイコンが電卓に飛び込む演出を追加。操作がより分かりやすくなります。

### 修正

1. 2台の端末で同時に精算を記録したとき、入帳された明細が重複したり食い違うことがある問題を修正。
2. ラインモードで大分類を切り替えた後、右側のサブカテゴリが前の分類のまま残ることがある問題を修正。
3. 通貨・為替レート画面で言語を切り替えるとグループ表示が乱れる問題を修正。
4. Apple サインイン時にプロフィールカードが一瞬空になる問題を修正。「サインイン中…」を表示するようにしました。
5. 収支選択の「よく使う」の余分な項目を削除し、カテゴリ一覧をすっきり。
6. 一部の画面の文言を修正。
7. アカウントを削除して入り直した後、下部ナビゲーションバーのボタンが反応しない問題を修正。

## 2026-10-05 v1.1.0（32）

### 追加機能

1. 新テーマ「クラフト紙」を追加。レトロな紙の質感で、アプリ全体の雰囲気が引き立ちます。
2. レトロフォントと角丸サイズの設定を追加。好みのスタイルにすぐ変更できます。
3. 複数のカードの背景を追加。プロフィール画面を自由に飾れます。
4. 「明細レシート」を追加。明細をワンタップで素敵なレシートにして共有できます。
5. 使い方を充実させ、複数の画面のタイトルバーに「?」ヘルプ入口を追加。
6. 項目が使用頻度順に並び、よく使うものが上に表示されます。
7. 同期ステータスが見やすくなり、未同期のデータがあるとヒントを表示します。
8. アプリアイコンを更新。

### 修正

1. 明細インポートの解析速度を大幅に改善。大きなファイルでも長く待たされません。
2. 一部の画面表示と文言の細部を修正。
