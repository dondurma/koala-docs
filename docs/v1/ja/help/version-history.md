# 更新履歴

> 本ページは、コアラ家計簿（Koala）の各リリースの更新内容を記録します。新しい順（降順）で管理します（最新を先頭に）。

## 2026-09-26 v1.0.7（31）

### 修正

1. 精算で入れた明細が勝手に消えてしまう問題を修正。機種変更や再インストール後も残ります。
2. 別のアカウントでログインし直したあと、前のアカウントの失敗分が同期に引き継がれる問題を修正。
3. 同期が長時間止まったままになる、または明細がまとめて読み込めなくなる問題を修正。
4. 一部のカテゴリ・タグ・振替の変更が同期されない、端末によって表示が違う問題を修正。

## 2026-09-15 v1.0.2（25）

### 修正

1. 分割した明細の金額が、タグ集計とエクスポートで重複計上される問題を修正。
2. 定期記帳が設定した終了日を過ぎても記帳が続く問題を修正。
3. サブカテゴリを他のカテゴリへ移動した後、他の端末に同期されない問題を修正。
4. 明細一覧のスクロールと画面戻りの安定性を改善。
5. 一部の韓国語の文言を修正。

## 2026-09-10 v1.0.1（24）

### 修正

1. 明細のインポート - データプレビュー画面で明細を削除する際のカクつきを修正。

## 2026-09-02 v1.0.0（23）

### 追加機能

1. 明細の一括編集に対応。

## 2026-05-22 v1.0.0

### 追加機能

1. 明細のインポート：テンプレート／WeChat／Alipay／Pixiu／iCost に対応。
2. 複数の帳簿の管理と切り替えに対応。
3. 本位通貨と為替レート表示の切り替えに対応。
4. クラウドバックアップと同期に対応。
5. 明細の分割、返金、精算、定期記帳に対応。
6. 統計チャート、FAQ、ヘルプドキュメントに対応。
