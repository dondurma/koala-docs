# 업데이트 기록

> 이 페이지는 코알라 가계부의 각 출시 버전에서 변경된 내용을 기록합니다. 최신 버전을 위에 두고(내림차순) 관리합니다.

## 2026-09-26 v1.0.7 (31)

### 수정

1. 정산으로 넣은 내역이 저절로 사라지던 문제 수정. 기기 변경이나 재설치 후에도 그대로 남아 있습니다.
2. 다른 계정으로 로그인한 뒤 이전 계정의 실패 항목이 동기화에 남아 있던 문제 수정.
3. 동기화가 오랫동안 멈춰 있거나 내역이 한꺼번에 불러와지지 않던 문제 수정.
4. 일부 카테고리·태그·이체 변경 사항이 동기화되지 않거나 기기마다 다르게 보이던 문제 수정.

## 2026-09-15 v1.0.2 (25)

### 수정

1. 분할한 내역의 금액이 태그 통계 및 내보내기에서 중복 합산되는 문제 수정.
2. 정기 기장이 설정한 종료일 이후에도 계속 기장되는 문제 수정.
3. 하위 카테고리를 다른 카테고리로 이동한 후 다른 기기에서 동기화되지 않는 문제 수정.
4. 내역 목록 스크롤 및 페이지 뒤로 가기 안정성 개선.
5. 일부 한국어 문구 수정.
