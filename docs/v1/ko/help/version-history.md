# 업데이트 기록

> 이 페이지는 코알라 가계부의 각 출시 버전에서 변경된 내용을 기록합니다. 최신 버전을 위에 두고(내림차순) 관리합니다.

## 2026-10-28 v1.1.3 (36)

### 추가 기능

1. '평생 회원'을 추가했습니다. 멤버십 해제 화면에서 월간·연간·평생 중 선택할 수 있고, 멤버십 페이지에서 바로 업그레이드할 수도 있습니다. 평생 회원은 한 번 구매하면 계속 유효합니다.
2. 멤버십 페이지에 '오퍼 코드 사용'을 추가했습니다. 코드만 있으면 바로 멤버십을 활성화할 수 있습니다.
3. 계좌의 이체 기록을 월별로 볼 수 있으며, 이전 달·다음 달 전환과 '이번 달로' 이동을 지원합니다.
4. 크라프트지 테마의 스위치를 레트로 대괄호 스타일로 바꿔 종이 느낌과 더 잘 어울립니다.

### 수정

1. 내역 분할에서 '완료'를 연속으로 눌러도 중복 분할되지 않으며, 항목이 하나뿐일 때는 저장되지 않아 원본 내역이 바뀌지 않습니다.
2. 특정 계좌의 데이터에 문제가 있어도 다른 계좌와 이체는 계속 동기화되고, 동기화 상태에서 건너뛴 개수도 확인할 수 있습니다.
3. 동기화는 성공했는데도 계속 '미동기화'로 표시되고 반복 재시도되던 문제를 수정했습니다.
4. 내역·이체·계좌를 삭제한 뒤 다른 기기에서 잔액이나 관련 데이터가 남거나 두 번 차감되지 않습니다.
5. 내역을 추가할 때의 기본 날짜가 보고 있는 날짜를 따라가며, 과거 달에 기록해도 바로 표시됩니다.
6. 멤버십 구매 후 상태 확인에 실패해도 화면이 멈추지 않고 '회원 상태 동기화 중'을 안내한 뒤 돌아갑니다. 로그인하지 않은 상태에서는 구매 단계로 넘어가지 않습니다.
7. 다크 모드에서 대화상자 배경과 버튼 모서리를 통일해 어색함을 줄였습니다.
8. 설정 화면과 기장 화면의 일부 스위치 행이 옆 행보다 높아지지 않으며, 행 전체를 눌러도 전환됩니다.
9. 계좌 내역·이체 기록을 불러오지 못하면 안내를 표시하고, 눌러서 다시 시도할 수 있습니다.
10. 내역 검색에서 빠르게 연속 입력해도 이전 검색 결과가 새 결과를 덮어쓰지 않습니다.

## 2026-10-14 v1.1.2 (34)

### 추가 기능

1. 계좌 아이콘 커스터마이즈 지원: 계좌를 만들거나 수정할 때 아이콘을 고르거나 이모지를 직접 입력할 수 있습니다.
2. '키패드 진동' 스위치 추가: 숫자 키패드를 누르면 살짝 진동합니다(설정에서 언제든 끌 수 있습니다). 키를 가볍게 눌러도 눌림 효과가 표시됩니다.
3. 프로필 카드 배경 리뉴얼: '성긴 가지 / 무성한 잎 / 빈 편지지 / 매트 클레이 / 크라프트지 / 라이트 우드' 등을 추가하고 '없음'도 선택할 수 있습니다.

### 수정

1. 내역 수정 시 '정산 가능' 태그를 직접 해제할 수 있습니다.
2. 정산 입금이 이미 생성된 내역에서는 '정산 가능' 태그를 해제하려 하면 해제할 수 없다는 안내가 표시됩니다(기록 불일치 방지).

## 2026-10-12 v1.1.1 (33)

### 추가 기능

1. 그리드 기장에서 하위 카테고리를 선택하면 아이콘이 계산기로 날아가는 효과를 추가했습니다. 조작이 더 직관적입니다.

### 수정

1. 두 기기에서 동시에 정산을 기록할 때 입금된 내역이 중복되거나 어긋날 수 있던 문제를 수정했습니다.
2. 라인 모드에서 대분류를 전환한 뒤 오른쪽 하위 카테고리가 이전 분류에 그대로 남던 문제를 수정했습니다.
3. 통화·환율 화면에서 언어를 바꾸면 그룹 표시가 뒤섞이던 문제를 수정했습니다.
4. Apple 로그인 중 프로필 카드가 잠시 비어 보이던 문제를 수정했습니다. 이제 '로그인 중…'을 표시합니다.
5. 수입/지출 선택기의 불필요한 '자주 사용' 항목을 제거해 카테고리 목록이 더 깔끔해졌습니다.
6. 일부 화면 문구를 수정했습니다.
7. 계정을 삭제한 뒤 다시 들어왔을 때 하단 내비게이션 버튼이 반응하지 않던 문제를 수정했습니다.

## 2026-10-05 v1.1.0 (32)

### 추가 기능

1. '크라프트지' 테마 추가. 빈티지한 종이 질감으로 앱 전체 분위기가 한층 살아납니다.
2. 레트로 폰트와 모서리 크기 설정을 추가해, 원하는 스타일로 바로 바꿀 수 있습니다.
3. 여러 가지 카드 배경을 추가해 프로필 화면을 마음대로 꾸밀 수 있습니다.
4. '내역 영수증' 추가. 내역을 한 번에 예쁜 영수증으로 만들어 공유할 수 있습니다.
5. 사용 안내를 보강하고, 여러 화면의 제목 표시줄에 '?' 도움말 입구를 추가했습니다.
6. 항목이 사용 빈도순으로 정렬되어 자주 쓰는 항목이 위에 표시됩니다.
7. 동기화 상태가 더 직관적으로 바뀌어, 아직 동기화되지 않은 데이터가 있으면 알려 줍니다.
8. 앱 아이콘을 업데이트했습니다.

### 수정

1. 내역 가져오기 분석 속도를 대폭 개선했습니다. 큰 파일도 오래 기다리지 않습니다.
2. 일부 화면 표시와 문구의 세부 사항을 수정했습니다.

## 2026-09-26 v1.0.7 (31)

### 수정

1. 정산으로 넣은 내역이 저절로 사라지던 문제 수정. 기기 변경이나 재설치 후에도 그대로 남아 있습니다.
2. 다른 계정으로 로그인한 뒤 이전 계정의 실패 항목이 동기화에 남아 있던 문제 수정.
3. 동기화가 오랫동안 멈춰 있거나 내역이 한꺼번에 불러와지지 않던 문제 수정.
4. 일부 카테고리·태그·이체 변경 사항이 동기화되지 않거나 기기마다 다르게 보이던 문제 수정.
