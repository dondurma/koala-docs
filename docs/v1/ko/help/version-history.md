# 업데이트 기록

> 이 페이지는 코알라 가계부의 각 출시 버전에서 변경된 내용을 기록합니다. 최신 버전을 위에 두고(내림차순) 관리합니다.

## 2026-11-23 v1.2.1 (40)

### 추가 기능

1. 예산 관리를 추가했습니다. 월 예산과 카테고리 예산, 개요 페이지의 진행 막대(눌러서 같은 달 예산 페이지로 이동), 이월과 초과분 다음 달 차감, 3단계 색상 변경을 지원하고, 카테고리 예산을 누르면 해당 카테고리의 이번 달 내역을 볼 수 있습니다. 멤버십 기능입니다.
2. 예산은 계정과 함께 여러 기기로 동기화되어, 휴대폰을 바꿔도 그대로 이어서 쓸 수 있습니다.
3. 출장용 「출장 장부」를 추가했습니다. 수입/지출 카테고리는 출장 상황에 맞게 미리 준비되어 있습니다.
4. 수입/지출 항목 관리의 하위 카테고리와 자산 페이지의 계정을 길게 눌러 순서를 바꿀 수 있으며, 기록 화면도 새 순서로 표시됩니다.
5. App Store에 새 버전이 있으면 한 번 알려 드리고, 눌러서 바로 업데이트할 수 있습니다.
6. 설정에 「다른 앱」을 추가했습니다.

### 수정

1. 개요 페이지에서 수입과 지출 화살표 방향이 반대로 표시되던 문제를 수정했습니다.
2. 브랜드 색상 선택 화면에서 눌러도 반응이 없던 문제를 수정했습니다. 함께 4개 색상 선택 화면(브랜드·기분·수입/지출·예산)의 색상 견본 스타일을 통일했습니다.
3. 카테고리를 삭제해도 해당 카테고리의 예산이 이름 없는 빈 줄로 남지 않습니다.
4. 예산 페이지의 진행 막대가 한 줄을 가득 채우고, 카테고리 금액도 오른쪽에 정렬됩니다.
5. 예산 변경은 앱을 다시 열거나, 앞으로 돌아오거나, 개요 페이지에 머무는 동안 자동으로 동기화됩니다. 이제 직접 동기화할 필요가 없습니다.

5. 홍콩 번체 중국어 표기를 현지 표현('設定', '輔助使用', '捷徑' 등)으로 통일했습니다.

### 수정

1. 오퍼 코드 사용 또는 일부 기기에서 구매 후 멤버십이 활성화되지 않던 문제를 수정했습니다.
2. 내역이나 계정을 삭제한 뒤 관련 환불·정산 기록이 남거나 잔액이 더 많이 계산되지 않습니다.
3. 기기를 바꾸거나 다시 설치한 뒤 분할한 내역의 부모-자식 관계가 사라지고, 자식 내역을 삭제해도 부모가 남던 문제를 수정했습니다.
4. 환불·정산된 내역을 다시 조작할 때 안내가 표시되지 않거나, 정산 기록이 다른 날짜·계정에 있을 때 태그 행이 사라지던 문제를 수정했습니다.
5. iOS 위젯이 일부 OS에서 충돌할 수 있던 문제를 수정했습니다.
6. 아이콘 선택의 '전화' 이름이 올바르게 표시됩니다.

## 2026-11-03 v1.1.4 (37)

### 추가 기능

4. 앱 안에서 도움말을 열 때 웹사이트 상단 내비게이션이 중복으로 표시되지 않아 더 편하게 읽을 수 있습니다.

3. 다중 통화 회원 안내를 닫은 뒤 '통화 업데이트 실패'가 잘못 표시되지 않습니다.
4. 크라프트지 테마에서 레트로 글꼴을 끄면 스위치가 일반 스타일로 돌아갑니다(모두 레트로 대괄호가 되지 않습니다).
5. 내역 가져오기 후 표시되는 성공 건수가 정확해져, 건너뛴 기록이 성공으로 집계되지 않습니다.

## 2026-10-28 v1.1.3 (36)

### 추가 기능

1. '평생 회원'을 추가했습니다. 멤버십 해제 화면에서 월간·연간·평생 중 선택할 수 있고, 멤버십 페이지에서 바로 업그레이드할 수도 있습니다. 평생 회원은 한 번 구매하면 계속 유효합니다.
2. 멤버십 페이지에 '오퍼 코드 사용'을 추가했습니다. 코드만 있으면 바로 멤버십을 활성화할 수 있습니다.
3. 계좌의 이체 기록을 월별로 볼 수 있으며, 이전 달·다음 달 전환과 '이번 달로' 이동을 지원합니다.
4. 크라프트지 테마의 스위치를 레트로 대괄호 스타일로 바꿔 종이 느낌과 더 잘 어울립니다.

### 수정

1. 내역 분할에서 '완료'를 연속으로 눌러도 중복 분할되지 않으며, 항목이 하나뿐일 때는 저장되지 않아 원본 내역이 바뀌지 않습니다.
2. 특정 계좌의 데이터에 문제가 있어도 다른 계좌와 이체는 계속 동기화되고, 동기화 상태에서 건너뛴 개수도 확인할 수 있습니다.
3. 동기화는 성공했는데도 계속 '미동기화'로 표시되고 반복 재시도되던 문제를 수정했습니다.
4. 내역·이체·계좌를 삭제한 뒤 다른 기기에서 잔액이나 관련 데이터가 남거나 두 번 차감되지 않습니다.
5. 내역을 추가할 때의 기본 날짜가 보고 있는 날짜를 따라가며, 과거 달에 기록해도 바로 표시됩니다.
6. 멤버십 구매 후 상태 확인에 실패해도 화면이 멈추지 않고 '회원 상태 동기화 중'을 안내한 뒤 돌아갑니다. 로그인하지 않은 상태에서는 구매 단계로 넘어가지 않습니다.
7. 다크 모드에서 대화상자 배경과 버튼 모서리를 통일해 어색함을 줄였습니다.
8. 설정 화면과 기장 화면의 일부 스위치 행이 옆 행보다 높아지지 않으며, 행 전체를 눌러도 전환됩니다.
9. 계좌 내역·이체 기록을 불러오지 못하면 안내를 표시하고, 눌러서 다시 시도할 수 있습니다.
10. 내역 검색에서 빠르게 연속 입력해도 이전 검색 결과가 새 결과를 덮어쓰지 않습니다.
