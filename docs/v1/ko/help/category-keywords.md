## 키워드 사용법

「키워드」는 수입/지출 항목의 별칭 또는 동의어로, 기장할 때 원하는 항목을 더 빠르게 찾도록 도와줍니다.

- 「수입/지출 항목 편집 페이지」에서 항목에 키워드를 입력하세요. 여러 키워드는 세로줄 `|`로 구분합니다(예: `아침|조식|모닝`).
- **추가** 페이지 상단의 **검색창**에 입력하면 항목 이름, 다른 언어 번역명, 입력한 키워드를 함께 검색합니다.
- **리스트** 모드와 **아이콘** 모드 두 가지 추가 페이지에서 모두 사용할 수 있습니다.

> 💡 예: 「식비 / 아침」에 키워드 「조식|모닝」을 입력하면, 추가 페이지 검색창에 「조식」만 입력해도 바로 찾을 수 있습니다.
