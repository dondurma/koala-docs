# 계정 삭제 안내

계정을 삭제하면 해당 계정의 클라우드 및 현재 기기 내 모든 데이터가 삭제됩니다. 진행하기 전에 아래 내용을 반드시 확인해 주세요.

## 어떤 일이 발생하나요

- 클라우드 데이터: 해당 계정의 클라우드 동기화 데이터가 모두 삭제됩니다(장부, 거래/내역, 카테고리, 태그 등 포함).
- 로컬 데이터: 현재 기기에 저장된 해당 계정의 로컬 데이터가 모두 삭제됩니다(오프라인 데이터 포함).
- 되돌릴 수 없음: 삭제가 완료되면 데이터를 복구할 수 없습니다.

## 구독(멤버십)은 영향이 있나요

계정 삭제는 구독 유효 기간에 영향을 주지 않습니다.

유료 구독 중이라면, 계정 삭제 후 다시 로그인한 다음 앱에서 “구매 복원”을 눌러 멤버십 상태를 복원할 수 있습니다(App Store / Google Play의 구독 상태 기준).

## 권장 사항

- 데이터를 보관해야 한다면, 삭제 전에 앱에서 내보내기/백업을 먼저 진행해 주세요(제공되는 경우).
- 삭제 후 재로그인은 새로운 환경으로 간주되며, 다시 동기화/가져오기가 필요할 수 있습니다.
