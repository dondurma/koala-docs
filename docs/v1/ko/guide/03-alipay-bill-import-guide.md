# Alipay 내역 가져오기

## 📋 개요

이 가이드는 Alipay에서 거래 내역을 내보낸 다음, 코알라 가계부로 가져오는 방법을 안내합니다.

---

## 📱 1단계: Alipay에서 내역 내보내기

### 단계 1: 내역(账单) 화면 열기

1. Alipay 앱을 엽니다
2. 하단의 **我的**를 탭합니다
3. **账单**을 탭해 내역 화면으로 이동합니다

> 📝 참고: Alipay 버전에 따라 메뉴 위치가 다를 수 있습니다. 찾기 어렵다면 Alipay 검색창에서 “账单”을 검색해 보세요.

### 단계 2: 내보내기 시작

1. 내역 화면 오른쪽 위 **...**를 탭합니다
2. **开具交易流水证明** 또는 **账单导出**(표기 다를 수 있음)를 선택합니다
3. **用户个人对帐**를 선택하고 **申请**를 탭합니다

### 단계 3: 범위/수신 방법 선택

1. 거래 유형: **全部交易** / **收入** / **支出**
2. 기간(예: 최근 1개월/최근 3개월)
3. 수신 방법: **支付宝** / **邮箱**

> 💡 팁:
> - 한 번에 3개월 이내로 내보내는 것을 권장합니다(파일이 커지면 처리 속도가 느려질 수 있습니다).
> - 이메일로 받는 경우, Alipay에서 이메일 주소를 설정해야 할 수 있습니다.

### 단계 4: 기기에 파일 저장

1. 이메일로 받은 경우:
   - 이메일 앱에서 Alipay 메일을 찾습니다
   - 첨부파일(CSV)을 다운로드합니다
   - 파일 관리자에서 접근 가능한 위치에 저장합니다
2. “파일에 저장”이 가능한 경우:
   - 다운로드 폴더 등에 저장합니다
   - 저장 위치를 기억해 둡니다

---

## 📱 2단계: 코알라 가계부로 가져오기

### 단계 1: 가져오기 화면 열기

1. 코알라 가계부 앱을 엽니다
2. 하단의 **설정**을 탭합니다
3. **내역 가져오기**를 찾아 들어갑니다

### 단계 2: 가져오기 소스 선택

1. **가져오기 소스**를 탭합니다
2. **Alipay**를 선택합니다

> ⚠️ 중요: 반드시 Alipay를 선택해야 합니다. 소스를 잘못 선택하면 파일을 제대로 파싱할 수 없습니다.

### 단계 3: 파일 선택

1. **파일 경로**를 탭합니다
2. Alipay에서 내보낸 CSV(`.csv`)를 선택합니다
3. 파일명이 표시되는지 확인합니다

### 단계 4: 장부 연결

1. **장부 연결**을 탭합니다
2. 가져올 장부를 선택합니다

### 단계 5: 파싱 → 미리보기 → 가져오기

1. 우측 상단의 **파싱**을 탭합니다
2. 미리보기 화면에서 내역을 확인하고 필요 시 카테고리/계정/메모 등을 수정합니다
3. **가져오기**를 탭합니다

## 📋 Alipay CSV 열(참고)

Alipay CSV에는 보통 아래와 같은 열이 포함됩니다.

| 열 이름(내보내기 표기) | 의미 | 예시 |
|------|------|------|
| 交易时间 | 거래 시간 | 2024-01-01 12:00:00 |
| 交易分类 | 분류 | 餐饮美食/日用百货 |
| 交易对方 | 상대방 | 张三 / 商户名称 |
| 对方账号 | 상대 계정 | xxx@163.com |
| 商品说明 | 내용 | 午餐 / 购物等 |
| 收/支 | 수입/지출 | 收入 / 支出 |
| 金额 | 금액 | 100.00 |
| 收/付款方式 | 결제 수단/계정 | 余额宝 |
| 交易状态 | 상태 | 交易成功 / 已退款 |
| 交易订单号 | 거래 주문 번호 | 20240101... |
| 商家订单号 | 가맹점 주문 번호 | 1234567890 |
| 备注 | 메모 | 备注内容 |

## ⚠️ 유의사항

### 1. 파일 형식 요구사항

- **파일 인코딩**: UTF-8 인코딩 권장(Alipay 내보내기는 보통 UTF-8 또는 GBK)
- **파일 형식**: CSV(`.csv`)만 지원
- **파일 크기**: 파일당 10MB 이하 권장

### 2. 데이터 매핑

Alipay 내역의 열은 아래와 같이 코알라 가계부 필드로 자동 매핑됩니다:

- 交易時間(CSV 열1 / row[0]) → 내역 시간 (날짜만, yyyy-MM-dd)
- 交易分類(열2 / row[1]) → 부모/자식 카테고리 (동일 이름)
- 交易對方(열3 / row[2]) → 내역 메모 ("交易对方:xxx" 추가, 헤더명은 원본 따름)
- 對方帳號(열4 / row[3]) → 내역 메모 ("对方账号:xxx" 추가)
- 商品說明(열5 / row[4]) → 내역 메모 ("商品说明:xxx" 추가)
- 收/支(열6 / row[5]) → 내역 유형 (수입/지출)
- 金額(열7 / row[6]) → 내역 금액
- 收/付款方式(열8 / row[7]) → 계정 이름 (이름으로 조회, 없으면 생성 후 저장)
- 交易狀態(열9 / row[8]) → 내역 메모 ("交易状态:xxx" 추가)
- 交易訂單號(열10 / row[9]) → 내역 메모 ("交易订单号:xxx" 추가)
- 商家訂單號(열11 / row[10]) → 내역 메모 ("商家订单号:xxx" 추가)
- 備註(열12 / row[11]) → 내역 메모 (원본 메모; "/" 또는 비어 있으면 무시, 위 항목과 합침)

### 3. 카테고리 매칭

- 시스템이 카테고리를 자동 매칭하지만, 완벽하지 않을 수 있습니다
- 미리보기 화면에서 카테고리가 맞는지 확인하세요
- 필요 시 수동으로 카테고리를 수정할 수 있습니다

### 4. 계정 매칭

- 시스템이 "거래 출처" 등의 정보를 바탕으로 계정을 매칭합니다
- 계정이 없으면 자동으로 생성됩니다
- 가져오기 전에 자주 쓰는 계정을 미리 만들어 두는 것을 권장합니다

### 5. 중복 데이터 처리

- 기존 내역과 중복으로 판단되는 항목(거래 번호 기준)은 자동으로 건너뜁니다
- 가져오기 전에 중복 데이터가 없는지 확인하는 것을 권장합니다

### 6. 환불 처리

- 내역에 환불 건이 포함된 경우 시스템이 자동으로 인식하여 처리합니다
- 환불 건은 보통 "已退款" 또는 "退款成功"로 표시됩니다
- 미리보기 화면에서 환불 건이 올바르게 처리되었는지 확인하세요

## 🔧 자주 묻는 질문

### Q1: "导出账单" 메뉴를 찾을 수 없어요.

가능한 이유:

1. Alipay 버전이 오래되어 내보내기 미지원
2. 메뉴 위치가 다름:
   - 내역 화면 우측 상단 **...** 확인
   - **我的** 화면에서 **账单** 찾기
   - Alipay 검색창에서 "账单导出" 검색

### Q2: 이메일이 오지 않아요.

확인:

1. Alipay에 이메일 주소가 연결되어 있는지
2. 이메일 주소가 올바른지
3. 스팸함/정크함
4. 가능하다면 "파일에 저장" 방식으로 재시도

### Q3: 파싱에 실패해요.

확인:

1. 파일 형식(CSV)이 맞는지
2. 가져오기 소스가 Alipay인지
3. 파일이 손상되지 않았는지
4. 인코딩(UTF-8 또는 GBK 권장)

### Q4: 가져온 뒤 카테고리가 맞지 않아요.

정상적인 현상입니다. 이유:

1. Alipay의 카테고리와 코알라 가계부의 카테고리가 완전히 일치하지 않을 수 있습니다
2. 시스템이 자동으로 매칭하지만, 항상 정확하지는 않습니다
3. 미리보기 화면에서 수동으로 카테고리를 조정하거나, 가져온 뒤 일괄 수정하세요

### Q5: 이미지를 가져올 수 있나요?

현재 지원하지 않습니다. Alipay 내역에는 이미지 정보가 포함되어 있지 않으며, 가져온 뒤에도 이미지를 추가할 수 없습니다.

### Q6: 얼마나 오래된 데이터까지 가져올 수 있나요?

이론적으로 제한은 없지만, 다음을 권장합니다:

1. 한 번에 3개월 이내의 데이터를 가져오세요
2. 데이터 양이 많으면 여러 번 나눠서 가져오세요
3. 가져오는 동안 앱을 포그라운드로 유지하세요

### Q7: CSV 형식만 지원하는 이유는 뭔가요?

Alipay는 현재 CSV 형식만 내보내기 지원합니다. 향후 Excel 형식이 추가되면 빠르게 대응하겠습니다.

## 💡 사용 팁

1. **주기적으로 가져오기**: 월 1회 등 주기적으로 가져오면 데이터 동기화가 편합니다
2. **카테고리 정리**: 가져온 뒤 카테고리를 정리하면 통계가 더 정확해집니다
3. **계정 관리**: 가져오기 전에 자주 쓰는 계정을 미리 만들어 두면 자동 생성되는 계정명이 깔끔해집니다
4. **데이터 백업**: 가져오기 전에 기존 데이터를 백업해 두면 안전합니다
5. **환불 확인**: 가져온 뒤 환불 건이 올바르게 처리되었는지 꼭 확인하세요
