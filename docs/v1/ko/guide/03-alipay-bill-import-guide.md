# Alipay 내역 가져오기

## 📋 개요

이 가이드는 Alipay에서 거래 내역을 내보낸 다음, 코알라 가계부로 가져오는 방법을 안내합니다.

---

## 📱 1단계: Alipay에서 내역 내보내기

### 단계 1: 내역(账单) 화면 열기

1. Alipay 앱을 엽니다
2. 하단의 **我的**를 탭합니다
3. **账单**을 탭해 내역 화면으로 이동합니다

> 📝 참고: Alipay 버전에 따라 메뉴 위치가 다를 수 있습니다. 찾기 어렵다면 Alipay 검색창에서 “账单”을 검색해 보세요.

### 단계 2: 내보내기 시작

1. 내역 화면 오른쪽 위 **...**를 탭합니다
2. **开具交易流水证明** 또는 **账单导出**(표기 다를 수 있음)를 선택합니다
3. **用户个人对帐**를 선택하고 **申请**를 탭합니다

### 단계 3: 범위/수신 방법 선택

1. 거래 유형: **全部交易** / **收入** / **支出**
2. 기간(예: 최근 1개월/최근 3개월)
3. 수신 방법: **支付宝** / **邮箱**

> 💡 팁:
> - 한 번에 3개월 이내로 내보내는 것을 권장합니다(파일이 커지면 처리 속도가 느려질 수 있습니다).
> - 이메일로 받는 경우, Alipay에서 이메일 주소를 설정해야 할 수 있습니다.

### 단계 4: 기기에 파일 저장

1. 이메일로 받은 경우:
   - 이메일 앱에서 Alipay 메일을 찾습니다
   - 첨부파일(CSV)을 다운로드합니다
   - 파일 관리자에서 접근 가능한 위치에 저장합니다
2. “파일에 저장”이 가능한 경우:
   - 다운로드 폴더 등에 저장합니다
   - 저장 위치를 기억해 둡니다

---

## 📱 2단계: 코알라 가계부로 가져오기

### 단계 1: 가져오기 화면 열기

1. 코알라 가계부 앱을 엽니다
2. 하단의 **설정**을 탭합니다
3. **내역 가져오기**를 찾아 들어갑니다

### 단계 2: 가져오기 소스 선택

1. **가져오기 소스**를 탭합니다
2. **Alipay**를 선택합니다

> ⚠️ 중요: 반드시 Alipay를 선택해야 합니다. 소스를 잘못 선택하면 파일을 제대로 파싱할 수 없습니다.

### 단계 3: 파일 선택

1. **파일 경로**를 탭합니다
2. Alipay에서 내보낸 CSV(`.csv`)를 선택합니다
3. 파일명이 표시되는지 확인합니다

### 단계 4: 장부 연결

1. **장부 연결**을 탭합니다
2. 가져올 장부를 선택합니다

### 단계 5: 파싱 → 미리보기 → 가져오기

1. 우측 상단의 **파싱**을 탭합니다
2. 미리보기 화면에서 내역을 확인하고 필요 시 카테고리/계정/메모 등을 수정합니다
3. **가져오기**를 탭합니다

## 📋 Alipay CSV 열(참고)

Alipay CSV에는 보통 아래와 같은 열이 포함됩니다.

| 열 이름(내보내기 표기) | 의미 | 예시 |
|------|------|------|
| 交易时间 | 거래 시간 | 2024-01-01 12:00:00 |
| 交易分类 | 분류 | 餐饮美食/日用百货 |
| 交易对方 | 상대방 | 张三 / 商户名称 |
| 对方账号 | 상대 계정 | xxx@163.com |
| 商品说明 | 내용 | 午餐 / 购物等 |
| 收/支 | 수입/지출 | 收入 / 支出 |
| 金额 | 금액 | 100.00 |
| 收/付款方式 | 결제 수단/계정 | 余额宝 |
| 交易状态 | 상태 | 交易成功 / 已退款 |
| 交易订单号 | 거래 주문 번호 | 20240101... |
| 商家订单号 | 가맹점 주문 번호 | 1234567890 |
| 备注 | 메모 | 备注内容 |

## ⚠️ 유의사항

1. **CSV만 지원**: Alipay는 현재 CSV 내보내기만 지원합니다.
2. **중복/환불**: 중복으로 판단되는 항목은 건너뛰어질 수 있으며, 환불 항목은 미리보기에서 확인해 주세요.
3. **파일을 임의로 수정하지 마세요**: 헤더 변경, 열 삭제/추가 등은 파싱 실패의 흔한 원인입니다.
