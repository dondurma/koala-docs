# Alipay 내역 가져오기

## 📋 개요

Alipay에서 내역을 내보낸 뒤 Koala로 가져오는 방법입니다.

## 📤 Alipay 내보내기(요약)

Alipay → **我的** → **账单** → 우측 상단 `...` → **账单导出/开具交易流水证明** → **用户个人对帐** → 기간 선택 → CSV 저장.

## 📥 Koala 가져오기

1. Koala → **설정** → **내역 가져오기**
2. 가져오기 소스: **Alipay**
3. 내보낸 `.csv` 선택
4. 장부 선택 → **파싱** → 미리보기 → **가져오기**

⚠️ CSV의 헤더/열을 변경하면 파싱 실패가 발생할 수 있습니다.
