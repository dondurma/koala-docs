# 환불 안내

## 1. 어떤 기능인가요?

‘환불’은 거래가 환불되었을 때의 자금 흐름을 기록하고, 통계에서 해당 금액 영향이 자동으로 상쇄되도록 하기 위한 기능입니다.

코알라 가계부는 원거래를 기준으로 '음수 금액'의 환불 기록을 추가로 생성합니다.

- 원거래가 지출이면: 환불 기록도 ‘지출’이지만 금액이 음수로 저장되어 원 지출을 상쇄합니다
- 원거래가 수입이면: 환불 기록도 ‘수입’이지만 금액이 음수로 저장되어 원 수입을 상쇄합니다

또한 환불 기록에는 자동으로 ‘환불’ 태그가 붙어, 나중에 필터링/확인이 쉽습니다.

## 2. 이런 경우에 유용해요

- 구매 환불/반품 환불
- 부분 환불
- 수입 회수(예: 이체 취소, 입금 반송)

## 3. 사용 방법

1. 거래 목록에서 환불할 거래를 찾습니다
2. 해당 거래를 왼쪽으로 스와이프한 뒤 **환불**을 선택합니다
3. 환불 화면에서 설정합니다:
   - 금액: 기본값은 원거래 금액이며, 부분 환불이면 변경할 수 있습니다
   - 날짜: 기본값은 오늘이며, 필요 시 실제 환불 날짜로 변경합니다
   - 태그: 원거래 태그를 유지하고 **환불** 태그가 자동으로 추가됩니다
   - 메모: 선택 사항
4. **확인/완료**를 눌러 저장합니다

저장하면 목록에 환불 기록이 추가되어 해당 금액 영향이 상쇄됩니다.

## 4. 규칙 및 주의사항

- 환불 금액은 ‘실제로 돌려받은 금액’을 입력하면 됩니다. 마이너스 기호를 직접 입력할 필요는 없습니다.
- 지출 환불/수입 환불 모두 ‘음수 금액’으로 기록되므로 통계에서 자동으로 상쇄됩니다.
- 여러 번 환불도 가능합니다. 같은 거래가 여러 번에 나뉘어 환불되면, 환불할 때마다 환불 기록이 1건씩 생성됩니다.
- 환불 기록을 삭제하면 상쇄 효과도 사라져 통계가 환불 전 상태로 돌아갑니다.

## 5. 자주 묻는 질문

### Q1. 부분 환불은 어떻게 기록하나요?

환불 화면에서 금액을 실제 환불 금액으로 변경하면 됩니다. 여러 번에 나눠 환불하는 것도 가능합니다.

### Q2. 환불하면 원거래가 바뀌나요?

원거래 금액은 수정되지 않습니다. 환불은 ‘환불 기록을 추가로 생성’하는 방식이라 원래 소비 기록을 보존하면서도 통계를 설명 가능하고 추적 가능하게 유지할 수 있습니다.

### Q3. 환불만 모아서 볼 수 있나요?

환불 기록에는 자동으로 ‘환불’ 태그가 붙으므로, 태그로 필터/검색해 확인할 수 있습니다.
