# 정산 안내(지출 정산)

## 1. 어떤 기능인가요?

‘정산’은 먼저 지출을 기록한 뒤, 이후 회사나 다른 사람에게서 비용을 돌려받는 상황(예: 출장비, 사무용품, 선지출/대납 비용 등)을 관리하기 위한 기능입니다.

Koala의 정산 핵심 로직은 다음과 같습니다.

- 먼저 **지출**을 기록하고, 해당 거래를 **정산 대상**으로 표시합니다
- 정산이 완료되면, 시스템이 자동으로 **정산 입금(수입)** 거래를 생성해 사용자가 선택한 계정으로 금액을 다시 더해 줍니다

이 방식의 장점:

- 원 지출이 그대로 남아 사용 목적을 추적하기 쉽습니다
- 정산으로 들어온 입금도 별도로 기록되어, 실제 입금 계정/날짜를 확인하기 쉽습니다
- 통계가 명확해집니다(지출과 정산 입금을 분리 기록)

## 2. 이런 경우에 유용해요

- 회사 정산(교통, 숙박, 식비, 사무용품 등)
- 누군가 대신 결제해 준 뒤 나중에 송금으로 돌려받는 경우
- 선지출한 비용을 추후 회수해야 하는 경우

## 3. 사용 방법

### 3.1 정산 대상 지출 만들기

1. 새 지출 거래를 생성합니다
2. 생성/편집 화면에서 **정산**(또는 ‘정산 대상/정산 대기’와 유사한 옵션)을 선택합니다
3. 저장하면 목록에서 **정산 대기/정산 완료** 등의 상태가 표시됩니다

### 3.2 지출을 정산하기

1. 거래 목록에서 **정산 대기** 상태의 지출을 찾습니다
2. 해당 거래를 왼쪽으로 스와이프한 뒤 **정산**을 선택합니다
3. 정산 화면에서 설정합니다:
   - 금액: 기본값은 원 지출 금액이며, 필요 시 실제 정산 금액으로 변경할 수 있습니다
   - 날짜: 기본값은 오늘이며, 필요 시 실제 입금 날짜로 변경합니다
   - 입금 계정: 정산금이 실제로 들어온 계정을 선택합니다
   - 메모: 선택 사항
4. **완료/저장**을 누릅니다

저장하면 **정산 입금(수입)** 거래가 추가되어, 정산금을 기록할 수 있습니다.

## 4. 규칙 및 주의사항

- **지출**이면서 **정산 대상**으로 표시된 거래만 정산할 수 있습니다.
- 거래 분할과 정산은 상호 배타적입니다. 이미 분할된 거래(하위 거래/분할 컨테이너 포함)는 정산 절차를 시작할 수 없고, 정산 대상으로 표시한 지출도 분할할 수 없습니다. 먼저 정산이 필요한지 결정하고, 필요하다면 비용을 먼저 나눈 뒤 정산이 필요한 부분은 별도의 정산 대상 지출로 기록하는 것을 권장합니다.
- 한 번 **정산 입금**이 생성된 지출은 기본적으로 다시 정산할 수 없습니다(중복 입금 방지).
- **정산 입금** 거래를 삭제하면 원 지출이 **정산 대기** 상태로 돌아가 다시 정산할 수 있습니다.
- 정산 입금은 수입 통계에 포함되고, 원 지출은 지출 통계에 그대로 포함됩니다. 현금 흐름을 명확히 하기 위한 정책입니다.

## 5. 자주 묻는 질문

### Q1. 정산과 환불은 무엇이 다른가요?

- 환불: 거래가 취소/반환되어 원거래 영향이 상쇄되는 경우(음수 금액 기록 추가)
- 정산: 정산 대상 지출에 대해 이후 입금을 받는 경우(정산 입금 수입 거래 추가)

### Q2. 정산금이 다른 계정으로 들어왔어요

정산 화면에서 **입금 계정**을 실제 입금 계정으로 변경하면 됩니다.

### Q3. 일부 금액만 정산되었어요

정산 금액을 실제 정산 금액으로 변경하면 됩니다. 미정산 금액은 원 지출에 남아 이후 확인과 추가 정산에 도움이 됩니다.
