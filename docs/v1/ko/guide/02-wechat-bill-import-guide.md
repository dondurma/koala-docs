# WeChat 내역 가져오기

## 📋 개요

WeChat에서 내역을 내보낸 뒤 Koala로 가져오는 방법입니다.

## 📤 WeChat 내보내기(요약)

WeChat → **我** → **服务/支付** → **钱包** → **账单** → **下载账单** → 기간 선택 → 파일 저장.

> 💡 팁: 한 번에 3개월 이내로 내보내면 파일이 더 다루기 쉽습니다.

## 📥 Koala 가져오기

1. Koala → **설정** → **내역 가져오기**
2. 가져오기 소스: **WeChat**
3. 파일 선택(`.csv` / `.xlsx` / `.xls`)
4. 장부 선택 → **파싱** → 미리보기 → **가져오기**

⚠️ 내보낸 파일의 헤더/열을 수동으로 수정하면 파싱에 실패할 수 있습니다.
