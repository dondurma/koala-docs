# WeChat 내역 가져오기

## 📋 개요

이 가이드는 WeChat에서 거래 내역을 내보낸 다음, 코알라 가계부로 가져오는 방법을 안내합니다.

---

## 📱 1단계: WeChat에서 내역 내보내기

### 단계 1: 내역(账单) 화면 열기

1. WeChat 앱을 엽니다
2. 오른쪽 아래 **我** 탭을 누릅니다
3. **服务**(또는 **支付**)를 누릅니다
4. 오른쪽 위 **钱包** 아이콘을 누릅니다
5. 오른쪽 위 **账单**을 눌러 내역 화면으로 이동합니다

> 📝 참고: WeChat 버전에 따라 메뉴 위치가 조금 다를 수 있습니다. 찾기 어렵다면 WeChat 검색창에서 “账单”을 검색해 보세요.

### 단계 2: 내역 파일 다운로드

1. 내역 화면에서 오른쪽 위 **...** 또는 **筛选**을 누릅니다
2. 아래로 뜨는 메뉴에서 **下载账单**을 누릅니다
3. **用于个人对账**을 선택합니다
4. 수신 방법(**WeChat** 또는 **이메일**)을 선택하고 확인합니다
5. 기간(예: 최근 1개월/최근 3개월)을 선택하고 확인합니다

> 💡 팁:
> - 한 번에 3개월 이내로 내보내는 것을 권장합니다(파일이 커지면 처리 속도가 느려질 수 있습니다).
> - 더 긴 기간이 필요하면 여러 번 나눠서 내보낸 뒤 파일을 하나씩 가져오세요.

### 단계 3: 필요 시 인증 진행

1. 선택을 완료한 뒤 **下一步**를 누릅니다
2. WeChat 안내에 따라 인증을 완료합니다
3. WeChat이 파일을 생성할 때까지 잠시 기다립니다

> ⚠️ 중요:
> - 내보내기가 완료되면 WeChat이 이메일 또는 WeChat으로 파일을 전달합니다.
> - 이메일로 받는 경우, WeChat에서 이메일 주소를 먼저 설정해야 할 수 있습니다.

### 단계 4: 기기에 파일 저장

1. 이메일로 받은 경우:
   - 이메일 앱에서 WeChat이 보낸 메일을 찾습니다
   - 첨부파일(CSV 또는 Excel)을 다운로드합니다
   - 파일 관리자에서 접근 가능한 위치에 저장합니다
2. “파일에 저장”이 가능한 경우:
   - 다운로드 폴더 등에 저장합니다
   - 저장 위치를 기억해 둡니다

> 📝 저장 위치 힌트:
> - iOS: 파일 앱의 “다운로드”
> - Android: “다운로드” 폴더 또는 WeChat 폴더

---

## 📱 2단계: 코알라 가계부로 가져오기

### 단계 1: 가져오기 화면 열기

1. 코알라 가계부 앱을 엽니다
2. 하단의 **설정**을 탭합니다
3. **내역 가져오기**를 찾아 들어갑니다

### 단계 2: 가져오기 소스 선택

1. **가져오기 소스**를 탭합니다
2. 목록에서 **WeChat**을 선택합니다

> ⚠️ 중요: 반드시 WeChat을 선택해야 합니다. 소스를 잘못 선택하면 파일을 제대로 파싱할 수 없습니다.

### 단계 3: 파일 선택

1. **파일 경로**를 탭합니다
2. WeChat에서 내보낸 파일을 선택합니다
3. 파일명이 표시되는지 확인합니다

> 📝 지원 형식:
> - CSV (`.csv`)
> - Excel (`.xlsx`, `.xls`)

### 단계 4: 장부 연결

1. **장부 연결**을 탭합니다
2. 가져올 장부를 선택합니다

> 💡 팁: 장부가 1개만 있는 경우 기본 장부로 자동 연결될 수 있습니다.

### 단계 5: 파싱

1. 우측 상단의 **파싱**을 탭합니다
2. 파싱이 완료되면 미리보기 화면으로 이동합니다

> ⚠️ 파싱 실패 시:
> - 파일 형식이 맞는지 확인하세요
> - 가져오기 소스가 WeChat인지 확인하세요
> - 파일이 손상되었는지 확인하세요
> - WeChat에서 다시 내보낸 파일로 재시도해 보세요

### 단계 6: 미리보기 및 수정

미리보기 화면에서:

- 날짜별로 묶인 내역을 확인할 수 있습니다
- 단건 편집(카테고리, 금액, 시간, 계정, 태그, 메모 등)이 가능합니다
- 잘못된 항목은 길게 눌러 삭제할 수 있습니다
- 유효하지 않은 항목은 일괄로 건너뛸 수 있습니다

### 단계 7: 가져오기 실행

1. 내용이 맞는지 확인한 뒤 **가져오기**를 탭합니다
2. 완료될 때까지 기다립니다

## 📋 WeChat 내역 파일 열(참고)

WeChat CSV에는 보통 아래와 같은 열이 포함됩니다.

| 열 이름(내보내기 표기) | 의미 | 예시 |
|------|------|------|
| 交易时间 | 거래 시간 | 2024-01-01 12:00:00 |
| 交易类型 | 거래 유형 | 微信红包 / 转账 / 消费等 |
| 交易对方 | 상대방 | 张三 / 商户名称 |
| 商品 | 상품/내용 | 午餐 / 购物等 |
| 收/支 | 수입/지출 | 收入 / 支出 |
| 金额(元) | 금액 | 100.00 |
| 支付方式 | 결제 수단 | 零钱 / 银行卡 |
| 当前状态 | 상태 | 支付成功/已转账/已到账 |
| 交易单号 | 거래 번호 | 4200001234567890 |
| 商户单号 | 가맹점 번호 | 1234567890 |
| 备注 | 메모 | 备注内容 |

Excel 내보내기도 열 이름과 내용은 같고, 파일 형식만 다릅니다.

## ⚠️ 유의사항

### 1. 파일 형식 요구사항

- **파일 인코딩**: UTF-8 인코딩 권장(WeChat 내보내기는 보통 UTF-8)
- **파일 형식**: CSV 및 Excel 지원
- **파일 크기**: 파일당 10MB 이하 권장

### 2. 데이터 매핑

WeChat 내역의 열은 아래와 같이 코알라 가계부 필드로 자동 매핑됩니다:

- 交易時間(row[0]) → **내역 날짜** (날짜 문자열 변환)
- 交易類型(row[4], "지출/수입" 포함) → **내역 유형** (지출/수입)
- 交易分類(row[1] 대분류, row[3] 소분류) → 대분류/소분류 카테고리
- 金額(row[5]) → **내역 금액**
- 收/付款方式(row[6]) → **계정** (이름으로 조회/생성)
- 交易對方(row[2])、當前狀態(row[7])、交易單號(row[8])、商戶單號(row[9])、備註(row[10]) → **내역 메모** (합침)

### 3. 카테고리 매칭

- 시스템이 카테고리를 자동 매칭하지만, 완벽하지 않을 수 있습니다
- 미리보기 화면에서 카테고리가 맞는지 확인하세요
- 필요 시 수동으로 카테고리를 수정할 수 있습니다

### 4. 계정 매칭

- 시스템이 "결제 수단"을 바탕으로 계정을 매칭합니다
- 계정이 없으면 자동으로 생성됩니다
- 가져오기 전에 자주 쓰는 계정을 미리 만들어 두는 것을 권장합니다

### 5. 중복 데이터 처리

- 가져오기 전에 중복 데이터가 없는지 확인하는 것을 권장합니다

### 6. 파일을 임의로 수정하지 마세요

WeChat에서 내보낸 파일은 헤더 변경, 열 삭제, 열 추가 등을 하지 마세요. 파싱 실패의 가장 흔한 원인입니다.

## 🔧 자주 묻는 질문

### Q1: “下载账单”을 찾을 수 없어요.

가능한 이유:

1. WeChat 버전이 오래됨
2. 메뉴 위치가 다름

다음도 시도해 보세요:

- 내역 화면 우측 상단 **...** 확인
- Wallet(钱包)에서 **账单** 찾기
- WeChat 검색창에서 “账单导出” 검색

### Q2: 이메일이 오지 않아요.

확인:

1. WeChat에 이메일 주소가 연결되어 있는지
2. 이메일 주소가 올바른지
3. 스팸함/정크함
4. 가능하다면 “파일에 저장” 방식으로 재시도

### Q3: 파싱에 실패해요.

확인:

1. 파일 형식(CSV/Excel)
2. 가져오기 소스가 WeChat인지
3. 파일이 손상되지 않았는지
4. 인코딩(UTF-8 권장)

### Q4: 가져온 뒤 카테고리가 맞지 않아요.

정상적인 현상입니다. 이유:

1. WeChat의 카테고리와 코알라 가계부의 카테고리가 완전히 일치하지 않을 수 있습니다
2. 시스템이 자동으로 매칭하지만, 항상 정확하지는 않습니다
3. 미리보기 화면에서 수동으로 카테고리를 조정하거나, 가져온 뒤 일괄 수정하세요

### Q5: 이미지를 가져올 수 있나요?

현재 지원하지 않습니다. WeChat 내역에는 이미지 정보가 포함되어 있지 않으며, 가져온 뒤에도 이미지를 추가할 수 없습니다.

### Q6: 얼마나 오래된 데이터까지 가져올 수 있나요?

이론적으로 제한은 없지만, 다음을 권장합니다:

1. 한 번에 3개월 이내의 데이터를 가져오세요
2. 데이터 양이 많으면 여러 번 나눠서 가져오세요
3. 가져오는 동안 앱을 포그라운드로 유지하세요

---

## 💡 팁

1. 월 1회 등 주기적으로 가져오면 관리가 편합니다
2. 가져온 뒤 카테고리를 정리하면 통계가 더 정확해집니다
3. 자주 쓰는 계정은 미리 만들어 두면 자동 생성되는 계정명이 깔끔해집니다
4. 가져오기 전에 백업을 권장합니다
