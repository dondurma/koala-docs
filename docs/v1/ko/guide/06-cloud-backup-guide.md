# 클라우드 백업 및 동기화

## 📋 개요

클라우드 백업을 사용하면 같은 계정으로 로그인한 여러 기기에서 데이터를 동기화할 수 있습니다.

---

## ☁️ 클라우드 백업이란?

클라우드 백업은 데이터를 서버에 보관해 다음을 가능하게 합니다.

- 기기 분실/고장 대비
- 여러 기기 간 동기화
- 새 기기에서 로그인 후 동기화로 데이터 복원

> 💡 팁:
> - 클라우드 백업을 사용하려면 로그인이 필요합니다.
> - 계정 단위로 데이터가 분리되며, 본인만 접근할 수 있도록 처리됩니다.

## 🔐 로그인

현재는 Apple 로그인을 지원합니다. 설정 화면 상단의 사용자 카드에서 로그인할 수 있습니다.

---

## 🔄 동기화 시점

- 자동 동기화: 앱 실행 시, 데이터 변경 후, 장부 전환 시 등
- 수동 동기화: 설정 화면 우측 상단의 구름 아이콘

> ⚠️ 참고: 수동 동기화 중에는 앱을 전면에 두는 것을 권장합니다.

## 📊 동기화되는 항목

동기화: 장부, 내역, 계정, 분류, 태그  
미동기화: 앱 설정(테마/언어), 캐시, 개인 설정

---

## 📌 동기화 상태(개요)

데이터는 보통 다음 상태로 관리됩니다.

- 동기화 완료
- 동기화 대기(변경됨)
- 삭제 대기(삭제됨)

---

## 🔄 충돌(동시 수정) 처리

여러 기기에서 같은 데이터를 수정한 경우, Koala는 가능한 한 최신 변경을 유지하면서도 아직 업로드되지 않은 로컬 변경이 덮어쓰여지지 않도록 처리합니다.
