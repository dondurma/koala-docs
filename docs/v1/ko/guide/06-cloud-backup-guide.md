# 클라우드 백업 및 동기화

## 📋 개요

클라우드 백업을 사용하면 같은 계정으로 로그인한 여러 기기에서 데이터를 동기화할 수 있습니다.

## 🔐 로그인

현재는 Apple 로그인을 지원합니다. 설정 화면 상단의 사용자 카드에서 로그인할 수 있습니다.

## 🔄 동기화 시점

- 자동 동기화: 앱 실행 시, 데이터 변경 후, 장부 전환 시 등
- 수동 동기화: 설정 화면 우측 상단의 구름 아이콘

## 📊 동기화되는 항목

동기화: 장부, 내역, 계정, 분류, 태그  
미동기화: 앱 설정(테마/언어), 캐시, 개인 설정
