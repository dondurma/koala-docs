# 클라우드 백업 안내

## 📋 개요

코알라 가계부는 클라우드 백업 기능을 제공하여 내역 데이터를 안전하게 클라우드에 백업하고 여러 기기 간에 동기화할 수 있습니다. 본 가이드에서는 클라우드 백업 기능의 사용 방법을 안내합니다.

---

## ☁️ 클라우드 백업이란?

**클라우드 백업**은 내역 데이터를 클라우드 서버에 업로드하여 다음을 가능하게 합니다.

- **데이터 안전**: 기기 분실 또는 파손으로 인한 데이터 유실 방지
- **다중 기기 동기화**: 다른 기기에서 같은 계정으로 로그인하면 데이터가 자동으로 동기화
- **데이터 복원**: 언제든지 클라우드에서 새 기기로 데이터를 복원

> 💡 **팁**:
> - 클라우드 백업을 사용하려면 로그인이 필요합니다(현재 Apple 계정 로그인 지원)
> - 클라우드에서는 접근 제어와 데이터 격리가 이루어지며, 로그인한 계정의 사용자만 자신의 데이터에 접근할 수 있습니다
> - 대부분의 경우 자동으로 동기화되며, 설정 화면에서 수동으로 동기화를 트리거할 수도 있습니다

---

## 🔐 계정 로그인

### Apple 계정으로 로그인

1. 코알라 가계부 앱을 엽니다
2. 하단 내비게이션 바에서 **"설정"** 아이콘을 탭합니다
3. 설정 화면 상단에서 사용자 정보 카드를 탭합니다
4. 로그인하지 않은 경우 로그인 옵션이 표시됩니다
5. **"Apple 계정으로 로그인"**을 탭합니다
6. 안내에 따라 Apple 계정 로그인 절차를 완료합니다

> 📝 **참고**:
> - 로그인 후 데이터가 자동으로 클라우드에 동기화되기 시작합니다
> - 첫 로그인 시 초기 동기화에 시간이 소요될 수 있습니다
> - 네트워크 연결이 정상인지 확인하세요

---

## 🔄 클라우드 동기화 메커니즘

### 자동 동기화

시스템은 다음과 같은 시점에 자동으로 데이터를 동기화합니다.

- **앱 실행 시**: 계정 및 장부 데이터를 자동으로 동기화
- **데이터 변경 후**: 내역을 생성, 수정, 삭제한 후 자동으로 동기화 대기로 표시
- **장부 전환 시**: 현재 장부의 데이터(내역, 카테고리, 태그 등)를 조용히 동기화

> 💡 **팁**:
> - 자동 동기화는 백그라운드에서 이루어지며 정상적인 사용에 영향을 주지 않습니다
> - 네트워크를 사용할 수 없는 경우 데이터가 로컬에 임시 저장되며, 네트워크 복구 후 자동으로 동기화됩니다

### 수동 동기화

수동으로 동기화를 트리거할 수도 있습니다.

1. 코알라 가계부 앱을 엽니다
2. 하단 내비게이션 바에서 **"설정"** 아이콘을 탭합니다
3. 설정 화면 우측 상단에서 클라우드 동기화 아이콘(구름 아이콘)을 탭합니다
4. 동기화가 완료될 때까지 기다립니다(동기화 진행 상태가 표시됩니다)

> ⚠️ **참고**:
> - 수동 동기화는 로그인이 필요합니다
> - 로그인하지 않은 경우 "먼저 로그인한 후 클라우드 동기화를 진행하세요"라는 안내가 표시됩니다
> - 동기화 중에는 앱을 포그라운드에서 실행 상태로 유지하세요

## 📊 동기화 대상

### 동기화되는 데이터 유형

클라우드 백업은 다음과 같은 데이터를 동기화합니다.

- **장부 데이터**: 장부 이름, 설명, 통화, 아이콘 등
- **내역 데이터**: 모든 내역 기록(금액, 카테고리, 태그, 메모 등 포함)
- **계정 데이터**: 계정 이름, 잔액, 유형 등
- **카테고리 데이터**: 지출 및 수입 카테고리
- **태그 데이터**: 태그 그룹 및 태그

### 동기화되지 않는 데이터

다음 데이터는 클라우드에 동기화되지 않습니다.

- **앱 설정**: 테마, 언어 등 로컬 설정
- **캐시 데이터**: 임시 캐시 데이터
- **사용자 설정**: 개인 환경 설정

## 🔒 데이터 보안

### 데이터 보호

- **접근 제어**: 로그인한 계정의 사용자만 자신의 데이터에 접근할 수 있습니다
- **데이터 격리**: 서로 다른 계정의 데이터는 격리되어 상호 접근이 불가합니다
- **보안 권장사항**: Apple 계정을 안전하게 관리하고, 안정적인 네트워크 환경에서 첫 동기화를 진행하세요

### 데이터 격리

- **사용자 격리**: 각 사용자의 데이터는 완전히 격리되어 상호 접근이 불가합니다
- **기기 격리**: 서로 다른 기기의 데이터는 사용자 계정을 통해 연결됩니다
- **장부 격리**: 서로 다른 장부의 데이터는 독립적으로 저장됩니다

---

## 🔄 동기화 프로세스

### 증분 동기화

코알라 가계부는 증분 동기화 메커니즘을 사용합니다.

- **변경분만 동기화**: 새로 추가, 수정, 삭제된 데이터만 동기화
- **효율성 향상**: 데이터 전송량을 줄여 동기화 속도를 높임
- **데이터 절약**: 특히 모바일 네트워크 환경에 적합

### 동기화 상태

각 데이터에는 동기화 상태가 있습니다.

- **동기화 완료(0)**: 데이터가 클라우드에 성공적으로 동기화됨
- **동기화 대기(1)**: 데이터에 변경이 있어 동기화를 대기 중
- **삭제 대기(2)**: 데이터가 삭제되어 동기화 삭제 작업을 대기 중

### 충돌 처리

여러 기기에서 동시에 같은 데이터를 수정한 경우:

- **로컬 우선**: 아직 업로드되지 않은 로컬 수정이 있는 경우, 시스템은 클라우드 데이터에 덮어쓰이지 않도록 로컬 수정을 우선 보존합니다
- **최신 수정 기준**: 양쪽에서 동시에 같은 데이터를 수정한 경우, 시스템은 가능한 한 가장 최근 수정을 기준으로 처리합니다
- **수동 해결**: 충돌이 발생한 경우 수동으로 해결해야 할 수 있습니다

## 📱 다중 기기 동기화

### 기기 요구사항

- **같은 계정 로그인**: 모든 기기에서 동일한 계정으로 로그인해야 합니다
- **네트워크 연결**: 동기화를 위해 네트워크 연결이 필요합니다
- **앱 버전**: 최신 버전의 앱 사용을 권장합니다

### 동기화 절차

1. **새 기기에서 로그인**:
   - 코알라 가계부 앱을 엽니다
   - 동일한 Apple 계정으로 로그인합니다
   - 시스템이 자동으로 데이터 동기화를 시작합니다

2. **동기화 완료 대기**:
   - 첫 동기화에는 시간이 소요될 수 있습니다
   - 설정 화면에서 동기화 상태를 확인할 수 있습니다
   - 동기화가 완료되면 새 기기에 데이터가 표시됩니다

3. **계속 사용**:
   - 동기화 완료 후 새 기기에서 정상적으로 사용할 수 있습니다
   - 데이터 변경 사항은 자동으로 다른 기기에 동기화됩니다

> 💡 **팁**:
> - 동기화가 완료되기 전에 대량의 작업을 하지 않는 것을 권장합니다
> - 동기화에 실패하면 수동으로 동기화를 트리거할 수 있습니다
> - 모든 기기가 동일한 계정으로 로그인되어 있는지 확인하세요

## 🔧 자주 묻는 질문

### Q1: 클라우드 백업은 유료인가요?

**A:** 현재 클라우드 백업 기능은 무료입니다. 하지만 향후 회원 기능이 도입되어 더 많은 저장 공간이나 고급 기능을 제공할 수 있습니다.

### Q2: 데이터가 얼마나 많은 저장 공간을 차지하나요?

**A:**
- 일반 사용자의 내역 데이터는 보통 매우 작습니다(수 MB~수십 MB)
- 데이터 양이 매우 많은 경우 동기화 속도에 영향을 줄 수 있습니다
- 필요 없는 데이터를 정기적으로 정리하는 것을 권장합니다

### Q3: 클라우드 백업을 비활성화할 수 있나요?

**A:** 가능합니다. 클라우드 백업을 사용하지 않으려면:
- 계정에 로그인하지 않으면 됩니다(데이터는 로컬에만 저장)
- 하지만 이 경우 여러 기기 간 동기화가 불가능합니다
- 데이터 유실 방지도 할 수 없습니다

### Q4: 동기화에 실패하면 어떻게 하나요?

**A:** 다음을 시도해 보세요:
1. 네트워크 연결이 정상인지 확인합니다
2. 계정에 로그인되어 있는지 확인합니다
3. 수동으로 동기화를 트리거합니다
4. 여전히 실패하면 나중에 다시 시도하세요

### Q5: 과거 데이터를 복원할 수 있나요?

**A:**
- 클라우드에 동기화된 데이터는 동일한 계정으로 로그인하면 새 기기에 동기화됩니다
- 기기 데이터가 유실된 경우 클라우드에서 복원할 수 있습니다
- 삭제된 데이터는 일반적으로 앱 내에서 복원할 수 없습니다. 신중하게 진행하세요

### Q6: 동기화가 성능에 영향을 주나요?

**A:**
- 동기화는 백그라운드에서 이루어지며 성능에 눈에 띄는 영향을 주지 않습니다
- 대량의 데이터 동기화에는 시간이 소요될 수 있습니다
- 첫 동기화는 Wi-Fi 환경에서 진행하는 것을 권장합니다

### Q7: 여러 계정에 동기화할 수 있나요?

**A:** 불가능합니다. 각 기기에는 하나의 계정만 로그인할 수 있으며, 데이터는 하나의 계정에만 동기화됩니다.

### Q8: 앱을 삭제하면 데이터가 유실되나요?

**A:**
- 로그인 후 동기화한 경우 데이터가 클라우드에 보존됩니다
- 앱을 다시 설치하고 로그인하면 데이터를 복원할 수 있습니다
- 로그인하지 않은 경우 앱을 삭제하면 로컬 데이터가 유실됩니다

## 💡 사용 팁

1. **정기적 동기화**: 데이터 최신 유지를 위해 정기적으로 수동 동기화를 하는 것을 권장합니다
2. **네트워크 환경**: 첫 동기화는 Wi-Fi 환경에서 진행하는 것을 권장합니다
3. **데이터 백업**: 중요한 데이터는 정기적으로 내보내기 백업(CSV/Excel)을 하는 것을 권장합니다
4. **계정 보안**: 로그인 계정을 안전하게 관리하여 계정 도용을 방지하세요
5. **다중 기기 관리**: 여러 기기를 사용하는 경우 정기적으로 동기화 상태를 확인하세요

---

## ⚠️ 주의사항

1. **로그인 필요**: 클라우드 백업은 로그인이 필요하며, 로그인하지 않으면 사용할 수 없습니다
2. **네트워크 의존**: 동기화는 네트워크 연결이 필요하며, 오프라인 상태에서는 동기화할 수 없습니다
3. **데이터 보안**: 데이터가 암호화되어 있지만, 로그인 계정을 안전하게 관리해야 합니다
4. **동기화 지연**: 동기화에는 지연이 있을 수 있으며, 실시간이 아닙니다
5. **데이터 복원**: 삭제된 데이터는 복원할 수 없습니다. 신중하게 진행하세요
