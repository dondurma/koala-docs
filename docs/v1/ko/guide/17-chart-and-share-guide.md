# 통계 및 공유 안내

## 📋 개요

하단 내비게이션 바의 「통계」 화면은 현재 장부의 수입·지출 통계를 확인하고, 통계 결과나 가계부 리포트를 이미지로 내보내 공유하는 데 사용됩니다.

## 📊 시간 범위 선택

통계 화면 우측 상단의 필터 아이콘을 탭하면 통계의 시간 범위를 선택할 수 있습니다:

- **월별**: 특정 월의 통계 보기
- **연도별**: 특정 연도의 통계 보기
- **사용자 지정**: 직접 지정한 시작/종료 날짜로 통계 보기

> 💡 **팁**: 통계 화면은 **현재 장부**의 데이터만 집계합니다. 장부를 전환하면 통계 결과도 함께 바뀝니다.

## 📤 공유

통계 화면 하단에서 **"현재 화면 공유 >"**를 탭하면 공유 방식 선택이 표시됩니다:

- **현재 화면 공유**: 현재 통계 화면을 캡처해 공유
- **리포트 공유**: 「가계부 리포트」 이미지를 생성해 공유
- **기분 기록**: 기분 히트맵을 생성해 공유(「월별 / 연도별」 범위에서만 사용 가능)

> ⚠️ **참고**:
> - 선택한 시간 범위에 내역 데이터가 없으면 먼저 기록한 뒤 공유하라는 안내가 표시됩니다
> - 공유 이미지는 시스템 공유 패널로 전송하거나 저장하며, 클라우드에 업로드되지 않습니다
> - 「기분 기록」은 내역 통계와 서로 독립적입니다. 자세한 내용은 《기분 기록 안내》를 참고하세요

## 🔧 자주 묻는 질문

### Q1: 공유를 눌러도 반응이 없는 이유는 무엇인가요?

현재 시간 범위에 내역 데이터가 없으면 먼저 기록한 뒤 공유하라는 안내가 표시됩니다. 데이터가 있는 시간 범위로 전환하거나 먼저 기록해 주세요.

### Q2: 공유한 가계부 리포트에는 어떤 내용이 포함되나요?

가계부 리포트는 현재 범위의 수입·지출 개요와 주요 지출 항목을 이미지로 보여줍니다. 구체적인 내용은 생성된 미리보기를 기준으로 합니다.

### Q3: 통계 데이터가 내역 목록과 맞지 않습니다.

통계는 현재 장부의 데이터만 집계하며, 분할된 내역은 하위 내역 기준으로 집계됩니다(분할 컨테이너는 포함되지 않음). 현재 장부와 필터 시간 범위 선택을 확인해 주세요.
