# 기분 기록 안내

## 📋 개요

코알라 가계부는 개요 화면에서 「기분 카드」를 제공하여, 기록을 하면서 하루의 기분도 간편하게 남기고 월 보기로 되돌아볼 수 있습니다. 소비와 감정 상태를 함께 살펴보고 싶거나 매일 꾸준히 기록하고 싶은 사용자에게 적합합니다.

---

## 🚀 기분 기록 방법

1. 코알라 가계부 앱을 열고 하단 내비게이션 바의 **"개요"** 화면으로 들어갑니다
2. **"기분 카드"**를 찾습니다(해당 월에 오늘 아직 기록하지 않았다면 카드 하단에 세 가지 선택지가 표시됩니다)
3. **기쁨 / 보통 / 슬픔** 중 하나를 탭하면 오늘의 기분이 기록됩니다

> 📝 **참고**:
> - 하루에 한 번만 기록할 수 있습니다(자연일 기준)
> - 당일 기분을 기록한 뒤에는 그날의 선택지가 더 이상 표시되지 않으며, **앱 안에서 수정하거나 삭제할 수 없습니다**
> - **당일**의 기분만 기록할 수 있고, 과거 날짜를 소급 기록하거나 수정할 수 없습니다

---

## 📅 월 보기 확인

기분 카드는 해당 월의 기록 상황을 보여줍니다:

- 상단에 해당 월의 **기록한 일수 / 전체 일수**와 오늘의 기분을 표시
- 하단에 그리드로 해당 월의 각 날짜를 표시: 기록한 날은 기분에 따라 색이 칠해지고(기쁨 / 보통 / 슬픔 각각 하나의 색), 기록하지 않은 날은 연한 색
- 미래 날짜는 표시하지 않음

> 💡 **팁**: 개요 화면에서 다른 달로 전환하면 카드가 해당 월의 기록 상황을 표시합니다(「오늘」 정보는 표시하지 않음).

---

## 🎨 개인화 설정

**"설정" → "개인화"**에서 기분 관련 항목을 조정할 수 있습니다:

- **기분 카드 표시**: 스위치로 개요 화면에 기분 카드를 표시할지 결정합니다(기본 표시)
- **기분 색상**: 「기쁨 / 보통 / 슬픔」 세 가지 기분에 대응하는 색을 직접 설정합니다

> 📝 **참고**: 기분 색상은 「통계 화면 공유 → 기분 기록」으로 생성되는 히트맵에도 동일하게 적용됩니다.

---

## 📤 기분 기록 공유

1. 하단 내비게이션 바의 **"통계"** 화면을 엽니다
2. 화면 하단에서 **"현재 화면 공유 >"**를 탭합니다
3. 표시된 메뉴에서 **"기분 기록"**을 선택합니다
4. 기분 히트맵이 생성되면 시스템 공유 패널로 전송하거나 저장합니다

> ⚠️ **참고**:
> - 「기분 기록」 공유는 시간 범위가 「월별」 또는 「연도별」일 때만 사용할 수 있습니다(사용자 지정 기간에서는 이 옵션이 표시되지 않습니다)
> - 기분 기록은 내역 데이터와 서로 독립적이며, 내역 통계에 영향을 주지 않습니다

---

## 🔄 여러 기기 동기화

- **계정 로그인 후**: 기분 기록이 계정과 함께 동기화되어, 여러 기기에서 같은 계정으로 로그인하면 동일한 기분 기록을 볼 수 있습니다
- **미로그인 시**: 기분 기록은 기기에만 저장되며, 앱 삭제나 기기 변경 후에는 복원할 수 없습니다

> 📝 기분 기록은 계정에 귀속되어 동기화되며, 장부 데이터와는 서로 독립적입니다.

## 🔧 자주 묻는 질문

### Q1: 기분을 잘못 기록했는데 수정할 수 있나요?

현재 하루에 한 번만 기록할 수 있으며, 기록 후에는 앱 안에서 수정하거나 삭제할 수 없습니다. 기록하기 전에 확인해 주세요.

### Q2: 며칠 전 기분을 소급해서 기록할 수 있나요?

현재는 「당일」의 기분만 기록할 수 있고, 과거 날짜를 소급 기록하거나 수정할 수 없습니다.

### Q3: 개요 화면에서 기분 카드가 보이지 않는 이유는 무엇인가요?

**"설정" → "개인화" → "기분 카드 표시"**가 켜져 있는지 확인해 주세요.

### Q4: 기기를 바꾸면 기분 기록이 남아 있나요?

로그인 후 동기화를 완료한 경우, 재설치 후 같은 계정으로 로그인하면 계정과 함께 복원됩니다. 로그인하지 않은 경우 데이터는 기기에만 있습니다.
