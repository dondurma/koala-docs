# 환율 전환 안내

## 📋 개요

코알라 가계부는 다중 통화 기록을 지원하며, 실시간 환율 조회 및 전환 기능을 제공합니다. 본 가이드에서는 환율 전환, 기준 통화 설정, 환율이 내역 표시에 미치는 영향에 대해 안내합니다.

---

## 💰 기준 통화란?

**기준 통화**는 장부의 주요 통화로, 다음과 같이 사용됩니다.

- **통일된 표시**: 모든 내역 금액이 기준 통화로 환산되어 표시
- **통계 계산**: 개요 및 통계 화면의 데이터가 기준 통화를 기반으로 계산
- **환율 기준**: 환율 목록에서 기준 통화를 기준으로 다른 통화의 환율을 표시

> 💡 **예시**:
> - 기준 통화가 KRW(원)인 경우, 모든 내역 금액이 원으로 표시됩니다
> - 100 USD 내역을 기록하더라도 시스템이 자동으로 원으로 환산하여 표시합니다(예: 139,000 KRW)

---

## 🚀 기준 통화 전환 방법

### 방법 1: 통화 설정 화면에서 전환

1. 코알라 가계부 앱을 엽니다
2. 하단 내비게이션 바에서 **"설정"** 아이콘을 탭합니다
3. 설정 화면에서 **"통화 설정"** 옵션을 찾습니다
4. 통화 설정 화면으로 들어갑니다
5. 화면 상단의 **"기준 통화"** 옵션을 탭합니다
6. 팝업 통화 선택기에서 새 기준 통화를 선택합니다
7. 선택을 확인하면 시스템이 자동으로 다음을 수행합니다:
   - 장부의 기준 통화 설정을 업데이트
   - 최신 환율 데이터를 가져옴
   - 모든 화면의 금액 표시를 새로고침

> ⚠️ **참고**:
> - 기준 통화를 전환하면 모든 내역의 금액 표시에 영향을 줍니다
> - 시스템이 최신 환율에 따라 자동으로 환산합니다
> - 환율 데이터를 사용할 수 없는 경우 오류가 표시될 수 있습니다

### 방법 2: 장부 상세 화면에서 전환

1. 코알라 가계부 앱을 엽니다
2. **"장부 관리"** 화면으로 들어갑니다
3. 수정할 장부 카드 우측 상단의 **"더보기"** 버튼을 탭합니다
4. 장부 상세 화면으로 들어갑니다
5. **"장부 통화"** 옵션을 탭합니다
6. 팝업 통화 선택기에서 새 통화를 선택합니다
7. 선택을 확인하면 시스템이 자동으로 업데이트됩니다

> 📝 **참고**:
> - 장부 통화는 곧 기준 통화입니다
> - 장부 통화를 수정하는 것은 기준 통화를 전환하는 것과 동일합니다
> - 수정 후 해당 장부의 모든 내역 표시에 영향을 줍니다

## 📊 환율 목록 안내

### 환율 목록 보기

통화 설정 화면에서 다음을 할 수 있습니다.

- **모든 통화 보기**: 지원되는 모든 통화를 그룹별로 표시
- **환율 보기**: 각 통화에 대해 기준 통화 대비 환율을 표시
- **환율 새로고침**: 우측 상단의 새로고침 버튼을 탭하여 최신 환율을 가져옴

### 환율 그룹 분류

환율 목록은 다음과 같이 분류됩니다.

- **기준 통화**: 현재 설정된 기준 통화 표시(환율 1.0)
- **주요 통화**: 주요 통화 표시(예: USD, EUR, GBP, JPY 등)
- **알파벳 정렬**: 기타 통화는 첫 글자별로 그룹 표시

### 환율 업데이트

시스템은 다음과 같은 시점에 환율을 업데이트합니다.

- **기준 통화 전환 시**: 최신 환율을 자동으로 가져옴
- **수동 새로고침 시**: 새로고침 버튼을 탭할 때
- **장부 통화 업데이트 시**: 최신 환율을 자동으로 가져와 표시를 새로고침

> 💡 **팁**:
> - 환율 데이터는 서버에서 서드파티 환율 API를 통해 가져옵니다
> - 네트워크를 사용할 수 없는 경우 캐시된 환율 데이터를 사용합니다
> - 환율 정확도를 위해 정기적으로 새로고침하는 것을 권장합니다

## 💱 환율이 내역에 미치는 영향

### 금액 표시

다중 통화 내역을 기록할 때:

1. **거래 통화 선택**: 내역 기록 시 실제 거래 통화를 선택합니다(예: USD)
2. **금액 입력**: 실제 거래 금액을 입력합니다(예: 100 USD)
3. **자동 환산**: 시스템이 현재 환율에 따라 기준 통화로 자동 환산하여 표시합니다(예: 139,000 KRW)

### 통계 계산

모든 통계와 차트 데이터는 기준 통화를 기반으로 합니다.

- **개요 화면**: 기준 통화 기준 총 수입·지출 표시
- **통계 화면**: 차트 데이터가 기준 통화를 기반으로 표시
- **카테고리 통계**: 각 카테고리의 금액이 기준 통화로 환산됨

> 📝 **참고**:
> - 환율이 변경되면 과거 내역의 표시 금액이 달라질 수 있습니다
> - 하지만 원래 거래 금액은 변경되지 않습니다
> - 시스템은 **현재 환율**을 사용하여 환산 표시하므로, 환율을 새로고치면 과거 내역의 환산 표시도 달라질 수 있습니다

## 🔄 환율 캐시 메커니즘

### 캐시 안내

성능 향상을 위해 시스템은 환율 데이터를 캐시합니다.

- **메모리 캐시**: 앱 실행 중 메모리에 캐시
- **데이터베이스 캐시**: 로컬 데이터베이스에 영구 저장
- **캐시 업데이트**: 수동 새로고침 또는 기준 통화/장부 통화를 전환하면 환율이 업데이트되고 이전 캐시가 정리됩니다

### 캐시 삭제

시스템은 다음과 같은 경우에 캐시를 삭제합니다.

- **기준 통화 전환 시**: 모든 환율 캐시를 삭제
- **수동 새로고침 시**: 이전 캐시를 삭제하고 새 데이터를 가져옴
- **장부 통화 업데이트 시**: 해당 장부의 환율 캐시를 삭제

## ⚙️ 환율 설정 옵션

### 환율 수동 수정

특정 상황에서 환율을 수동으로 수정해야 할 수 있습니다.

1. 통화 설정 화면에서 수정할 통화를 찾습니다
2. 통화 항목을 탭하여 환율 설정 화면으로 들어갑니다
3. 환율 값을 수동으로 입력할 수 있습니다
4. 저장하면 해당 환율이 모든 관련 계산에 적용됩니다

> ⚠️ **참고**:
> - 수동으로 수정한 환율은 자동으로 가져온 환율을 덮어씁니다
> - 필요한 경우에만 수동으로 수정하는 것을 권장합니다
> - 수동 수정 후 자동 업데이트 기능이 수정 내용을 덮어쓸 수 있습니다

### 환율 정밀도

시스템은 다음과 같은 환율 정밀도를 지원합니다.

- **표시 정밀도**: 환율 목록에는 일반적으로 여러 자리 소수점이 표시
- **계산 정밀도**: 내부 계산에는 더 높은 정밀도를 사용
- **금액 표시**: 최종 금액은 일반적으로 소수점 이하 2자리까지 표시

## 🔧 자주 묻는 질문

### Q1: 기준 통화를 전환하면 과거 내역 금액이 변하나요?

**A:** 예. 기준 통화를 전환하면:
- 모든 내역 금액이 새 기준 통화에 맞게 다시 환산되어 표시됩니다
- 하지만 원래 거래 금액은 변경되지 않습니다
- 시스템은 **현재 환율**을 사용하여 환산 표시하므로, 기준 통화를 전환하거나 환율을 새로고치면 과거 내역의 환산 표시도 달라질 수 있습니다

### Q2: 환율이 부정확한 경우 어떻게 하나요?

**A:** 다음을 시도해 보세요:
1. 새로고침 버튼을 탭하여 최신 환율을 가져옵니다
2. 네트워크 연결이 정상인지 확인합니다
3. 여전히 부정확한 경우 환율을 수동으로 수정할 수 있습니다

### Q3: 기준 통화를 여러 개 설정할 수 있나요?

**A:** 불가능합니다. 각 장부에는 하나의 기준 통화만 설정할 수 있습니다. 하지만:
- 여러 장부를 만들어 각각 다른 기준 통화를 설정할 수 있습니다
- 다른 장부에서 다른 통화의 거래를 기록할 수 있습니다

### Q4: 환율은 얼마나 자주 업데이트되나요?

**A:**

- 환율 데이터는 서버가 서드파티 API를 대리하여 가져오며, 업데이트 빈도는 서버 정책 및 서드파티 데이터 소스에 따라 달라집니다
- 앱은 기준 통화/장부 통화를 전환하거나 수동으로 새로고침할 때 최신 환율을 가져옵니다
- 네트워크를 사용할 수 없는 경우 캐시된 환율 데이터를 사용합니다

### Q5: 어떤 통화를 지원하나요?

**A:** 코알라 가계부는 전 세계 주요 통화를 지원합니다.
- 주요 통화: KRW, USD, EUR, GBP, JPY, AUD, CAD 등
- 기타 통화: 100종 이상의 통화 지원

### Q6: 환율 데이터의 출처는 무엇인가요?

**A:** 환율 데이터는 서드파티 환율 API에서 가져오며, 서버를 대리하여 조회하여 데이터의 정확성과 안정성을 보장합니다.

### Q7: 기준 통화 전환이 다른 장부에 영향을 주나요?

**A:** 영향을 주지 않습니다. 각 장부는 독립적인 기준 통화 설정을 가지며, 한 장부의 기준 통화를 전환해도 다른 장부에는 영향을 주지 않습니다.

## 💡 사용 팁

1. **적절한 기준 통화 선택**: 주요 거래 통화에 맞게 기준 통화를 선택하면 환산 오차를 줄일 수 있습니다
2. **정기적 환율 새로고침**: 환율 정확도를 위해 정기적으로 환율을 새로고침하는 것을 권장합니다
3. **다중 장부 관리**: 다중 통화를 자주 처리하는 경우 여러 장부를 만들어 각각 다른 기준 통화를 설정하세요
4. **수동 조정**: 자동 환율이 부정확한 경우 수동으로 조정할 수 있지만, 정기적으로 확인하는 것을 권장합니다
5. **데이터 백업**: 중요한 장부는 환율 데이터 유실에 대비해 정기적으로 백업하세요
