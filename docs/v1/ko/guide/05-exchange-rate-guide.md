# 환율

## 📋 개요

Koala는 다중 통화 기록을 지원하며, 환율 조회와 통화 전환 기능을 제공합니다.

## 💰 기준 통화(본위 통화)

장부의 기본 통화로, 금액 표시와 통계 계산의 기준이 됩니다.

## 🚀 변경 방법

- 설정 → 통화 설정 → 기준 통화
- 장부 관리 → 장부 상세 → 장부 통화

## 💱 표시 규칙

환산 표시는 **현재 환율**을 사용합니다. 환율을 새로 고치거나 기준 통화를 바꾸면, 과거 내역의 환산 표시가 달라질 수 있습니다(원거래 금액은 변하지 않습니다).
