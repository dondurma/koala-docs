# 환율

## 📋 개요

코알라 가계부는 다중 통화 기록을 지원하며, 환율 조회와 통화 전환 기능을 제공합니다.

---

## 💰 기준 통화(본위 통화)

장부의 기본 통화로, 금액 표시와 통계 계산의 기준이 됩니다.

사용되는 곳:

- 앱 전반의 금액 표시 기준
- 개요/통계 계산 기준
- 환율 목록에서 기준 통화 대비 환율 표시

## 🚀 변경 방법

- 설정 → 통화 설정 → 기준 통화
- 장부 관리 → 장부 상세 → 장부 통화

변경 후에는 표시/통계가 자동으로 갱신됩니다.

---

## 📊 환율 목록

- 지원 통화 목록을 확인할 수 있습니다
- 기준 통화 대비 환율을 볼 수 있습니다
- 우측 상단의 새로고침 버튼으로 최신 환율을 가져올 수 있습니다

> 💡 팁: 오프라인 상태에서는 최근 환율(캐시)을 사용할 수 있습니다.

## 💱 표시 규칙

환산 표시는 **현재 환율**을 사용합니다. 환율을 새로 고치거나 기준 통화를 바꾸면, 과거 내역의 환산 표시가 달라질 수 있습니다(원거래 금액은 변하지 않습니다).

---

## 🔄 캐시

코알라 가계부는 성능을 위해 환율을 앱 내부에 일시적으로 저장합니다.

- 수동 새로고침, 기준 통화 변경, 장부 통화 변경 시 환율이 갱신됩니다

---

## ⚙️ 환율 수동 수정

일부 경우 환율 설정 화면에서 환율을 직접 입력해 저장할 수 있습니다. 저장한 값은 표시와 계산에 반영됩니다.

---

## 🔧 자주 묻는 질문

### Q1: 기준 통화를 바꾸면 과거 내역 금액이 바뀌나요?

환산 “표시”는 달라질 수 있지만, **원거래 금액은 변하지 않습니다**.

### Q2: 환율이 이상해 보입니다

우측 상단 새로고침 버튼으로 환율을 업데이트해 보세요. 네트워크 환경에 따라 업데이트가 실패할 수 있습니다.
