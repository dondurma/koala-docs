# Pixiu 내역 가져오기

## 📋 개요

Koala는 Pixiu에서 내보낸 내역(CSV)을 가져올 수 있습니다(CSV만 지원).

## 📤 Pixiu 내보내기(요약)

Pixiu의 「我的」에서 데이터 내보내기/내역 내보내기를 찾아 기간을 선택하고 **CSV**로 저장합니다.

## 📥 Koala 가져오기

1. 설정 → 내역 가져오기
2. 가져오기 소스: **Pixiu**
3. CSV 선택 → 장부 선택
4. 파싱 → 미리보기 → 가져오기

## ⚠️ 파일 요구 사항(핵심)

- 1행은 헤더
- 총 10열
- 구분자는 쉼표 `,`
