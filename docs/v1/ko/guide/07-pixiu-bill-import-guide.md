# Pixiu 내역 가져오기

## 📋 개요

이 가이드는 **Pixiu**에서 내보낸 거래 내역(CSV)을 **Koala**로 가져오는 방법을 안내합니다.

Koala는 현재 **Pixiu CSV 내보내기 파일**만 지원합니다(CSV 전용).

---

## 📱 1단계: Pixiu에서 내역 내보내기

Pixiu는 버전에 따라 메뉴명이 조금 다를 수 있지만 흐름은 같습니다. “데이터 내보내기/내역 내보내기”에서 기간을 선택한 뒤 CSV로 저장하세요.

### 단계 1: 내보내기 메뉴 찾기

1. Pixiu 앱을 엽니다
2. **我的**로 이동합니다
3. **数据导出 / 导出账单**(표기 다를 수 있음)을 찾습니다

### 단계 2: 기간 선택

1. 기간(예: 최근 1개월/최근 3개월)을 선택합니다
2. 확인 후 내보내기를 시작합니다

> 💡 팁:
> - 한 번에 3개월 이내로 내보내는 것을 권장합니다(파일이 커지면 파싱이 느려질 수 있습니다).
> - 데이터가 많다면 여러 파일로 나눠서 내보낸 뒤 순서대로 가져오세요.

### 단계 3: CSV로 저장

1. 내보내기 형식은 **CSV**를 선택합니다
2. 파일을 기기에 저장합니다(공유 → 파일에 저장 등)
3. 저장 위치를 기억해 둡니다

---

## 📱 2단계: Koala로 가져오기

### 단계 1: 가져오기 화면 열기

1. Koala 앱을 엽니다
2. 하단의 **설정**을 탭합니다
3. **내역 가져오기**를 찾아 들어갑니다

### 단계 2: 가져오기 소스 선택

1. **가져오기 소스**를 탭합니다
2. **Pixiu**를 선택합니다

> ⚠️ 중요: 반드시 Pixiu를 선택해야 합니다. 소스를 잘못 선택하면 검증이 실패하거나 필드가 잘못 읽힐 수 있습니다.

### 단계 3: 파일 선택

1. **파일 경로**를 탭합니다
2. Pixiu에서 내보낸 **CSV**를 선택합니다
3. 파일명이 표시되는지 확인합니다

### 단계 4: 장부 연결

1. **장부 연결**을 탭합니다
2. 가져올 장부를 선택합니다

### 단계 5: 파싱 및 미리보기

1. 우측 상단의 **파싱**을 탭합니다
2. 파싱 성공 시 미리보기 화면으로 이동합니다
3. 단건 수정/삭제 또는 유효하지 않은 항목 일괄 건너뛰기가 가능합니다

### 단계 6: 가져오기 실행

1. 확인이 끝나면 **가져오기**를 탭합니다
2. 완료될 때까지 기다립니다

## 📋 Pixiu CSV 형식(참고)

Koala는 Pixiu CSV를 아래 기준으로 검증합니다.

- 1행은 헤더여야 합니다
- 헤더 열 수는 **10열**이어야 합니다
- 구분자는 쉼표 `,` 입니다(표준 CSV)

### 열 정의(순서)

| 열 | 의미 | 설명 |
|------|------|------|
| 1 | 날짜 | `yyyy-MM-dd` / `yyyy/MM/dd` 지원. 연도는 2016 이상이어야 하며, 아니면 유효하지 않은 날짜로 처리됩니다 |
| 2 | 상위 분류 | Koala의 상위 카테고리명 매칭에 사용됩니다 |
| 3 | 유형 | “支出”(지출) 또는 “收入”(수입) 키워드를 포함해야 합니다. “收入”이 포함되면 수입으로, 그 외는 지출로 가져옵니다 |
| 4 | 하위 분류 | Koala의 하위 카테고리명 매칭에 사용됩니다 |
| 5 | 유입 금액 | 수입 금액 열(`-` 포함 가능, 가져오기 시 부호는 제거됩니다) |
| 6 | 유출 금액 | 지출 금액 열(`-` 포함 가능, 가져오기 시 부호는 제거됩니다) |
| 7 | 통화 코드 | `CNY` / `USD` 등. 비어 있으면 장부 기본 통화를 사용합니다 |
| 8 | 계정 | 계정명(이름으로 매칭, 없으면 가져오기 중 생성될 수 있음) |
| 9 | 태그 | 여러 태그는 쉼표로 구분(`,`), 중국어 쉼표 `，`도 지원 |
| 10 | 메모 | 메모 텍스트 |

### Koala로의 매핑(개요)

- 날짜 → 날짜
- 유형 → 수입/지출
- 상위+하위 분류 → 카테고리(매칭 실패 시 미리보기에서 “미완성”으로 표시됨)
- 유입/유출 금액 → 금액(유형에 따라 참조 열이 결정됨)
- 계정 → 계정
- 태그 → 태그(이름으로 매칭/생성 후 연결)
- 메모 → 메모
- 통화 코드 → 통화(코드로 매칭, 실패 시 장부 통화로 대체)

---

## ⚠️ 유의사항

1. **자동 중복 제거 없음**: 같은 파일을 두 번 가져오면 중복 내역이 생성됩니다. 동일 기간을 반복해서 가져오지 않도록 주의하세요.
2. **카테고리 매칭**: “상위+하위” 이름으로 매칭합니다. 매칭되지 않으면 미리보기에서 수정 후 가져오세요.
3. **계정 유효성**: 계정명이 비어 있거나 기호만 있는 경우 무효로 처리되어 보완이 필요할 수 있습니다.
4. **인코딩**: UTF-8/GBK를 지원합니다. 글자가 깨지면 UTF-8로 다시 내보내거나 인코딩을 변환해 다시 시도하세요.

## 🔧 자주 묻는 질문

### Q1: “헤더 열 수가 맞지 않아요”.

CSV 첫 줄 헤더가 **10열**인지 확인하세요. 흔한 원인:

1. Pixiu에서 내보낸 파일이 아님
2. Excel/WPS에서 편집하면서 구분자가 늘어나 열 수가 바뀜
3. 호환되지 않는 CSV로 저장(예: 세미콜론 구분)

### Q2: 금액이 0이 되거나 이상합니다.

확인:

1. “유형” 열에 “支出/收入” 키워드가 포함되어 있는지(유입/유출 중 어떤 열을 읽을지 결정)
2. 해당 금액 열이 숫자 형식인지(`-`는 허용, 가져오기 시 제거)

### Q3: 카테고리가 매칭되지 않습니다.

미리보기에서 단건으로 올바른 카테고리를 선택해 주세요. 또는 Koala에 Pixiu 내보내기와 같은 이름의 카테고리를 먼저 만든 뒤 다시 파싱하세요.
