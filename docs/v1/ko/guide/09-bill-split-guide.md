# 거래 분할 안내

## 1. 어떤 기능인가요?

한 번의 결제에 여러 용도가 함께 포함될 때(예: ‘마트/장보기’ 한 건에 과일과 생활용품이 함께 포함된 경우), 하나의 거래를 여러 개의 하위 거래로 분할해 카테고리 통계를 더 정확하게 만들 수 있습니다.

분할이 완료되면:

- 여러 개의 '하위 거래'가 생성됩니다(각각 카테고리, 금액, 메모를 가짐).
- 원거래는 ‘분할 컨테이너’로 처리되어 목록 표시와 통계 합산에서 제외됩니다(중복 합산 방지).

## 2. 이런 경우에 유용해요

- 한 번의 결제에 여러 카테고리가 섞여 있는 경우(식비 + 생활용품, 교통 + 주차 등)
- 카테고리별 분석/예산 비교를 더 세밀하게 하고 싶은 경우
- 한 장의 영수증을 여러 카테고리/태그로 나눠 기록하고 싶은 경우

## 3. 사용 방법

1. 거래 목록에서 분할할 거래를 찾습니다
2. 해당 거래를 왼쪽으로 스와이프한 뒤 **분할**을 선택합니다
3. **거래 분할** 화면에서:
   - 각 항목의 **카테고리**를 눌러 카테고리를 선택합니다
   - **금액**을 눌러 각 항목의 금액을 입력합니다
   - 메모는 선택 사항입니다(추가 설명용)
   - 항목이 더 필요하면 **항목 추가**를 누릅니다
4. **남은 배분 금액**이 0인지 확인합니다(하위 항목 합계가 원금액과 일치)
5. 우측 상단의 **완료/저장**을 누릅니다

## 4. 규칙 및 주의사항

- 하위 항목 금액의 합계는 원거래 금액과 같아야 하며, 그렇지 않으면 저장할 수 없습니다.
- 각 하위 항목은 카테고리 선택이 필요하며, 금액은 0보다 커야 합니다.
- 통계는 하위 거래를 기준으로 계산되며, 원거래는 통계에 포함되지 않습니다.
- 다단계 분할을 지원합니다. 하위 거래도 다시 분할할 수 있으며, 최종 통계는 마지막 단계(리프) 하위 거래를 기준으로 계산됩니다.
- 거래 분할과 정산(报销)은 상호 배타적입니다. 정산 대상/정산 완료 상태의 지출은 분할할 수 없고, 이미 분할된 거래(하위 거래/분할 컨테이너 포함)는 정산 절차를 시작할 수 없습니다. 먼저 정산이 필요한지 결정한 뒤 분할 여부를 선택하세요.

## 5. 자주 묻는 질문

### Q1. 분할 후 원거래는 어디로 가나요?

중복 합산을 방지하기 위해 원거래는 ‘분할 컨테이너’로 표시되며, 보통 목록에 노출되지 않습니다. 통계는 하위 거래를 기준으로 계산됩니다.

### Q2. 일부만 분할할 수도 있나요?

가능합니다. 한 줄을 '기타/원 카테고리'로 남겨 두고, 금액을 남은 금액으로 입력하면 됩니다. 핵심은 하위 항목의 합계가 원금액과 일치해야 한다는 점입니다.

### Q3. 분할 후에도 수정할 수 있나요?

보통은 하위 거래(금액/카테고리/메모 등)를 직접 수정하는 것을 권장합니다. 다시 분할해야 한다면, 관련 하위 거래를 삭제한 뒤 재분할하는 방식이 일반적입니다.
