# iCost 내역 가져오기

## 📋 개요

이 가이드는 **iCost**에서 내보낸 내역을 **Koala**로 가져오는 방법을 안내합니다.

Koala는 현재 **iCost Excel 내보내기 파일**(`.xlsx` / `.xls`)을 지원하며, **iCost CSV 파일은 지원하지 않습니다**.

---

## 📱 1단계: iCost에서 내역 내보내기

iCost는 버전에 따라 메뉴명이 조금 다를 수 있지만 흐름은 같습니다. “내보내기/데이터 내보내기”에서 Excel 형식으로 저장하세요.

### 단계 1: 내보내기 메뉴 찾기

1. iCost 앱을 엽니다
2. **설정 / 더보기**(또는 “我的”의 설정)로 이동합니다
3. **导出 / 数据导出 / 导出账单**(표기 다를 수 있음)을 찾습니다

### 단계 2: Excel로 내보내기

1. 내보내기 형식: **Excel(.xlsx / .xls)** 선택
2. 기간 선택(권장: 한 번에 3개월 이내)
3. 내보내기 후 기기에 저장(공유 → 파일에 저장 등)

> ⚠️ 중요: CSV로 내보내면 Koala에서 “CSV는 지원하지 않습니다. Excel을 사용해 주세요”라고 안내됩니다.

---

## 📱 2단계: Koala로 가져오기

### 단계 1: 가져오기 화면 열기

1. Koala 앱을 엽니다
2. 하단의 **설정**을 탭합니다
3. **내역 가져오기**를 찾아 들어갑니다

### 단계 2: 가져오기 소스 선택

1. **가져오기 소스**를 탭합니다
2. **iCost**를 선택합니다

> ⚠️ 중요: 반드시 iCost를 선택해야 합니다. 다른 소스로 파싱하면 헤더를 찾지 못하거나 열이 어긋날 수 있습니다.

### 단계 3: 파일 선택

1. **파일 경로**를 탭합니다
2. iCost에서 내보낸 Excel(`.xlsx` / `.xls`)을 선택합니다
3. 파일명이 표시되는지 확인합니다

### 단계 4: 장부 연결

1. **장부 연결**을 탭합니다
2. 가져올 장부를 선택합니다

### 단계 5: 파싱 및 미리보기

1. 우측 상단의 **파싱**을 탭합니다
2. 파싱 성공 시 미리보기 화면으로 이동합니다
3. 미리보기에서 카테고리/계정/시간/금액/태그/메모 등을 수정한 뒤 가져올 수 있습니다

### 단계 6: 가져오기 실행

1. 확인이 끝나면 **가져오기**를 탭합니다
2. 완료될 때까지 기다립니다

## 📋 iCost Excel 형식(참고)

Koala의 검증 기준:

- 읽을 수 있는 워크시트가 있어야 합니다
- 헤더 행에 **“日期”**가 포함되어 있어야 합니다(헤더 행을 찾는 기준)

> 📝 팁: iCost 내보내기에서 언어를 선택할 수 있다면 중국어 헤더로 내보내는 것을 권장합니다(최소한 “日期”를 포함).

### 읽는 열(열 위치 기준)

Koala는 iCost Excel의 일부 열을 “열 위치”로 읽고, 나머지는 무시합니다.

| 열 | 필드 | 설명 |
|------|------|------|
| 1 | 날짜 | `yyyy-MM-dd` / `yyyy/MM/dd` / `yyyy-MM-ddTHH:mm:ss` / `yyyy-MM-dd HH:mm:ss`, Excel 시리얼 날짜 지원 |
| 2 | 유형 | “支出”(지출) 또는 “收入”(수입) 키워드를 포함해야 합니다 |
| 3 | 금액 | `+`/`-` 허용, 가져오기 시 부호 제거 및 천 단위 구분자 `,` 처리 |
| 4 | 상위 분류 | Koala 상위 카테고리명 매칭 |
| 5 | 하위 분류 | 비어 있으면 상위 분류 값을 사용 |
| 6 | 계정 | 비어 있으면 기본 계정으로 대체 |
| 8 | 메모 | 메모 텍스트 |
| 9 | 통화 코드 | `CNY` / `USD` 등, 비어 있거나 매칭 실패 시 장부 통화 사용 |
| 10 | 태그 | 여러 태그는 쉼표로 구분(`,`), 중국어 쉼표 `，`도 지원 |

### Koala로의 매핑(개요)

- 날짜(row[0]) → 날짜
- 유형(row[1]) → 수입/지출
- 금액(row[2]) → 금액
- 상위 분류(row[3]) → 상위 카테고리(매칭/생성)
- 하위 분류(row[4], 비어 있으면 상위 사용) → 하위 카테고리(매칭/생성)
- 계정(row[5], 비어 있으면 기본 계정) → 계정
- 7번째 열(row[6]) → 사용하지 않음
- 메모(row[7]) → 메모
- 통화 코드(row[8]) → 통화(코드로 매칭, 실패 시 장부 통화로 대체)
- 태그(row[9]) → 태그(파싱/생성 후 연결)

## ⚠️ 유의사항

1. **Excel만 지원**: iCost CSV 파일은 가져올 수 없습니다.
2. **자동 중복 제거 없음**: 같은 파일을 두 번 가져오면 중복 내역이 생성됩니다. 동일 기간을 반복해서 가져오지 않도록 주의하세요.
3. **헤더 언어**: 헤더 행에 “日期”가 있어야 합니다. 영어 헤더로 내보내면 헤더를 찾지 못해 실패할 수 있습니다.
4. **계정이 비어 있는 경우**: “계정” 열이 비어 있으면 기본 계정으로 들어갑니다. 미리보기에서 계정을 일괄 수정하거나, iCost에서 계정을 채운 뒤 다시 내보내세요.
5. **카테고리 매칭**: “상위+하위” 이름으로 매칭합니다. 매칭 실패 시 미리보기에서 수정 후 가져오세요.

## 🔧 자주 묻는 질문

### Q1: “iCost 헤더를 찾지 못했습니다”.

흔한 원인:

1. 헤더 행에 “日期”가 없음(예: 영어 헤더로 내보냄)
2. iCost 내보내기 파일이 아니거나, 편집으로 구조가 깨짐
3. Excel이 비어 있거나 워크시트가 없음

iCost에서 다시 내보내고, 중국어 헤더를 우선 선택해 주세요.

### Q2: 계정이 비어 있어서 모두 같은 계정으로 들어갔어요.

“계정” 열이 비어 있을 때의 기본 동작입니다. 미리보기에서 계정을 일괄 수정하거나, iCost에서 계정을 채운 뒤 다시 가져오세요.

### Q3: 카테고리가 매칭되지 않습니다.

미리보기에서 단건으로 올바른 카테고리를 선택해 주세요. 또는 Koala에 iCost 내보내기와 같은 이름의 카테고리를 먼저 만든 뒤 다시 파싱하세요.
