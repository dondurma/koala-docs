# iCost 내역 가져오기

## 📋 개요

Koala는 iCost의 **Excel 내보내기**(`.xlsx` / `.xls`)를 가져올 수 있습니다. iCost의 CSV는 지원하지 않습니다.

## 📤 iCost 내보내기(요약)

iCost 설정/더보기에서 내보내기(데이터 내보내기)를 찾아 형식을 **Excel**로 선택한 뒤 파일을 저장합니다.

## 📥 Koala 가져오기

1. 설정 → 내역 가져오기
2. 가져오기 소스: **iCost**
3. Excel 파일 선택 → 장부 선택
4. 파싱 → 미리보기 → 가져오기

## ⚠️ 참고

- 파싱은 헤더 행에 「日期」가 포함되어 있다고 가정합니다. 내보내기 언어를 선택할 수 있다면 중국어 헤더로 내보내는 것을 권장합니다.
- 같은 파일을 중복으로 가져오면 내역이 중복 생성될 수 있습니다.
