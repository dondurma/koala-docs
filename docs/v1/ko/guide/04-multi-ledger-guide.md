# 다중 장부 기능 안내

## 📋 개요

코알라 가계부는 여러 장부를 생성하여 다양한 유형의 재무 기록을 관리할 수 있습니다. 각 장부는 이름, 통화, 카테고리 등을 독립적으로 설정할 수 있어 다음과 같은 상황에 적합합니다.

- **개인 장부**: 개인 일상 수입·지출 기록
- **가족 장부**: 가족 공동 지출 기록
- **여행 장부**: 여행 기간 중 지출 기록
- **육아 장부**: 육아 관련 지출 기록
- **차량 장부**: 차량 관련 비용 기록
- **리모델링 장부**: 인테리어 프로젝트 지출 기록
- **비즈니스 장부**: 사업 거래 수입·지출 기록

---

## 🚀 빠른 시작

### 새 장부 만들기

1. 코알라 가계부 앱을 엽니다
2. 하단 내비게이션 바에서 **"설정"** 아이콘을 탭합니다
3. 설정 화면에서 **"장부 관리"** 옵션을 찾습니다
4. 장부 관리 화면으로 들어갑니다
5. 우측 상단의 **"+"** 버튼을 탭합니다
6. 장부 정보를 입력합니다:
   - **장부 이름**: 장부 이름을 입력합니다(예: 개인 장부, 가족 장부 등)
   - **장부 설명**: 선택 사항, 장부 설명을 입력합니다
   - **장부 아이콘**: 장부 아이콘을 선택합니다(선택 사항)
   - **장부 통화**: 장부에서 사용할 통화를 선택합니다(예: KRW, USD 등)
7. **"저장"**을 탭하여 생성을 완료합니다

> 💡 **팁**:
> - 장부 이름은 언제든지 수정할 수 있습니다
> - 장부 통화는 장부 상세 화면에서 수정할 수 있습니다
> - 각 장부의 데이터는 독립적이며 서로 영향을 주지 않습니다

### 장부 전환하기

1. 코알라 가계부 앱을 엽니다
2. 하단 내비게이션 바에서 **"설정"** 아이콘을 탭합니다
3. 설정 화면에서 **"장부 관리"** 옵션을 찾습니다
4. 장부 관리 화면으로 들어갑니다
5. 장부 목록에서 전환할 장부를 찾습니다
6. 장부 카드를 탭하면 해당 장부로 전환됩니다

> 📝 **참고**:
> - 장부를 전환하면 모든 화면(개요, 통계, 내역 목록 등)이 해당 장부의 데이터를 표시합니다
> - 장부 전환은 다른 장부의 데이터에 영향을 주지 않습니다
> - 현재 장부는 장부 카드에 표시됩니다

## 📚 장부 관리

### 장부 목록 보기

장부 관리 화면에서 다음을 할 수 있습니다.

- **모든 장부 보기**: 그리드 형태로 모든 장부를 표시
- **장부 정보 보기**: 각 장부 카드에 다음 정보 표시:
  - 장부 아이콘
  - 장부 이름
  - 현재 장부 표시(선택된 경우)
- **빠른 전환**: 장부 카드를 탭하면 전환

### 장부 수정

1. 장부 관리 화면에서 수정할 장부를 찾습니다
2. 장부 카드 우측 상단의 **"더보기"** 버튼(점 세 개 아이콘)을 탭합니다
3. 장부 상세 화면으로 들어갑니다
4. 다음 항목을 수정할 수 있습니다:
   - **장부 이름**: 이름을 탭하여 편집
   - **장부 설명**: 설명을 탭하여 편집
   - **장부 아이콘**: 아이콘을 탭하여 새 아이콘 선택
   - **장부 통화**: 통화를 탭하여 통화 변경
5. 수정이 완료되면 **"저장"**을 탭하여 변경사항을 저장합니다

> ⚠️ **참고**:
> - 장부 통화를 변경하면 모든 내역의 금액 표시가 조정됩니다
> - 장부 생성 시 올바른 통화를 선택하는 것을 권장합니다

### 장부 삭제

1. 장부 관리 화면에서 삭제할 장부를 찾습니다
2. 장부 카드 우측 상단의 **"더보기"** 버튼을 탭합니다
3. 장부 상세 화면으로 들어갑니다
4. **"장부 삭제"** 버튼을 탭합니다
5. 삭제를 확인합니다(삭제 후 복원할 수 없다는 안내가 표시됩니다)

> ⚠️ **경고**:
> - 장부를 삭제하면 해당 장부의 모든 내역 데이터도 함께 삭제됩니다
> - 삭제 후 장부는 기기에서 제거되며, 클라우드 동기화를 사용 중인 경우 이후 동기화 시 클라우드에서도 삭제됩니다
> - 삭제 작업은 앱 내에서 복원할 수 없습니다. 신중하게 진행하세요
> - 삭제 전에 데이터를 백업하는 것을 권장합니다

## 💰 장부 통화 설정

### 장부 통화 설정하기

각 장부는 독립적인 통화를 설정할 수 있으며, 다음 작업이 가능합니다.

1. **생성 시 설정**: 장부를 만들 때 통화를 선택
2. **사후 변경**: 장부 상세 화면에서 통화를 변경

### 통화 변경 안내

장부 통화를 변경하면:

- **환율 자동 업데이트**: 시스템이 최신 환율 데이터를 자동으로 가져옵니다
- **금액 표시 조정**: 모든 내역의 금액이 새 통화에 맞게 표시됩니다
- **환율 캐시 삭제**: 시스템이 이전 환율 캐시를 삭제하여 데이터 정확도를 보장합니다

> 📝 **참고**:
> - 통화를 변경해도 내역의 원래 금액은 변경되지 않습니다
> - 시스템이 환율에 따라 자동으로 환산하여 표시합니다
> - 환율 데이터를 사용할 수 없는 경우 오류가 표시될 수 있습니다

### 다중 통화 지원

코알라 가계부는 다양한 통화를 지원합니다.

- **주요 통화**: KRW(원), USD(달러), EUR(유로), GBP(파운드), JPY(엔) 등
- **기타 통화**: 전 세계 주요 통화 지원

> 💡 **팁**: 장부에서 다중 통화 거래를 처리해야 하는 경우:
> - 하나의 주요 통화를 장부 통화로 설정하세요
> - 거래 기록 시 올바른 거래 통화를 선택하세요
> - 시스템이 장부 통화로 자동 환산하여 표시합니다

## 📊 장부 데이터 격리

### 데이터 독립성

각 장부의 데이터는 완전히 독립적입니다.

- **내역 데이터**: 각 장부에 독립적인 내역 목록
- **카테고리 데이터**: 각 장부에 독립적인 카테고리 설정
- **태그 데이터**: 각 장부에 독립적인 태그 설정
- **통계 데이터**: 각 장부에 독립적인 통계

> 📝 **참고**:
> - 계정 데이터는 기기 단위로 관리되며 모든 장부에서 공유됩니다
> - 즉, 여러 장부에서 동일한 계정을 사용할 수 있습니다

### 장부 전환 시 영향

장부를 전환하면:

- **개요 화면**: 현재 장부의 통계를 표시
- **통계 화면**: 현재 장부의 차트 데이터를 표시
- **내역 목록**: 현재 장부의 내역 기록을 표시
- **계정 목록**: 모든 계정을 표시(장부 공유)

## 🔄 장부 동기화

### 클라우드 동기화 지원

코알라 가계부는 장부의 클라우드 동기화를 지원합니다.

- **다중 기기 동기화**: 다른 기기에서 같은 계정으로 로그인하면 장부 데이터가 자동으로 동기화됩니다
- **증분 동기화**: 변경된 데이터만 동기화하여 효율성을 높입니다
- **충돌 처리**: 여러 기기에서 동시에 수정한 경우, 시스템은 업로드되지 않은 로컬 변경을 우선 보존합니다

### 동기화 시점

장부 데이터는 다음과 같은 시점에 자동으로 동기화됩니다.

- **앱 실행 시**: 장부 목록과 현재 장부 데이터를 자동으로 동기화
- **수동 동기화**: 설정 화면에서 클라우드 동기화 버튼을 탭
- **데이터 변경 후**: 장부를 생성, 수정, 삭제한 후 자동으로 동기화 대기로 표시

> 💡 **팁**:
> - 정기적으로 수동 동기화를 하여 최신 데이터를 유지하는 것을 권장합니다
> - 네트워크가 불안정한 경우 나중에 동기화를 재시도하세요

## 🔧 자주 묻는 질문

### Q1: 장부는 몇 개까지 만들 수 있나요?

**A:** 현재 최대 **50**개까지 만들 수 있지만, 다음을 권장합니다.
- 실제 필요에 따라 생성하고 너무 많이 만들지 마세요
- 각 장부는 저장 공간을 차지합니다
- 장부가 너무 많으면 앱 성능에 영향을 줄 수 있습니다

### Q2: 장부를 삭제할 수 있나요?

**A:** 가능하지만 다음에 유의하세요:
- 장부를 삭제하면 해당 장부의 모든 데이터가 함께 삭제됩니다
- 삭제 후 장부는 기기에서 제거되며, 클라우드 동기화를 사용 중인 경우 이후 동기화 시 클라우드에서도 삭제됩니다
- 삭제 작업은 앱 내에서 복원할 수 없습니다. 신중하게 진행하세요
- 삭제 전에 데이터를 백업하는 것을 권장합니다

### Q3: 장부 데이터가 동기화되나요?

**A:** 예. 계정에 로그인한 경우 장부 데이터가 자동으로 클라우드에 동기화되어 여러 기기에서 동기화할 수 있습니다.

### Q4: 장부 유형을 변경할 수 있나요?

**A:** 현재 장부 유형을 직접 변경하는 것은 지원하지 않습니다. 필요한 경우:
- 새 장부를 만들고 올바른 유형을 선택하세요
- 데이터를 새 장부로 마이그레이션하세요
- 이전 장부를 삭제하세요

### Q5: 계정은 장부 단위인가요?

**A:** 아닙니다. 계정은 기기 단위로 관리되며 모든 장부에서 공유됩니다. 이는 다음을 의미합니다:
- 여러 장부에서 동일한 계정을 사용할 수 있습니다
- 계정 잔액은 모든 장부에서 공유됩니다
- 다른 장부에서 다른 계정을 사용하려면 동일한 이름의 계정을 여러 개 만들 수 있지만(권장하지 않음)

### Q6: 장부 전환이 다른 장부에 영향을 주나요?

**A:** 영향을 주지 않습니다. 각 장부의 데이터는 완전히 독립적이며, 장부 전환은 다른 장부의 데이터에 영향을 주지 않습니다.

4. **명명 규칙**: 명확한 장부 이름을 사용하여 식별과 관리를 용이하게 하세요
5. **통화 선택**: 장부 용도에 맞는 통화를 선택하고 빈번한 변경을 피하세요
