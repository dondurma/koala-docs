# 다중 장부

## 📋 개요

Koala는 여러 장부(ledger)를 만들어 용도별로 내역과 통계를 분리해 관리할 수 있습니다.

## 🚀 생성 및 전환

- 생성: 설정 → 장부 관리 → 우측 상단 `+` → 정보 입력 → 저장
- 전환: 장부 목록에서 원하는 장부 카드 선택

## 🗑️ 삭제

장부 상세 화면에서 삭제할 수 있습니다. 삭제 시 해당 장부의 데이터도 함께 삭제됩니다.  
클라우드 동기화를 켜둔 경우, 다음 동기화 때 클라우드에도 반영됩니다. 앱 내에서 복구할 수 없습니다.
