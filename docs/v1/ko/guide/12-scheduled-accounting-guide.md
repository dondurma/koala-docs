# 정기 기장 안내

## 1. 어떤 기능인가요?

‘정기 기장’은 월세, 공과금, 구독 서비스, 급여처럼 일정하게 반복되는 수입/지출을 규칙으로 등록해, 규칙에 따라 자동으로 거래를 생성하는 기능입니다. 반복 입력을 줄일 수 있습니다.

## 2. 이런 경우에 유용해요

- 매월 월세, 대출 상환, 카드 결제 대금
- 매주 통근 교통비, 고정 식비/수당
- 매월 구독 서비스(영상 멤버십, 클라우드 저장소 등)
- 매월 고정 수입(급여, 지원금 등)

## 3. 사용 방법

1. **설정**에서 **정기 기장**을 찾습니다
2. 새 규칙을 만들고 다음을 입력합니다:
   - 유형: 지출 / 수입
   - 분류
   - 금액
   - 계정
   - 태그, 메모(선택)
   - 실행 주기: 매일 / 매주 / 매월(규칙에 따라 날짜 또는 요일 선택)
   - 시작/종료: 시작일은 필수, 종료일은 선택(만료 시 자동 중지)
3. 저장하면 규칙이 정기 기장 목록에 표시됩니다
4. 실행 시간이 되면 규칙에 따라 거래가 생성됩니다

## 4. 규칙 및 주의사항

- 정기 기장으로 생성된 거래는 일반 수동 거래와 동일하게 목록에 표시되며 통계에 포함됩니다.
- 앱을 오래 열지 않으면 일부 기기에서는 ‘정확히 지정 시각’에 생성되지 않을 수 있습니다. 이 경우에도 다음에 앱을 열 때, 생성되어야 했지만 아직 생성되지 않은 거래를 자동으로 보완 생성합니다(누락 방지).
- 월세 인상, 계정 변경 등 상황이 바뀔 수 있으므로 규칙 목록을 주기적으로 점검하는 것을 권장합니다.
- 규칙을 일시정지/종료하면 더 이상 생성되지 않으며, 다시 활성화하면 다음 주기부터 실행됩니다.

## 5. 자주 묻는 질문

### Q1. 정기 기장으로 생성된 거래가 잘못되면 어떻게 하나요?

정기 기장으로 생성된 거래도 일반 거래처럼 수정하거나 삭제할 수 있습니다. 자주 발생한다면 해당 규칙(금액/주기/계정 등)을 조정하세요.

### Q2. 규칙을 수정하면 이미 생성된 거래도 자동으로 바뀌나요?

아니요. 규칙 변경은 이후에 생성되는 거래에만 적용되며, 과거 거래는 추적을 위해 그대로 유지됩니다.

### Q3. 같은 날에 여러 건이 생성될 수 있나요?

여러 규칙을 설정했다면 규칙별로 거래가 각각 생성됩니다. 동일한 규칙에 대해서는 중복 생성이 되지 않도록 최대한 방지합니다.
