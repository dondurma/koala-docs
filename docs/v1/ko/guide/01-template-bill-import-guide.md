# 템플릿 내역 가져오기(CSV)

## 📋 개요

Koala는 외부 파일에서 거래 내역(장부)을 가져올 수 있습니다. 과거 데이터 이전에 유용합니다.  
템플릿 / WeChat / Alipay / Pixiu / iCost 총 5가지 방식에 대응합니다.

## 📁 지원 형식

- CSV: 템플릿, Alipay, Pixiu
- Excel: WeChat, iCost

## 🚀 가져오기 절차

1. Koala → **설정** → **내역 가져오기**
2. **가져오기 소스** 선택
3. **파일 경로**에서 파일 선택
4. **장부(ledger)** 선택
5. 우측 상단 **파싱** → 미리보기 확인 → **가져오기**

## 📝 템플릿 CSV 핵심

- 구분자: 쉼표 `,`
- 날짜 형식: `yyyy/MM/dd` (예: 2026/01/01)
- 1행은 헤더 필수
