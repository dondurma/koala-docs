# 템플릿 내역 가져오기(CSV)

## 📋 개요

코알라 가계부는 외부 파일에서 거래 내역을 가져와 과거 기록을 빠르게 옮길 수 있습니다. 현재 다음 방식의 가져오기를 지원합니다.

- **템플릿 파일 가져오기**: 표준 형식의 CSV 파일 가져오기
- **WeChat 가져오기**: WeChat에서 내보낸 거래 내역 파일 가져오기
- **Alipay 가져오기**: Alipay에서 내보낸 거래 내역 파일 가져오기
- **Pixiu 가져오기**: Pixiu에서 내보낸 CSV 파일 가져오기
- **iCost 가져오기**: iCost에서 내보낸 Excel 파일 가져오기

---

## 📁 지원 파일 형식

- **CSV** (`.csv`): Alipay, Pixiu, 템플릿
- **Excel** (`.xlsx`, `.xls`): WeChat, iCost

---

## 🚀 빠른 시작

### 1단계: 가져오기 화면 열기

1. 코알라 가계부 앱을 엽니다
2. 하단의 **설정**을 탭합니다
3. 설정 화면에서 **내역 가져오기**를 찾습니다
4. 내역 가져오기 화면으로 들어갑니다

### 2단계: 가져오기 소스 선택

가져오기 화면에서 내역의 출처를 선택합니다.

- **템플릿 파일**
- **WeChat**
- **Alipay**
- **Pixiu**
- **iCost**

> ⚠️ **중요**: 소스를 잘못 선택하면 파싱에 실패하거나 항목이 어긋나게 읽힐 수 있습니다.

### 3단계: 파일 선택

1. **파일 경로**를 탭합니다
2. 파일 선택기에서 가져올 파일을 선택합니다
3. 선택된 파일명이 표시되는지 확인합니다

> 📝 **참고**:
> - 파일은 기기 로컬에 저장되어 있어야 합니다(파일 관리자에서 접근 가능한 위치)
> - 파일 형식(CSV/Excel)이 올바른지 확인하세요
> - 파일이 손상된 경우 다시 내보내서 시도해 주세요

### 4단계: 장부 연결

1. **장부 연결**을 탭합니다
2. 어느 장부로 가져올지 선택합니다

> 💡 팁: 장부가 1개만 있는 경우 기본 장부로 자동 연결될 수 있습니다.

### 5단계: 파싱

1. 우측 상단의 **파싱**을 탭합니다
2. 파싱이 완료되면 미리보기 화면으로 이동합니다

### 6단계: 미리보기 및 수정

미리보기 화면에서:

- 날짜별로 묶인 내역을 확인할 수 있습니다
- 단건 편집(카테고리, 금액, 시간, 계좌, 태그, 메모 등)이 가능합니다
- 임의의 기록을 길게 누르면 다중 선택 모드로 들어가며, 하단 작업 표시줄(전체 선택/삭제)로 일괄 삭제할 수 있습니다
- "가져오기" 시 유효하지 않은 데이터가 있으면 "유효한 데이터만 가져오기" 또는 "돌아가서 수정"을 선택할 수 있습니다

### 7단계: 가져오기 실행

1. 내용이 맞는지 확인한 뒤 **가져오기**를 탭합니다
2. 완료될 때까지 기다립니다

## 📝 템플릿 CSV 형식 안내

템플릿 파일로 가져오려면 아래 형식으로 CSV를 준비해 주세요.

### CSV 요구사항

1. **인코딩**: UTF-8 또는 GBK
2. **구분자**: 쉼표 `,`
3. **헤더**: 1행에 헤더 필수

### 표준 예시

```csv
거래일,거래분류,수입지출 대분류,수입지출 소분류,유입금액,유출금액,계좌,태그,비고
2026/01/01,지출,식비,점심,,15.00,기본 계좌,회사식,동료와 식사
2026/01/05,수입,급여,월급,5000.00,,은행 카드,,월급
```

### 필드 설명

| 필드 | 설명 | 필수 | 예시 |
|------|------|------|------|
| 거래 날짜 | 날짜 형식: `yyyy/MM/dd`(`yyyy-MM-dd`도 지원) | ✅ | 2026/01/01 |
| 수입/지출 | 지출 또는 수입 | ✅ | 지출 / 수입 |
| 대분류 | 1단계 카테고리명 | ❌ | 식비 |
| 소분류 | 2단계 카테고리명 | ❌ | 아침 |
| 유입 금액 | 수입일 때 사용하는 금액 | ✅ | 100.00 |
| 유출 금액 | 지출일 때 사용하는 금액 | ✅ | 15 |
| 계좌 | 계좌명(가능하면 코알라 가계부에 이미 존재하는 계좌명) | ❌ | 기본 계좌 |
| 메모 | 메모 | ❌ | 점심 |
| 태그 | 태그명(복수는 쉼표로 구분) | ❌ | 회사식,회식 |

### 템플릿 다운로드

1. 가져오기 화면에서 **템플릿 다운로드**를 탭합니다
2. 시스템이 현재 App 언어로 **헤더만 있는** CSV 템플릿 파일을 생성하고 시스템 공유/저장을 실행합니다
3. 템플릿에 헤더에 맞춰 데이터를 한 줄씩 입력한 뒤, 다시 가져오기 화면에서 해당 파일을 선택해 가져옵니다

## ⚠️ 유의사항

### 1. 데이터 형식

- **날짜**: `YYYY/MM/DD` 형식 지원(예: `2026/01/01`), `YYYY-MM-DD`도 호환됩니다
- **금액**: 숫자 형식(소수점 가능, 예: `100.00`)
- **수입/지출**: `지출` 또는 `수입` (중국어 `支出`/`收入`도 지원)
- **카테고리/계좌**: 앱에 없는 카테고리/계좌는 가져오기 시 자동 생성됩니다(자주 쓰는 계좌를 미리 만들어 두면 규칙에 맞지 않는 이름이 생성되는 것을 줄일 수 있습니다)

### 2. 데이터 검증

가져오기 전에 코알라 가계부가 자동으로 검증합니다.

- ✅ 유효: 정상 가져오기 가능
- ⚠️ 무효: 형식 오류로 수정 필요
- ❌ 건너뛰기: 무효 항목을 제외하고 유효 항목만 가져오기 가능

### 3. 대량 데이터

- 데이터가 많다면(예: 1000건 이상) 나눠서 가져오기를 권장합니다
- 가져오기 중에는 앱을 전면에 두어 주세요

> 💡 **팁**: 무료 사용자는 전체 장부의 내역 총 개수 상한이 1,000건이며, 멤버는 제한이 없습니다. 데이터가 많은 경우 가져오기 전에 남은 기록 가능 건수를 확인하세요.

## 🔧 자주 묻는 질문

### Q1: 파싱에 실패합니다.

아래를 확인해 주세요.

1. 파일 형식(CSV/Excel)이 올바른지
2. 가져오기 소스 선택이 맞는지
3. 파일이 손상되지 않았는지
4. 인코딩(UTF-8 권장)

### Q2: 가져온 데이터가 일부 누락됩니다.

가능한 원인:

1. 일부 행이 형식 오류로 건너뛰어짐
2. 카테고리/계좌가 없어 생성 또는 수정이 필요
3. 미리보기 화면에서 무효 항목을 확인해 주세요

### Q3: 이미지는 가져올 수 있나요?

현재는 지원하지 않습니다.

### Q4: 가져온 뒤 수정할 수 있나요?

가능합니다. 가져온 후 내역 목록에서 수정/삭제할 수 있습니다.

### Q5: 여러 파일을 한 번에 가져올 수 있나요?

현재는 지원하지 않습니다. 파일을 하나씩 가져와 주세요.
