# 模板帳單匯入指南

## 📋 概述

考拉記帳支援從外部檔案匯入帳單資料，方便你快速搬移歷史帳單。目前支援以下匯入方式：

- **模板檔案匯入**：使用標準格式的 CSV 檔案匯入
- **微信帳單匯入**：直接匯入微信匯出的帳單檔案
- **支付寶帳單匯入**：直接匯入支付寶匯出的帳單檔案
- **貔貅記帳匯入**：直接匯入貔貅記帳 App 匯出的 CSV 帳單檔
- **iCost 匯入**：直接匯入 iCost App 匯出的 xlsx 檔案

---

## 📁 支援的檔案格式

- **CSV 檔**（`.csv`）：支付寶、貔貅、模板帳單
- **Excel 檔**（`.xlsx`、`.xls`）：微信帳單、iCost 帳單

---

## 🚀 快速開始

### 步驟 1：進入匯入頁面

1. 打開考拉記帳 App
2. 點擊底部導覽列的 **「設定」**
3. 在設定頁面中找到 **「帳單匯入」**
4. 點擊進入帳單匯入頁面

### 步驟 2：選擇匯入來源

在匯入頁面中，請選擇帳單來源類型：

- **模板檔案**：適用於標準格式的 CSV
- **微信**：適用於微信匯出的帳單檔
- **支付寶**：適用於支付寶匯出的帳單檔
- **貔貅記帳**：適用於貔貅記帳匯出的帳單檔
- **iCost**：適用於 iCost 匯出的帳單檔

> ⚠️ **重要**：請務必選擇正確的匯入來源，否則可能導致解析失敗。

### 步驟 3：選擇檔案

1. 點擊 **「檔案路徑」**
2. 在檔案選擇器中選擇要匯入的檔案
3. 確認已選擇檔案（會顯示檔名）

> 📝 **注意**：
> - 檔案必須保存在裝置本機（可透過檔案管理器存取）
> - 確保檔案格式正確（CSV 或 xlsx）
> - 確保檔案未損壞

### 步驟 4：關聯帳本

1. 點擊 **「關聯帳本」**
2. 選擇要把帳單匯入到哪個帳本
3. 確認帳本選擇

> 💡 **提示**：如果只有一個帳本，系統會自動關聯到預設帳本。

### 步驟 5：解析檔案

1. 點擊右上角 **「解析」**
2. 等待系統解析（可能需要幾秒）
3. 解析成功後會自動跳轉到預覽頁

> ⚠️ **如果解析失敗**：
> - 檢查檔案格式是否正確
> - 檢查是否選擇了正確的匯入來源
> - 檢查檔案是否損壞
> - 嘗試重新匯出檔案

### 步驟 6：預覽與編輯

解析成功後，你可以在預覽頁：

- **查看所有帳單記錄**：按日期分組顯示
- **編輯單筆記錄**：點擊記錄可修改分類、金額、時間等
- **刪除無效記錄**：長按記錄可刪除
- **批量操作**：可選擇跳過無效記錄

> 📝 **建議**：匯入前先預覽資料，確認無誤再匯入。

### 步驟 7：匯入資料

1. 在預覽頁確認資料無誤後
2. 點擊 **「匯入」**
3. 等待匯入完成
4. 匯入成功後會顯示匯入結果

## 📝 模板檔案格式說明

如要使用模板匯入，請依照以下格式準備 CSV 檔案。

### CSV 格式要求

1. **檔案編碼**：支援 UTF-8 或 GBK
2. **分隔符**：使用逗號 `,`
3. **表頭**：第一行必須包含表頭

### 標準格式示例

```csv
日期,類型,金額,分類,帳戶,備註,標籤
2024-01-01,支出,100.00,餐飲,現金,午餐,工作餐
2024-01-02,收入,5000.00,工資,銀行卡,月薪,
```

### 欄位說明

| 欄位 | 說明 | 必填 | 示例 |
|------|------|------|------|
| 交易日期 | 帳單日期，格式：`yyyy/MM/dd` | ✅ | 2026/01/01 |
| 交易分類 | 支出或收入 | ✅ | 支出 / 收入 |
| 收支大類 | 一級分類名稱 | ✅ | 伙食 |
| 收支小類 | 二級分類名稱（隸屬於一級分類） | ✅ | 早餐 |
| 流入金額 | 收入金額欄位（交易分類為收入時填寫） | ✅ | 100.00 |
| 流出金額 | 支出金額欄位（交易分類為支出時填寫） | ✅ | 15 |
| 資金帳戶 | 帳戶名稱（盡量填寫 App 內已存在的帳戶） | ✅ | 預設帳戶 |
| 備註 | 帳單備註 | ❌ | 午餐 |
| 標籤 | 標籤名稱，多個以逗號分隔 | ❌ | 工作餐,聚餐 |

### 下載模板檔案

1. 在匯入頁面點擊 **「下載模板檔案」**
2. 系統會下載示例 CSV 檔
3. 你可參考模板格式準備自己的資料

## ⚠️ 注意事項

### 1. 資料格式要求

- **日期格式**：必須為 `YYYY/MM/DD`（例如：`2026/01/01`）
- **金額格式**：必須為數字，支援小數點（例如：`100.00`）
- **交易分類**：必須為「支出」或「收入」
- **分類與帳戶**：若 App 中不存在，匯入時可能會自動建立

### 2. 資料驗證

匯入前，系統會自動驗證資料：

- ✅ **有效記錄**：格式正確，可正常匯入
- ⚠️ **無效記錄**：格式錯誤，需要修改
- ❌ **跳過記錄**：可跳過無效記錄，只匯入有效資料

### 3. 重複資料處理

- 建議匯入前先檢查是否有重複資料

### 4. 大量資料匯入

- 資料量很大（例如超過 1000 筆）建議分批匯入
- 匯入過程請保持 App 在前台
- 匯入完成後，建議手動同步一次資料

## 🔧 常見問題

### Q1：解析失敗怎麼辦？

請檢查：

1. 檔案格式是否正確（CSV 或 xlsx）
2. 是否選擇了正確的匯入來源
3. 檔案是否損壞
4. 檔案編碼是否正確（建議 UTF-8）

### Q2：匯入後資料不完整？

可能原因：

1. 部分記錄格式錯誤，被系統跳過
2. 分類或帳戶不存在，需要先建立
3. 建議在預覽頁檢查無效記錄

### Q3：可以匯入圖片嗎？

目前不支援。

### Q4：匯入後可以修改嗎？

可以。匯入後你可在帳單列表中編輯或刪除記錄。

### Q5：支援一次匯入多個檔案嗎？

目前不支援。每次只能匯入一個檔案，多個檔案請逐個匯入。
