# 帳單拆分說明

## 1. 這是什麼功能

當一筆消費同時包含多個用途（例如「超市購物」同時買了水果和日用品），你可以把這筆帳單拆成多筆子帳單，讓分類統計更準確。

拆分完成後：

- 你會看到多筆「子帳單」（每筆都有自己的分類、金額、備註）。
- 原本那筆帳單會變成「拆分容器」，不再參與列表顯示與統計匯總，避免金額重複計算。

## 2. 適用場景

- 一筆付款包含多個類別（餐飲 + 日用品、交通 + 停車等）
- 需要更精細的分類統計、預算對比
- 同一張收據想拆到不同分類/標籤

## 3. 如何使用

1. 進入「帳單列表」找到要拆分的帳單
2. 對該帳單左滑，選擇「拆分」
3. 在「拆分帳單」頁面中：
   - 點選子項的「分類」選擇需要的收支項目
   - 點選「金額」輸入每個子項的金額
   - 備註可選填（用作補充說明）
   - 需要更多項目時，點選「新增一項」
4. 確保「剩餘待分配金額」為 0（表示子項合計剛好等於原始帳單金額）
5. 點選右上角「完成/儲存」提交

## 4. 使用規則與注意事項

- 子項金額合計必須等於原始帳單金額，否則無法儲存。
- 每一條子項都需要選擇分類，且金額必須大於 0。
- 拆分後的統計口徑以子帳單為準；原始帳單不再計入統計。
- 支援多級拆分：子帳單也可以再拆分；最終統計以最末級子帳單為準。
- 拆分與報銷互斥：已標記「可報銷/待報銷/已報銷」的支出帳單不能拆分；已拆分的帳單也無法開啟報銷流程。建議先確認這筆支出是否需要走報銷，再決定是否拆分。

## 5. 常見問題

### Q1：拆分後原本的帳單去哪了？

為了避免金額重複統計，原本的帳單會被標記為「拆分容器」，通常不會在列表中顯示；實際統計會以拆分後的子帳單為準。

### Q2：可以只拆一部分嗎？

可以。你可以把其中一項保留為「其他/原分類」，金額填寫為剩餘金額即可。重點是所有子項金額合計必須等於原始金額。

### Q3：拆分後還能修改嗎？

一般建議直接修改拆分後的子帳單（金額/分類/備註等）。如果需要重新拆分，通常做法是先刪除相關子帳單再重新操作。
