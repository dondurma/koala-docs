# 支付寶帳單匯入教學

## 📋 概述

本教學將指引你如何從支付寶匯出帳單，並匯入到考拉記帳 App。

---

## 📱 第一步：在支付寶中匯出帳單

### 步驟 1：打開支付寶帳單頁面

1. 打開支付寶 App
2. 點擊底部導覽列的 **「我的」**
3. 點擊 **「帳單」** 進入帳單頁

> 📝 **注意**：不同版本的支付寶入口可能略有不同。若找不到，可在支付寶搜尋框搜尋「帳單」。

### 步驟 2：匯出帳單

1. 在帳單頁點擊右上角 **「...」**
2. 選擇 **「開具交易流水證明」** 或 **「帳單匯出」**
3. 選擇 **「用戶個人對帳」**，並點擊 **「申請」**

### 步驟 3：選擇交易範圍

1. 選擇交易類型：**全部交易** / **收入** / **支出**
2. 選擇匯出時間範圍（例如：最近一個月、最近三個月）
3. 選擇接收方式：**支付寶** / **郵箱**

> 💡 **提示**：
> - 建議一次匯出不超過 3 個月，避免檔案過大
> - 若需匯出更長時間，可分多次匯出
> - 若選擇郵箱接收，支付寶會透過郵件發送帳單檔案（需先設定郵箱）

### 步驟 4：把檔案保存到裝置

1. 若選擇郵件：
   - 打開郵箱，找到支付寶發送的郵件
   - 下載附件（CSV）
   - 保存到裝置本機（檔案管理器可存取的位置）
2. 若選擇「保存到檔案」（如支援）：
   - 檔案會保存到下載資料夾
   - 記住保存位置

> 📝 **檔案位置提示**：
> - iOS：通常在「檔案」App 的「下載」資料夾
> - Android：通常在「下載」資料夾或「支付寶」資料夾

---

## 📱 第二步：在考拉記帳中匯入

### 步驟 1：進入匯入頁面

1. 打開考拉記帳 App
2. 點擊底部導覽列的 **「設定」**
3. 在設定頁面中找到 **「帳單匯入」**
4. 點擊進入帳單匯入頁

### 步驟 2：選擇匯入來源

1. 點擊 **「匯入來源」**
2. 在列表中選擇 **「支付寶」**
3. 確認選擇

> ⚠️ **重要**：必須選擇「支付寶」，否則系統無法正確解析檔案格式。

### 步驟 3：選擇檔案

1. 點擊 **「檔案路徑」**
2. 在檔案選擇器中找到並選擇支付寶匯出的帳單檔
3. 確認已選擇檔案（會顯示檔名）

> 📝 **檔案格式**：
> - 僅支援 CSV（`.csv`）
> - 檔名通常包含「支付寶」或「Alipay」

### 步驟 4：關聯帳本

1. 點擊 **「關聯帳本」**
2. 選擇匯入目標帳本
3. 確認帳本選擇

> 💡 **提示**：若只有一個帳本，系統會自動關聯預設帳本。

### 步驟 5：解析檔案

1. 點擊右上角 **「解析」**
2. 等待解析（可能需要幾秒）
3. 解析成功後會自動跳轉到預覽頁

> ⚠️ **若解析失敗**：
> - 檢查檔案格式是否正確
> - 檢查是否已選擇「支付寶」作為匯入來源
> - 檢查檔案是否損壞
> - 嘗試重新從支付寶匯出檔案

### 步驟 6：預覽與編輯

解析成功後，可在預覽頁中：

- **查看所有帳單記錄**：按日期分組顯示
- **編輯單筆記錄**：點擊記錄可修改：
  - 分類（支出/收入分類）
  - 金額
  - 時間
  - 帳戶
  - 標籤
  - 備註
- **刪除無效記錄**：長按記錄可刪除
- **批量操作**：可選擇跳過無效記錄

> 📝 **建議**：
> - 匯入前先預覽資料，確保資料正確
> - 檢查分類是否正確匹配
> - 檢查金額是否正確
> - 如有需要，可手動調整分類和帳戶

### 步驟 7：匯入資料

1. 在預覽頁確認資料無誤後
2. 點擊 **「匯入」**
3. 等待匯入完成（可能需要幾秒）
4. 匯入成功後，會顯示匯入結果

> ✅ **匯入成功**：所有有效記錄已匯入到帳本中，可在帳單列表中查看。

## 📋 支付寶帳單檔案格式說明（CSV）

支付寶匯出的 CSV 通常包含以下欄位：

| 欄名 | 說明 | 示例 |
|------|------|------|
| 交易時間 | 交易建立時間 | 2024-01-01 12:00:00 |
| 交易分類 | 收支分類名稱 | 餐飲美食/日用百貨 |
| 交易對方 | 交易對方資訊 | 張三 / 商戶名稱 |
| 對方帳號 | 對方支付寶帳號 | xxx@163.com |
| 商品說明 | 商品描述 | 午餐 / 購物等 |
| 收/支 | 收入或支出 | 收入 / 支出 |
| 金額 | 交易金額 | 100.00 |
| 收/付款方式 | 付款來源/方式 | 餘額寶 |
| 交易狀態 | 交易狀態 | 交易成功 / 已退款 |
| 交易訂單號 | 交易單號 | 20240101... |
| 商家訂單號 | 商家單號 | 1234567890 |
| 備註 | 備註資訊 | 備註內容 |

> 📝 **注意**：不同版本的支付寶欄名可能略有不同，但主要內容相同。

## ⚠️ 注意事項

### 1. 檔案格式要求

- **檔案編碼**：建議 UTF-8（支付寶匯出可能為 UTF-8 或 GBK）
- **檔案格式**：僅支援 CSV（`.csv`）
- **檔案大小**：建議單檔不超過 10MB

### 2. 欄位映射（匯入行為）

系統會把支付寶欄位映射到考拉記帳欄位（概念如下）：

- 交易時間（row[0]）→ 帳單日期（只取日期，`yyyy-MM-dd`）
- 交易分類（row[1]）→ 父/子分類（父子同名）
- 收/支（row[5]）→ 帳單類型（收入/支出）
- 金額（row[6]）→ 帳單金額
- 收/付款方式（row[7]）→ 帳戶（按名稱匹配/建立）
- 交易對方、對方帳號、商品說明、交易狀態、訂單號等 → 會追加拼接到帳單備註
- 備註（row[11]）→ 原始備註（若為「/」或空會忽略，再疊加上述追加項）

### 3. 分類匹配

- 系統會嘗試自動匹配分類，但可能不完全準確
- 建議在預覽頁檢查分類是否正確
- 如有需要，可手動調整分類

### 4. 帳戶匹配

- 系統會嘗試根據「付款來源」或其他資訊匹配帳戶
- 若帳戶不存在，系統會自動建立
- 建議匯入前先建立常用帳戶

### 5. 重複數據處理

- 若匯入的記錄與現有記錄重複（基於交易號），系統會自動跳過
- 建議匯入前先檢查是否有重複數據

### 6. 退款處理

- 若帳單包含退款記錄，系統會嘗試識別並處理
- 退款記錄通常標記為「已退款」或「退款成功」
- 建議在預覽頁檢查退款記錄是否正確

### 7. 不要手動修改帳單檔

不要手動修改支付寶帳單（包含但不限於修改/刪除表頭、或新增列），否則可能導致解析失敗。

## 🔧 常見問題

### Q1：找不到「匯出帳單」選項？

可能原因：

1. 支付寶版本較舊，不支援匯出
2. 入口位置不同，可嘗試：
   - 在帳單頁點擊右上角「...」
   - 在「我的」頁查找「帳單」
   - 在支付寶搜尋框搜尋「帳單匯出」

### Q2：匯出後收不到郵件？

請檢查：

1. 支付寶是否已綁定郵箱
2. 郵箱地址是否正確
3. 郵件是否進入垃圾郵件
4. 可改用「保存到檔案」方式

### Q3：解析失敗怎麼辦？

請檢查：

1. 檔案格式是否正確（CSV）
2. 是否選擇「支付寶」作為匯入來源
3. 檔案是否損壞
4. 檔案編碼是否正確（建議 UTF-8 或 GBK）

### Q4：匯入後分類不正確？

**A：** 這是正常現象，因為：
1. 支付寶的分類和考拉記帳的分類可能不完全匹配
2. 系統會嘗試自動匹配，但可能不完全準確
3. 建議在預覽頁手動調整分類，或匯入後批量修改

### Q5：可以匯入圖片嗎？

**A：** 目前不支援。支付寶帳單不包含圖片資訊，匯入後也無法新增圖片。

### Q6：支援匯入多長時間的數據？

**A：** 理論上沒有嚴格限制，但建議：
1. 單次匯入不超過 3 個月的數據
2. 若數據量很大，可分多次匯入
3. 匯入過程中請保持 App 在前景運行

### Q7：為什麼只支援 CSV 格式？

**A：** 支付寶目前只支援匯出 CSV 格式的帳單檔案。若將來支援 Excel 格式，我們會及時更新。

---

## 💡 使用技巧

1. **定期匯入**：建議每月匯入一次，保持資料同步
2. **分類整理**：匯入後檢查並整理分類，方便統計
3. **帳戶管理**：先建立常用帳戶，避免自動建立不規範的帳戶名稱
4. **資料備份**：匯入前建議先備份現有資料
5. **退款處理**：匯入後建議檢查退款記錄是否正確
