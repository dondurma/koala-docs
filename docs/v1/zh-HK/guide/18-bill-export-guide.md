# 帳單匯出說明

## 📋 概述

你可以把帳單匯出為 CSV 檔案，用於備份，或搬移到其他記帳工具。

> ⚠️ **會員功能**：帳單匯出需要會員。免費用戶可在會員頁了解並開通，詳見《會員說明》。

## 🚀 如何匯出

1. 打開考拉記帳 App，進入 **「設定」**
2. 找到並點擊 **「帳單匯出」**
3. 按需設定匯出條件：
   - **時間範圍**：選擇要匯出的起訖日期
   - **指定帳戶**：只匯出某個帳戶的帳單（可選）
   - **指定帳本**：選擇要匯出的帳本
4. 點擊右上角 **「匯出」**
5. 系統會產生 CSV 檔案並喚起系統分享/儲存，你可以儲存到本機或傳送到其他 App

## 📄 匯出格式

- 目前**僅支援匯出 CSV** 檔案
- 匯出欄為：日期、交易分類（支出/收入）、收支大類、收支小類、流入金額、流出金額、帳戶、標籤、備註
- 日期格式為 `yyyy/MM/dd`，與模板匯入的表頭一致，匯出的檔案可再透過「模板帳單匯入」回環匯入

> 📝 **注意**：匯出使用當前 App 語言表頭，可用試算表軟體（如 Excel / Numbers）直接打開，也可另存為 Excel。

## ⚠️ 注意事項

- 已刪除的帳單不會匯出；**拆分容器（原帳單）不會匯出**，只會匯出拆分後的子帳單
- 退款記錄會以負數金額匯出；報銷入帳會作為一筆收入記錄匯出
- 若不指定「指定帳戶」，則匯出所選帳本下所有帳戶的帳單

## 🔧 常見問題

### Q1：為什麼匯出的是 CSV 而不是 Excel？

目前僅提供 CSV 匯出。CSV 可被絕大多數試算表軟體直接打開，也能再另存為 Excel。

### Q2：匯出的範圍由什麼決定？

由「時間範圍 + 指定帳戶 + 指定帳本」共同決定；未選擇時間範圍時會匯出該帳本內的全部帳單。

### Q3：匯出的檔案能再匯回來嗎？

可以。匯出表頭與「模板帳單匯入」的表頭一致，可按《模板帳單匯入指南》重新匯入（請在預覽頁核對後再匯入，避免重複資料）。
