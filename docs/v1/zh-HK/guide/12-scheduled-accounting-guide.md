# 定時記帳說明

## 1. 這是什麼功能

「定時記帳」可以把一些固定、重複發生的收支（例如房租、水電、會員訂閱、薪資等）設定成規則，讓系統按規則自動生成帳單，減少重複手動輸入。

## 2. 適用場景

- 每月房租、房貸、信用卡還款
- 每週通勤交通費、固定餐補
- 每月訂閱服務（影片會員、雲端硬碟等）
- 每月固定收入（薪資、補貼等）

## 3. 如何使用

1. 進入「設定」頁面，找到「定時記帳」
2. 新增一條定時規則，填寫：
   - 收支類型：支出 / 收入
   - 分類（收支項目）
   - 金額
   - 帳戶
   - 標籤、備註（可選）
   - 執行週期：每天 / 每週 / 每月（依規則選擇日期或星期）
   - 起訖時間：開始時間必填；結束時間可選（到期後自動停止）
3. 儲存後，規則會出現在定時記帳列表中
4. 到達觸發時間後，系統會按規則生成帳單

## 4. 使用規則與注意事項

- 定時記帳生成的帳單與一般手動帳單一致：會在列表顯示並參與統計匯總。
- 若你長時間不開啟 App，部分裝置可能無法做到「完全準點」生成；下次打開 App 時，系統會補齊到期但尚未生成的帳單（避免漏記）。
- 建議定期檢查規則列表，確認金額、分類、帳戶仍符合目前狀況（例如房租調整、換卡等）。
- 暫停/終止規則後將不再繼續生成帳單；恢復啟用後會從下一次週期繼續執行。

## 5. 常見問題

### Q1：定時記帳生成錯了怎麼辦？

定時記帳生成的帳單可以像一般帳單一樣編輯或刪除。若經常出錯，建議直接調整對應的定時規則（金額/週期/帳戶等）。

### Q2：規則改了，之前生成的帳單會自動跟著改嗎？

不會。規則修改只影響後續生成的帳單；歷史帳單會保持不變，方便追溯。

### Q3：同一天會生成多筆嗎？

若你設定了多條規則，系統會分別生成對應的帳單。對同一條規則，系統會盡量避免重複生成。
