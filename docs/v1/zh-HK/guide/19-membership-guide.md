# 會員說明

## 📋 概述

考拉記帳提供會員服務（按月/按年訂閱或一次性買斷），用於解鎖多帳本、多幣種、帳單匯出、帳單拆分、定時記帳等進階能力；同時免費用戶也能使用記帳、雲同步、快捷記帳等核心功能。

## 💎 會員權益

開通會員後可解鎖：

- **多帳本**：建立與管理多個帳本
- **多幣種**：記錄非本位幣帳單
- **帳單匯出**：將帳單匯出為 CSV
- **帳單拆分**：把一筆帳單拆成多筆子帳單
- **定時記帳**：按週期自動產生帳單
- **無限記帳次數**：不受免費額度限制

其中，**快捷記帳、雲同步**對所有使用者開放，無需會員。

## 🚀 開通與恢復

### 開通會員

1. 打開考拉記帳 App，進入 **「設定」**
2. 點擊頁面頂部的使用者卡片（未登入需先登入 Apple 帳號）
3. 進入會員頁，選擇 **按月** 訂閱、**按年** 訂閱或 **永久會員**（一次性買斷）
4. 按 App Store 提示完成付款

> 💡 **提示**：會員價格以 App Store 實際展示與扣費為準；按年訂閱通常會顯示「折合每月」金額。

> ⚠️ **僅適用於已有訂閱的用戶**：如你目前仍在按月/按年訂閱中，購買永久會員不會自動取消該訂閱，Apple 亦不會退還已付訂閱費；請先在系統 **「設定 → Apple ID → 訂閱」** 中取消，否則訂閱到期仍會繼續扣費。此前從未訂閱過的用戶無需這一步。

### 恢復購買

換機或重裝後：進入會員頁，點擊右上角 **「恢復購買」**，按提示恢復會員狀態（以 App Store 的訂閱狀態為準）。

### 取消訂閱

訂閱由 App Store 管理，可在系統 **「設定 → Apple ID → 訂閱」** 中取消。取消後，當前已付費週期內仍可使用會員權益，到期後不再續費。

## 🔄 會員狀態

- 會員權益以 App Store 嘅購買／訂閱狀態為準；永久會員長期有效
- 若「恢復購買」後權益未生效，請確認登入的 Apple 帳號與購買時一致，並稍後重試

## 🔧 常見問題

### Q1：會員有訂閱和永久會員兩種，我該選哪個？

兩種權益相同，區別只在付款方式：按月/按年訂閱適合先試用一段時間、隨時可以取消；永久會員付一次長期有效，適合確定長期使用、不想管理續費的人。價格以 App Store 展示為準。

注意：如你目前仍在訂閱中，購買永久會員不會自動取消該訂閱，亦不會退還已付訂閱費，請先在 App Store 取消訂閱，否則到期仍會續費；此前從未訂閱過的用戶無需這一步。

### Q2：免費用戶有哪些限制？

免費用戶可使用記帳、雲同步、快捷記帳等功能，但帳單總數為 300 條，且無法使用多帳本、多幣種、帳單匯出、帳單拆分、定時記帳、報銷、退款、帳單篩選。

### Q3：換手機後會員還在嗎？

訂閱記錄由 App Store 保存，換機或重裝後登入購買時的 Apple 帳號，點擊「恢復購買」即可恢復（永久會員同樣適用）。
