# iCost 帳單匯入指南

## 📋 概述

本指南將指引你如何從 **iCost** 匯出帳單，並匯入到 **考拉記帳** App。

考拉記帳目前支援匯入 **iCost 匯出的 Excel 檔**（`.xlsx` / `.xls`），並且 **不支援 iCost 的 CSV 檔**。

---

## 📱 第一步：在 iCost 中匯出帳單

不同版本的 iCost 入口可能略有差異，但思路一致：進入「匯出/資料匯出」，選擇匯出格式為 Excel 後保存檔案。

### 步驟 1：進入匯出入口

1. 打開 **iCost**
2. 進入 **設定 / 更多**（或「我的」頁中的設定入口）
3. 找到 **匯出 / 資料匯出 / 匯出帳單**（名稱可能略有不同）

### 步驟 2：選擇匯出格式

1. 匯出格式選 **Excel（.xlsx / .xls）**
2. 選擇匯出時間範圍（建議每次不超過 3 個月）
3. 匯出並保存到本機（或透過「分享/保存到檔案」）

> ⚠️ **重要**：若匯出為 CSV，考拉記帳會提示「不支援 CSV，請使用 Excel」。

---

## 📱 第二步：在考拉記帳中匯入

### 步驟 1：進入匯入頁面

1. 打開考拉記帳 App
2. 點擊底部導覽列 **「設定」**
3. 在設定頁找到 **「帳單匯入」**
4. 點擊進入帳單匯入頁

### 步驟 2：選擇匯入來源

1. 點擊 **「匯入來源」**
2. 在列表中選擇 **「iCost」**

> ⚠️ **重要**：必須選擇「iCost」，否則系統會按其他來源解析，導致找不到表頭或欄位錯位。

### 步驟 3：選擇檔案

1. 點擊 **「檔案路徑」**
2. 選擇 iCost 匯出的 **Excel 檔**（`.xlsx` / `.xls`）
3. 確認檔名已顯示

### 步驟 4：關聯帳本

1. 點擊 **「關聯帳本」**
2. 選擇匯入目標帳本
3. 確認帳本選擇

### 步驟 5：解析並預覽

1. 點擊右上角 **「解析」**
2. 解析成功後進入預覽頁
3. 在預覽頁可編輯單筆的分類、帳戶、時間、金額、標籤、備註等，再執行匯入

### 步驟 6：匯入

1. 預覽確認無誤後點擊 **「匯入」**
2. 等待匯入完成

---

## 📋 iCost 帳單檔案格式說明（Excel）

考拉記帳對 iCost Excel 的校驗點：

- Excel 需要存在可讀取的工作表
- 表頭行需要包含 **「日期」** 字樣（用於定位表頭行）

> 📝 **提示**：若 iCost 匯出可選語言，建議以中文表頭匯出（至少保證表頭行包含「日期」）。

### 讀取欄位（按列位置）

考拉記帳按列位置讀取 iCost Excel 的部分欄位，其他列會被忽略：

| 欄序號 | 欄位 | 說明 |
|------|------|------|
| 1 | 日期 | 支援 `yyyy-MM-dd` / `yyyy/MM/dd` / `yyyy-MM-ddTHH:mm:ss` / `yyyy-MM-dd HH:mm:ss`；亦支援 Excel 序列號日期 |
| 2 | 類型 | 需包含「支出」或「收入」關鍵字；包含「支出」=支出，包含「收入」=收入 |
| 3 | 金額 | 允許帶 `+`/`-`，匯入會自動去除符號並去掉千分位逗號 |
| 4 | 父分類 | 用於匹配考拉記帳收支項目父類名稱 |
| 5 | 子分類 | 為空時會自動使用「父分類」的值 |
| 6 | 帳戶 | 為空時會使用預設帳戶作為兜底 |
| 8 | 備註 | 備註文字 |
| 9 | 幣種代碼 | 例如 `CNY` / `USD`；為空或匹配失敗時使用目標帳本幣種 |
| 10 | 標籤 | 多個標籤以逗號分隔（同時支援中文逗號 `，`） |

### 匯入映射（考拉記帳）

- 日期（row[0]）→ 帳單日期
- 類型（row[1]）→ 帳單類型
- 金額（row[2]）→ 金額
- 一級分類（row[3]）→ 一級分類（並匹配/建立）
- 二級分類（row[4]，空則用一級）→ 二級分類（並匹配/建立）
- 帳戶（row[5]，空則預設帳戶）→ 帳戶
- 第 7 列（row[6]）→ 不入庫（未使用）
- 備註（row[7]）→ 備註
- 幣種代碼（row[8]）→ 幣種（按 code 匹配；失敗則用帳本幣種）
- 標籤（row[9]）→ 標籤（解析/建立後綁定）

## ⚠️ 注意事項

1. **僅支援 Excel**：iCost CSV 檔無法匯入。
2. **不自動去重**：重複匯入同一份檔案會生成重複帳單，請避免多次匯入同一時間段。
3. **表頭語言**：解析依賴表頭行包含「日期」；若匯出為非中文表頭，可能導致找不到表頭而解析失敗。
4. **帳戶為空的處理**：若匯出中「帳戶」列為空，會使用預設帳戶兜底；建議在預覽頁統一修改，或在 iCost 匯出前補全帳戶資訊。
5. **收支項目匹配**：按「父分類 + 子分類」匹配；匹配失敗會在預覽提示不完善，需要手動選擇後再匯入。

## 🔧 常見問題

### Q1：提示「未找到 iCost 帳單表頭」？

常見原因：

1. Excel 表頭行不包含「日期」（例如匯出為英文表頭）
2. 檔案不是 iCost 匯出的帳單檔，或二次編輯破壞了表結構
3. Excel 檔為空/沒有工作表

建議重新從 iCost 匯出，並優先選擇中文表頭。

### Q2：帳戶為空導致匯入後都進了同一個帳戶？

這是正常兜底行為：當「帳戶」列為空時會使用預設帳戶。可在預覽頁批量編輯帳戶，或在 iCost 匯出前補全帳戶後再重新匯入。

### Q3：分類匹配不上怎麼辦？

可在預覽頁進入單筆手動選擇收支項目；或先在考拉記帳建立與 iCost 匯出檔同名的收支項目後再重新解析。
