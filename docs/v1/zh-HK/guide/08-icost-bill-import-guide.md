# iCost 帳單匯入指南

## 📋 概述

考拉記帳支援匯入 iCost 匯出的 Excel 檔（`.xlsx` / `.xls`），不支援 iCost 的 CSV。

## 📤 在 iCost 匯出（簡要）

在 iCost 的設定/更多中找到「匯出/資料匯出/匯出帳單」，選擇匯出格式為 **Excel** 後保存到本機。

## 📥 在考拉記帳匯入

1. 設定 → 帳單匯入
2. 匯入來源選「iCost」
3. 選擇 Excel 檔案
4. 關聯帳本 → 解析 → 預覽 → 匯入

## ⚠️ 注意事項

- 解析會依賴表頭行包含「日期」。若 iCost 可選語言，建議以中文表頭匯出。
- 重複匯入同一份檔案可能產生重複帳單，請避免。
