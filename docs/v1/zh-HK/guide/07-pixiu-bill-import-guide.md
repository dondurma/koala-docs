# 貔貅帳單匯入指南

## 📋 概述

本指南將指引你如何從 **貔貅記帳** 匯出帳單，並匯入到 **考拉記帳** App。

考拉記帳目前支援匯入 **貔貅記帳匯出的 CSV 帳單檔**（僅 CSV）。

---

## 📱 第一步：在貔貅記帳中匯出帳單

不同版本的貔貅記帳入口可能略有差異，但思路一致：進入「資料匯出/匯出帳單」，選擇時間範圍與匯出格式後保存檔案。

### 步驟 1：進入匯出入口

1. 打開 **貔貅記帳** App
2. 進入 **我的**
3. 找到 **資料匯出 / 匯出帳單**（名稱可能略有不同）

### 步驟 2：選擇匯出時間範圍

1. 選擇要匯出的時間範圍（例如：最近一個月、最近三個月）
2. 確認後開始匯出

> 💡 **提示**：
> - 建議一次匯出不超過 3 個月，避免檔案過大導致解析變慢
> - 資料量很大時，可分多次匯出後分批匯入

### 步驟 3：選擇匯出格式並保存

1. 匯出格式請選 **CSV**
2. 把匯出的 CSV 檔保存到裝置本機（或透過「分享/保存到檔案」）
3. 記住檔案保存位置，方便後續匯入

---

## 📱 第二步：在考拉記帳中匯入

### 步驟 1：進入匯入頁面

1. 打開考拉記帳 App
2. 點擊底部導覽列 **「設定」**
3. 在設定頁找到 **「帳單匯入」**
4. 點擊進入帳單匯入頁

### 步驟 2：選擇匯入來源

1. 點擊 **「匯入來源」**
2. 在列表中選擇 **「貔貅記帳」**

> ⚠️ **重要**：必須選擇「貔貅記帳」，否則可能導致格式校驗失敗或欄位解析錯誤。

### 步驟 3：選擇檔案

1. 點擊 **「檔案路徑」**
2. 選擇貔貅記帳匯出的 **CSV** 檔
3. 確認檔名已顯示

### 步驟 4：關聯帳本

1. 點擊 **「關聯帳本」**
2. 選擇匯入目標帳本
3. 確認帳本選擇

### 步驟 5：解析並預覽

1. 點擊右上角 **「解析」**
2. 解析成功後進入預覽頁
3. 預覽頁可編輯/刪除單筆，或批量跳過無效記錄

### 步驟 6：匯入

1. 預覽確認無誤後點擊 **「匯入」**
2. 等待匯入完成

## 📋 貔貅帳單檔案格式說明（CSV）

考拉記帳對貔貅帳單 CSV 的校驗點：

- 第一行必須是表頭
- **表頭欄位數必須為 10 欄**
- 使用英文逗號 `,` 作為分隔符（CSV 標準）

### 欄位定義（按順序）

| 欄序號 | 欄位含義 | 說明 |
|------|------|------|
| 1 | 日期 | 支援 `yyyy-MM-dd` / `yyyy/MM/dd`，且年份需 ≥ 2016；否則視為無效日期 |
| 2 | 父分類 | 用於匹配考拉記帳的收支項目父類名稱 |
| 3 | 交易分類 | 需包含「支出」或「收入」關鍵字；包含「收入」則按收入匯入，否則按支出匯入 |
| 4 | 子分類 | 用於匹配考拉記帳的收支項目子類名稱 |
| 5 | 流入金額 | 收入金額欄（允許帶 `-`，匯入會自動去除符號） |
| 6 | 流出金額 | 支出金額欄（允許帶 `-`，匯入會自動去除符號） |
| 7 | 幣種代碼 | 例如 `CNY` / `USD`；為空時使用目標帳本預設幣種 |
| 8 | 帳戶 | 帳戶名稱（用於匹配；不存在時匯入階段會嘗試建立） |
| 9 | 標籤 | 多個標籤以逗號分隔（同時支援中文逗號 `，`） |
| 10 | 備註 | 備註文字 |

### 匯入映射（考拉記帳）

- 日期 → 帳單日期
- 交易分類 → 帳單類型（收入/支出）
- 父分類 + 子分類 → 收支項目（匹配不到會在預覽提示不完善）
- 流入/流出金額 → 金額（由帳單類型決定取哪一欄）
- 帳戶 → 帳戶（按名稱匹配；不存在會建立）
- 標籤 → 標籤（按名稱匹配/建立並綁定）
- 備註 → 備註
- 幣種代碼 → 帳單幣種（按 code 匹配；失敗則用帳本幣種）

---

## ⚠️ 注意事項

1. **不自動去重**：重複匯入同一份檔案會生成重複帳單，請避免多次匯入同一時間段。
2. **收支項目匹配**：按「父分類 + 子分類」匹配；匹配失敗會提示不完善，需要手動選擇後再匯入。
3. **帳戶有效性**：帳戶名稱為空或僅符號時，可能被視為無效資料並提示補全。
4. **檔案編碼**：支援 UTF-8/GBK；如出現亂碼，建議用 UTF-8 重新匯出或轉換後再匯入。

## 🔧 常見問題

### Q1：提示「表頭長度不對」？

請確認匯出的 CSV 第一行表頭為 **10 欄**。常見原因：

1. 不是貔貅記帳匯出的 CSV，欄位數不一致
2. 用 Excel/WPS 二次編輯後出現多餘分隔符導致欄位數變化
3. 另存為 CSV 時選了不相容格式（例如分號分隔）

### Q2：匯入後金額不對或為 0？

請確認：

1. 「交易分類」欄包含「支出/收入」關鍵字（決定取「流入金額」或「流出金額」）
2. 對應金額欄有值且為數字（帶 `-` 也可以，會自動去除）

### Q3：分類匹配不上怎麼辦？

可在預覽頁進入單筆手動選擇收支項目；或先在考拉記帳建立與匯出檔同名的收支項目後再重新解析。
