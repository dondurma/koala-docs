# 帳單報銷說明

## 1. 這是什麼功能

「報銷」用來記錄一筆支出後，後續由他人/公司把錢補回來的情況（例如差旅、辦公用品、代墊費用等）。

在考拉記帳中，報銷的核心邏輯是：

- 你先記一筆「支出」，並標記為「可報銷」
- 當這筆支出完成報銷時，系統會自動新增一筆「報銷入帳」的收入帳單，並把金額加回到你指定的帳戶

這樣做的好處是：

- 原支出仍然保留（方便追溯用途）
- 報銷回款也有記錄（方便核對入帳帳戶與時間）
- 統計口徑清晰：支出與報銷入帳分開記錄

## 2. 適用場景

- 公司報銷（交通、住宿、餐飲、辦公用品等）
- 朋友/家人代付後再轉帳給你（也可用報銷方式記錄）
- 代墊款項需要後續收回

## 3. 如何使用

### 3.1 建立「可報銷」的支出

1. 新增一筆支出帳單
2. 在建立/編輯頁面勾選「報銷」（或類似的「可報銷/待報銷」選項）
3. 儲存後，該帳單在列表中會顯示「待報銷/已報銷」等狀態提示

### 3.2 對支出執行「報銷」

1. 在帳單列表找到「待報銷」的支出
2. 對該帳單左滑，選擇「報銷」
3. 在報銷頁面中設定：
   - 金額：預設等於原支出金額，可改為實際報銷金額
   - 時間：預設今天，可改為實際入帳日期
   - 入帳帳戶：選擇報銷款實際打入的帳戶
   - 備註：可選
4. 點選「完成/儲存」

儲存後，會新增一筆「報銷入帳」的收入帳單，用來記錄回款。

## 4. 使用規則與注意事項

- 只有「支出」且已標記為「可報銷」的帳單才能進行報銷。
- 拆分與報銷互斥：已拆分的帳單（包含拆分後的子帳單/拆分容器）無法開啟報銷流程；已標記為可報銷的支出也無法再進行拆分。建議先確認是否需要報銷；如有需要，可先把費用拆分清楚，再將需要報銷的部分另外記為可報銷支出。
- 已經生成過「報銷入帳」的支出，預設不支援重複報銷（避免重複入帳）。
- 若你刪除了「報銷入帳」那筆收入記錄，原支出會回到「待報銷」狀態（可再次執行報銷）。
- 報銷入帳會計入收入統計；原支出仍會計入支出統計，這是為了讓收支流向更清晰。

## 5. 常見問題

### Q1：報銷和退款有什麼不同？

- 退款：針對一筆帳單發生退回，通常用來抵銷原帳單影響（新增一筆負數記錄）
- 報銷：針對一筆「可報銷的支出」，後續收到補回款（新增一筆報銷入帳的收入記錄）

### Q2：報銷款打到別的帳戶怎麼辦？

在報銷頁面把「入帳帳戶」改為實際入帳帳戶即可。

### Q3：只報銷了部分金額要怎麼記？

把報銷金額改為實際報銷金額即可。未報銷的差額仍會保留在原支出上，方便你後續核對。
