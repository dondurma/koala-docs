# 微信帳單匯入教學

## 📋 概述

本教學將指引你如何從微信匯出帳單，並匯入到考拉記帳 App。

---

## 📱 第一步：在微信中匯出帳單

### 步驟 1：打開微信帳單頁面

1. 打開微信 App
2. 點擊右下角 **「我」**
3. 點擊 **「服務」**（或 **「支付」**）
4. 點擊右上角 **「錢包」**
5. 點擊右上角 **「帳單」** 進入帳單頁

> 📝 **注意**：不同版本的微信入口可能略有不同。若找不到，可在微信搜尋框搜尋「帳單」。

### 步驟 2：下載帳單

1. 在帳單頁面點擊右上角 **「...」** 或 **「篩選」**，在底部彈窗點擊 **「下載帳單」**
2. 在「下載帳單」頁選擇 **「用於個人對帳」**
3. 選擇接收方式（**「微信」** 或 **「郵箱」**）並點擊確定
4. 選擇要匯出的時間範圍（例如：最近一個月、最近三個月）並點擊確定

> 💡 **提示**：
> - 建議一次匯出不超過 3 個月，避免檔案過大
> - 若需匯出更長時間，可分多次匯出

### 步驟 3：匯出前驗證

1. 選擇完成後點擊「下一步」
2. 按微信提示完成認證流程
3. 等待微信處理（可能需要幾秒）

> ⚠️ **重要**：
> - 匯出後，微信會透過郵件或微信發送帳單檔案
> - 若選擇郵箱接收，需先設定微信的郵箱地址（如尚未設定）

### 步驟 4：把檔案保存到裝置

1. 若選擇郵件：
   - 打開郵箱，找到微信發送的郵件
   - 下載附件（CSV 或 Excel）
   - 保存到裝置本機（檔案管理器可存取的位置）
2. 若選擇「保存到檔案」（如支援）：
   - 檔案會保存到下載資料夾
   - 記住保存位置

> 📝 **檔案位置提示**：
> - iOS：通常在「檔案」App 的「下載」資料夾
> - Android：通常在「下載」資料夾或「微信」資料夾

---

## 📱 第二步：在考拉記帳中匯入

### 步驟 1：進入匯入頁面

1. 打開考拉記帳 App
2. 點擊底部導覽列的 **「設定」**
3. 在設定頁面中找到 **「帳單匯入」**
4. 點擊進入帳單匯入頁

### 步驟 2：選擇匯入來源

1. 點擊 **「匯入來源」**
2. 在列表中選擇 **「微信」**
3. 確認選擇

> ⚠️ **重要**：必須選擇「微信」，否則系統無法正確解析檔案格式。

### 步驟 3：選擇檔案

1. 點擊 **「檔案路徑」**
2. 在檔案選擇器中找到並選擇微信匯出的帳單檔
3. 確認已選擇檔案（會顯示檔名）

> 📝 **檔案格式**：
> - 支援 CSV（`.csv`）
> - 支援 Excel（`.xlsx`、`.xls`）
> - 檔名通常包含「微信」或「WeChat」

### 步驟 4：關聯帳本

1. 點擊 **「關聯帳本」**
2. 選擇匯入目標帳本
3. 確認帳本選擇

> 💡 **提示**：若只有一個帳本，系統會自動關聯到預設帳本。

### 步驟 5：解析檔案

1. 點擊右上角 **「解析」**
2. 等待解析（可能需要幾秒）
3. 解析成功後會自動跳轉到預覽頁

> ⚠️ **如果解析失敗**：
> - 檢查檔案格式是否正確
> - 檢查是否選擇了「微信」作為匯入來源
> - 檢查檔案是否損壞
> - 嘗試重新從微信匯出檔案

### 步驟 6：預覽與編輯

解析成功後，你可以在預覽頁：

- **查看所有帳單記錄**：按日期分組顯示
- **編輯單筆記錄**：點擊記錄可修改分類、金額、時間、帳戶、標籤、備註
- **刪除無效記錄**：長按記錄可刪除
- **批量操作**：可選擇跳過無效記錄

### 步驟 7：匯入資料

1. 在預覽頁確認資料無誤後
2. 點擊 **「匯入」**
3. 等待匯入完成

## 📋 微信帳單檔案格式說明

### CSV 格式（標準格式）

微信匯出的 CSV 通常包含以下欄位：

| 欄名 | 說明 | 示例 |
|------|------|------|
| 交易時間 | 交易發生時間 | 2024-01-01 12:00:00 |
| 交易類型 | 交易類型 | 微信紅包 / 轉帳 / 消費等 |
| 交易對方 | 交易對方資訊 | 張三 / 商戶名稱 |
| 商品 | 商品描述 | 午餐 / 購物等 |
| 收/支 | 收入或支出 | 收入 / 支出 |
| 金額(元) | 交易金額 | 100.00 |
| 支付方式 | 支付方式 | 零錢 / 銀行卡 |
| 當前狀態 | 支付是否成功 | 支付成功/已轉帳/已到帳 |
| 交易單號 | 交易單號 | 4200001234567890 |
| 商戶單號 | 商戶單號 | 1234567890 |
| 備註 | 備註資訊 | 備註內容 |

### Excel 格式

Excel 的欄名與內容與 CSV 相同，只是檔案格式不同。

## ⚠️ 注意事項

### 1. 檔案格式要求

- **檔案編碼**：建議 UTF-8（微信匯出通常為 UTF-8）
- **檔案格式**：支援 CSV 與 Excel
- **檔案大小**：建議單檔不超過 10MB

### 2. 欄位映射（匯入行為）

系統會把微信欄位映射到考拉記帳欄位（概念如下）：

- 交易時間 → 帳單日期
- 收/支 → 帳單類型（收入/支出）
- 金額 → 帳單金額
- 支付方式 → 帳戶（按名稱匹配/建立）
- 交易對方/狀態/單號/備註等 → 會拼接到帳單備註

### 3. 不要手動修改帳單檔

不要手動修改微信帳單（包含但不限於修改/刪除表頭、或新增列），否則可能導致解析失敗。

## 🔧 常見問題

### Q1：找不到「下載帳單」選項？

可能原因：

1. 微信版本較舊，不支援匯出
2. 入口位置不同，可嘗試：
   - 在帳單頁點擊右上角「...」
   - 在「錢包」頁尋找「帳單」
   - 在微信搜尋框搜尋「帳單匯出」

### Q2：匯出後收不到郵件？

請檢查：

1. 微信是否已綁定郵箱
2. 郵箱地址是否正確
3. 郵件是否進入垃圾郵件
4. 可改用「保存到檔案」方式

### Q3：解析失敗怎麼辦？

請檢查：

1. 檔案格式是否正確（CSV/Excel）
2. 是否選擇「微信」作為匯入來源
3. 檔案是否損壞
4. 檔案編碼是否正確（建議 UTF-8）

### Q4：匯入後分類不正確？

這是正常現象，因為：

1. 微信分類與考拉記帳分類不一定完全匹配
2. 系統會嘗試自動匹配，但可能不完全準確
3. 建議在預覽頁手動調整，或匯入後批量修改

---

## 💡 使用技巧

1. **定期匯入**：建議每月匯入一次
2. **分類整理**：匯入後檢查並整理分類，方便統計
3. **帳戶管理**：先建立常用帳戶，避免自動建立不規範的帳戶名稱
4. **資料備份**：匯入前建議先備份現有資料
