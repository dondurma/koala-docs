# 心情打卡說明

## 📋 概述

考拉記帳在概覽頁提供「心情卡片」，讓你在記帳之餘順手記錄每天的心情，並以月檢視回顧。適合想同時關注消費與情緒狀態、或希望堅持每日打卡的使用者。

## 🚀 如何記錄心情

1. 打開考拉記帳 App，進入底部導覽列的 **「概覽」** 頁面
2. 找到 **「心情卡片」**（當月且今天尚未記錄時，卡片底部會出現三個選項）
3. 點擊 **開心 / 一般 / 難過** 中的任意一個，即可記錄今天的心情

> 📝 **注意**：
> - 每天只能記錄一次（以自然日為準）
> - 已記錄當天心情後，當天不再顯示選項，且**不支援在 App 內修改或刪除**
> - 只能記錄「當天」的心情，不支援補記或修改歷史日期

## 📅 查看月檢視

心情卡片會展示當月的記錄情況：

- 頂部顯示當月**已記錄天數 / 總天數**以及今天的心情
- 下方以網格展示當月每一天：已記錄的日子按心情著色（開心 / 一般 / 難過各一種顏色），未記錄的日子為淺色
- 未來的日期不參與展示

> 💡 **提示**：當概覽頁切換到其他月份時，卡片會顯示該月的記錄情況（不顯示「今日」資訊）。

## 🎨 個性化設定

進入 **「設定」→「個性化」**，可以調整心情相關選項：

- **顯示心情卡片**：開關控制概覽頁是否顯示心情卡片（預設顯示）
- **心情顏色**：自訂「開心 / 一般 / 難過」三種心情對應的顏色

> 📝 **注意**：心情顏色在「統計頁分享 → 心情記錄」產生的熱力圖中同樣生效。

## 📤 分享心情記錄

1. 打開底部導覽列的 **「統計」** 頁面
2. 在頁面底部點擊 **「分享當前頁 >」**
3. 在彈出的選單中選擇 **「心情記錄」**
4. 產生心情熱力圖後，透過系統分享面板傳送或儲存

> ⚠️ **注意**：
> - 「心情記錄」分享僅在時間維度為「按月」或「按年」時可用（自訂時間範圍下不顯示該選項）
> - 心情記錄與帳單資料互相獨立，不影響帳單統計

## 🔄 多裝置同步

- **登入帳號後**：心情記錄會隨帳號同步，多裝置登入同一帳號即可看到相同的心情記錄
- **未登入時**：心情記錄只保存在本機，解除安裝或換裝置後無法復原

> 📝 心情記錄按帳號歸屬同步，與帳本資料相互獨立。

## 🔧 常見問題

### Q1：記錄錯了心情可以改嗎？

目前每天僅記錄一次，記錄後不支援在 App 內修改或刪除。請在記錄前確認。

### Q2：可以補記前幾天的心情嗎？

目前只支援記錄「當天」的心情，不支援補記或修改歷史日期。

### Q3：為什麼概覽頁看不到心情卡片？

請檢查 **「設定」→「個性化」→「顯示心情卡片」** 是否已開啟。

### Q4：換裝置後心情記錄還在嗎？

已登入並完成同步的情況下，重新安裝後登入同一帳號會隨帳號同步復原；未登入時資料只在本機。
