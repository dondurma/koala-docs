# 預算管理說明

## 📋 概述

預算管理是**會員功能**。你可以給某個月設一個總預算，也可以給具體分類單獨設預算，在概覽頁直接看到「這個月還能花多少」。

## 🚀 開啟入口

進入 **「設定」→「預算管理」**。

> 📝 非會員點入口會提示「會員專屬功能」，開通會員後即可使用。

## 💰 設定月預算

1. 點「月預算」右側的**鉛筆**圖示
2. 用計算機輸入金額，點「完成」
3. 想清空時輸入 0 並完成，會二次確認「清空本月預算」

> 📝 單月預算上限為 9,999,999.99。預算按月份獨立，換月不會互相影響。

## 🗂 設定分類預算

1. 點「新增分類預算」
2. 選擇 **一級分類** 或 **二級分類**，再點具體分類
3. 輸入金額並完成

規則：

- 同一棵分類樹**只能設一層**：已經給「伙食」設了預算，就不能再給它的子分類設；反過來也一樣，衝突時會直接提示。
- 分類列會顯示「已消費 / 預算」和進度條，**點進去**可以看這個分類本月的帳單明細。

## 📊 概覽頁進度條

概覽頁「月度收支概覽」卡片下方會顯示預算金額、百分比和進度條：

- **低於 50%**：安全色
- **50% ~ 100%**：預警色
- **超過 100%**：超支色，並顯示「超支」

點一下這塊區域可以直接進入同月份的預算管理。三種顏色都可以在預算設定裡自訂。

## 🔁 結餘結轉與超支扣除

進 **「設定」→「預算管理」→ 右上角滑桿圖示**，裡面有四個開關：

- **預算開關**：關閉後概覽頁不再顯示預算進度條（資料仍然保留）
- **分類預算計入月預算**：分類預算的總和會加到月預算上，影響概覽的總額與百分比
- **結餘結轉到下期**：本月沒花完的錢帶到下個月
- **超支從下期扣除**：本月超支的部分從下個月扣掉

> 📝 只有**已結帳的月份**才會把結餘真正傳給下個月。當月只顯示「本月剩餘 ¥xx・月末結算後轉入下月」這樣的預計提示。
> 📝 結轉起點是你**第一次開啟該開關的那個月**，不會回溯更早的月份。

## 📱 多裝置同步

登入帳號後，預算會隨帳號同步：

- 重開 App、停留在「概覽」頁時會自動同步，不必手動重新整理
- 預算為會員功能，未登入時無法使用

## 🔧 常見問題

### Q1：概覽頁為什麼看不到預算進度條？

先確認三件事：預算開關是否開啟、當月是否設過預算、目前帳號是否為會員。三者缺一都不會顯示。

### Q2：為什麼某個月的預算改了，別的月份沒變？

預算按月獨立儲存，需要每個月分別設定。

### Q3：結轉為什麼沒把更早月份的結餘算進來？

結轉起點固定為「首次開啟結餘結轉的那個月」，屬預期行為；需要更早的結餘時，只能從起點月開始累積。

### Q4：刪掉分類後，它的預算還在嗎？

刪除分類時會一併清掉對應預算，兩端裝置同步後都不再顯示。
