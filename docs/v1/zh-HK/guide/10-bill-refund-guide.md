# 帳單退款說明

## 1. 這是什麼功能

「退款」用來記錄一筆帳單發生退款後的資金變化，並自動抵銷統計上的金額影響。

系統的做法是：在原帳單的基礎上，新增一筆「金額為負數」的退款記錄。

- 原帳單是支出：退款記錄同樣是「支出」，但金額為負數，用來抵銷原支出
- 原帳單是收入：退款記錄同樣是「收入」，但金額為負數，用來抵銷原收入

同時，退款記錄會自動加上「退款」標籤，方便之後篩選與核對。

## 2. 適用場景

- 購物退款、退貨退款
- 帳單部分退款（只退一部分金額）
- 收入回退（例如轉帳撤回、收款退回）

## 3. 如何使用

1. 進入「帳單列表」找到要退款的帳單
2. 對該帳單左滑，選擇「退款」
3. 在退款頁面中設定：
   - 金額：預設等於原帳單金額，可改為部分退款金額
   - 時間：預設今天，可改為實際退款發生的日期
   - 標籤：預設沿用原帳單的標籤，並自動追加「退款」標籤
   - 備註：可選，用作補充說明
4. 點選「確定/完成」儲存

儲存後，列表會新增一筆退款記錄，用來抵銷對應的金額影響。

## 4. 使用規則與注意事項

- 退款金額建議填寫「實際退回的金額」，不需要手動加負號。
- 支出退款與收入退款都會以「負數金額」的方式記錄，因此在統計中會自動抵銷。
- 支援多次退款：同一筆帳單若分多次退款，可以重複操作，每次會生成一筆退款記錄。
- 若你刪除了退款記錄，對應的抵銷效果也會消失（統計會回到未退款狀態）。

## 5. 常見問題

### Q1：部分退款要怎麼記？

在退款頁面把金額改成實際退款金額即可。你也可以多次退款，每次填各自的退款金額。

### Q2：退款會影響原帳單嗎？

原帳單本身不會被修改金額；退款是以「新增一筆退款記錄」的方式實作。這樣可以保留原始消費記錄，同時讓統計結果可解釋、可追溯。

### Q3：怎麼快速找到所有退款？

退款記錄會自動帶「退款」標籤，你可以在篩選/搜尋中按標籤查看。
