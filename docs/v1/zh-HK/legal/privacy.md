考拉記帳（以下簡稱「本應用」）非常重視你的個人資料保障。本《考拉記帳私隱政策》（以下簡稱「本政策」）旨在說明我們如何收集、使用、儲存、共享與保護你的個人資料，以及你如何行使相關權利。

請你在使用本應用前仔細閱讀並理解本政策。你點擊「同意／接受」或繼續使用本應用，即表示你已充分理解並同意本政策。

## **2. 我們如何收集和使用個人資料**

我們會遵循合法、正當、必要原則，基於實現產品功能、保障運行安全、改善體驗等目的收集與使用資料。根據你是否登入、是否使用特定功能，我們收集的資料類型會有所不同。

### **2.1 你主動提供的資料**

1. 帳號與身份資料（如適用）

● 當你使用第三方帳號登入（例如「使用 Apple 登入」）時，我們可能會取得該第三方回傳的必要識別資料，用於完成登入與帳號管理。

2. 你在使用過程中輸入／匯入的資料

● 例如你在本應用內記錄的帳單、分類、標籤、備註、匯入的檔案內容等。此類資料一般儲存在你的裝置本機，或在你啟用同步功能時（如有）儲存在伺服器端。

### **2.2 我們自動收集的資料**

為保障本應用正常運行、進行統計分析、提升穩定性與安全性，我們可能會自動收集以下資料（僅在取得你的授權同意後，才會正式初始化相關 SDK 並進行上報）：

● 裝置資料：裝置型號、裝置名稱、作業系統版本、應用版本、語言設定等。

● 裝置識別碼：可能包括 IDFA（如你授權）、OPENUDID、GUID、IP 位址、MAC 位址（受系統限制）等，用於統計分析、反作弊、故障診斷與安全保障。

● 網絡資料：網絡類型、電訊商資料（如系統可取得）、網絡請求失敗資料等，用於優化連線品質與穩定性分析。

● 記錄資料：啟動、崩潰／異常堆疊、效能資料、頁面瀏覽路徑等，用於定位問題與提升效能體驗。

### **2.3 權限與功能對應關係（概述）**

本應用在提供特定功能時，可能會申請或使用裝置權限。不同系統版本的權限名稱與彈窗可能不同，實際以系統提示為準：

● 網絡權限：用於聯網請求、同步、統計分析等。

● 相簿／檔案存取（如你使用匯入匯出、選擇檔案、分享、儲存圖片等）：用於讓你選取或儲存檔案。

● 購買／訂閱能力（如你使用應用內購買）：用於完成付款、查詢訂閱狀態等。

我們不會在與你選擇的功能無關的情況下，主動請求超出必要範圍的權限。

## **3. 第三方 SDK 說明與資料共享**

為實現統計分析與應用效能監控等能力，本應用整合了第三方 SDK。第三方 SDK 可能會收集你的相關資料。我們僅會在取得你的授權同意後，才會呼叫相關 SDK 的正式初始化介面，使其開始蒐集與上報資料；若你不同意，我們不會進行正式初始化。

### **3.1 友盟+ SDK（流動統計／應用效能監控）**

我們整合【友盟+ SDK】用於統計分析與應用效能監控。友盟+ SDK 可能會收集以下資料以提供統計分析服務，並透過地理位置校準報表資料準確性，以及提供基礎反作弊能力：

● 裝置資料與裝置識別：MAC 位址、唯一裝置識別碼（IDFA / OPENUDID / GUID 等）

● 網絡資料：IP 位址

友盟+ SDK 的正式初始化將在你同意本政策後執行；在你不同意的情況下，我們不會呼叫友盟+ SDK 的正式初始化介面。

## **4. 我們如何儲存與保護你的資料**

1. 儲存地點與期限

● 我們會在實現本服務目的所需的期限內保留你的個人資料，法律法規另有規定的除外。

● 你的記帳資料可能主要儲存在本機資料庫中；若你啟用雲端同步（如有），相關資料可能會被上傳並儲存在伺服器端。

2. 安全措施

● 我們會採取合理可行的技術與管理措施保護你的資料安全，防止資料外洩、毀損或遺失。

● 儘管如此，互聯網環境並非絕對安全；如發生不可抗力或非因我們原因導致的安全事件，我們將依法依規處理。

## **5. 你的權利**

你可按法律法規要求行使以下權利（以本應用支援能力為準）：

● 查閱與更正：你可以在應用內查閱並修改你輸入的資料。

● 刪除：你可以在應用內刪除相關記錄；如涉及雲端資料（如有），我們會按產品能力提供同步刪除或帳號註銷方式。

● 撤回同意：你可以在系統或應用設定中撤回授權或關閉相關開關。撤回同意不影響撤回前基於你授權已進行的資料處理行為之合法性。

## **6. 未成年人保護**

若你為未滿 14 歲的未成年人，請在法定監護人陪同下閱讀，並在其同意與指導下使用本應用。我們將按照法律法規保護未成年人的個人資料。
