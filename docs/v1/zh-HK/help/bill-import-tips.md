# 帳單匯入注意事項

匯入帳單前，請先了解以下幾點，避免中途中斷或資料不完整。

## 一次不要匯入太多

- 單次匯入建議**不超過 1000 條**；超過請**分批匯入**（例如每次 500~1000 條）。
- 免費使用者全帳本帳單總數上限為 **300 條**，會員不限。資料量較大時，匯入前請確認剩餘可記帳條數。

## 資料量較大時請耐心等候

- 解析與匯入都需要時間。條數越多，等待越久；接近或超過 1000 條時可能需要較長時間（數十秒甚至更久）。
- 期間請不要認為「卡住了」，耐心等待進度完成即可。

## 匯入過程中不要離開頁面

- 匯入進行中，請**停留在目前頁面**：不要返回、不要切換到其他 App、不要鎖屏或強制關閉 App。
- 中途離開可能導致**本次匯入中斷**，出現只匯入了一部分、或需要重新匯入的情況。

## 匯入完成後

- 匯入完成後，建議手動同步一次，確保資料已上傳。
- 請在帳單列表中抽查幾筆，確認金額、分類、日期無誤。
