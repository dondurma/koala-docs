# 更新紀錄

> 本頁用於記錄考拉記帳每次上架版本的更新內容。並按時間倒序維護（最新版本放在最前面）。

## 2026-09-26 v1.0.7（31）

### 修正問題

1. 報銷入帳的帳單不會再無故消失，換機或重新安裝後依然存在。
2. 換帳號登入後，新帳號的同步不會再帶著上一個帳號的失敗記錄。
3. 修正同步偶爾長時間卡住不動、或整批帳單一直拉不下來的問題。
4. 修正個別分類、標籤、轉帳改動一直同步不上去、或兩部裝置上顯示不一致的問題。

## 2026-09-15 v1.0.2（25）

### 修正問題

1. 修正拆分帳單在標籤統計與匯出時金額重複計算的問題
2. 修正定時記帳在設定的結束時間之後仍會繼續記帳的問題
3. 修正子分類移動到其他分類後，其他裝置無法同步的問題
4. 優化帳單列表捲動與頁面返回的穩定性
5. 修正部分韓語文案

## 2026-09-10 v1.0.1（24）

### 修正問題

1. 修正帳單匯入－數據預覽頁刪除帳單卡頓問題。

## 2026-09-02 v1.0.0（23）

## 2026-05-22 v1.0.0

### 新增功能

1. 支援帳單匯入：模板／微信／支付寶／貔貅／iCost。

3. 支援本位幣與匯率顯示切換。
4. 支援雲端備份與同步。
5. 支援帳單拆分、退款、報銷與定時記帳。
6. 支援統計圖表、FAQ 與幫助檔案。
