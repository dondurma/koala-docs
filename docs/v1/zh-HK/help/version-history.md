# 更新紀錄

> 本頁用於記錄考拉記帳每次上架版本的更新內容。並按時間倒序維護（最新版本放在最前面）。

## 2026-10-05 v1.1.0（32）

### 新增功能

1. 新增「牛皮紙」主題：復古紙張質感，整個 App 更有味道。
2. 新增復古字體、倒角大小設定，風格隨手可調。
3. 新增多款個人卡片背景，個人主頁隨心裝扮。
4. 新增帳單小票：一鍵把帳單做成精美小票，分享更方便。
5. 完善使用指南，並在多個頁面標題欄加上「?」幫助入口。
6. 收支項按使用頻率自動排序，常用的排在前面。
7. 雲同步狀態更直觀：有資料未同步時會給出提示。
8. 更新了 App 圖示。

### 修正問題

1. 大幅提升帳單匯入的解析速度，大檔案匯入不再久等。
2. 修正部分介面顯示與文案細節。

## 2026-09-26 v1.0.7（31）

### 修正問題

1. 報銷入帳的帳單不會再無故消失，換機或重新安裝後依然存在。
2. 換帳號登入後，新帳號的同步不會再帶著上一個帳號的失敗記錄。
3. 修正同步偶爾長時間卡住不動、或整批帳單一直拉不下來的問題。
4. 修正個別分類、標籤、轉帳改動一直同步不上去、或兩部裝置上顯示不一致的問題。
