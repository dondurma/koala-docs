# 圖標與關鍵詞說明

## 關鍵詞怎麼用？

「關鍵詞」是收支項的別名 / 同義詞，用於記賬時更快找到對應的收支項。

- 在「收支項編輯頁」為收支項填寫關鍵詞，多個關鍵詞用豎線 `|` 分隔，例如：`早餐|早飯|早點`。
- 在**記一筆**頁面上方的**搜尋框**輸入內容時，會同時匹配：收支項名稱、其他語言譯名，以及你填寫的關鍵詞。
- **列表模式**與**圖標模式**兩種記一筆頁面都適用。

> 💡 例如：給「餐飲 / 早餐」填關鍵詞「早飯|早點」後，在記一筆搜尋框輸入「早飯」即可直接命中。
