# AssistiveTouch Guide

## 1. Open "Settings", select "Accessibility"

![1|400](./images/1-en.png)

## 2. In "Accessibility", find "Touch" and tap it

![2|400](./images/2-en.png)

## 3. In "Touch", find "AssistiveTouch" and turn it on

![5|400](./images/5-en.png)

## 4. Still in "AssistiveTouch", go to "Custom Actions" → "Single-Tap", scroll to the bottom and select "考拉快捷记账" under Shortcuts

![4|400](./images/4-en.png)
