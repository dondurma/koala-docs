# Scheduled Accounting

## 1. What this feature is

Scheduled accounting lets you set up rules for recurring income/expenses (such as rent, utilities, subscriptions, and salary). Koala will automatically create bills based on those rules, reducing repetitive manual entry.

## 2. When to use it

- Monthly rent, mortgage payments, credit card repayments
- Weekly commuting costs or fixed meal allowances
- Monthly subscriptions (streaming, cloud storage, etc.)
- Monthly fixed income (salary, allowances, etc.)

## 3. How to use it

1. Go to **Settings** and find **Scheduled accounting**
2. Create a new schedule rule and fill in:
   - Type: Expense / Income
   - Category
   - Amount
   - Account
   - Tags and note (optional)
   - Frequency: Daily / Weekly / Monthly (choose the date or weekday based on the rule)
   - Start/end date: start date is required; end date is optional (auto stops when it expires)
3. After saving, the rule will appear in the scheduled accounting list
4. When the trigger time arrives, Koala will generate bills based on the rule

## 4. Rules and notes

- Bills generated by scheduled accounting are the same as manually created bills: they appear in the list and are included in statistics.
- If you don’t open the app for a long time, some devices may not generate bills exactly on time. The next time you open the app, Koala will catch up and create any due bills that were not generated (to avoid missing entries).
- Review your rules periodically to ensure the amount, category, and account still match reality (for example, rent changes or you switch cards).
- After you pause/terminate a rule, no more bills will be created. Re-enabling it will continue from the next cycle.

## 5. FAQ

### Q1: What if a scheduled bill was generated incorrectly?

Scheduled bills can be edited or deleted just like normal bills. If it happens often, adjust the corresponding rule (amount/frequency/account, etc.).

### Q2: If I change a rule, will previously generated bills update automatically?

No. Rule changes only affect bills generated in the future. Historical bills remain unchanged for traceability.

### Q3: Will multiple bills be generated on the same day?

If you have multiple rules, Koala will generate bills for each rule. For the same rule, Koala tries to avoid generating duplicates.
