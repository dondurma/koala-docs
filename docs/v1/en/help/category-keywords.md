## How Do Keywords Work?

A keyword is an alias or synonym for an income/expense item, helping you find the right one faster when recording a bill.

- Add keywords to an income/expense item on its edit page. Separate multiple keywords with a vertical bar `|`, for example: `breakfast|morning meal`.
- When you type in the **search box** at the top of the **Add** page, it matches the item name, its translations in other languages, and the keywords you entered.
- This applies to both the **List Mode** and **Icon Mode** Add pages.

> 💡 For example: after adding the keywords `morning meal|brekkie` to "Food / Breakfast", typing "morning meal" in the Add page search box finds it directly.
