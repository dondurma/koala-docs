## **2. 我们如何收集和使用个人信息**

我们会遵循合法、正当、必要原则，出于实现产品功能、保障运行安全、改进体验等目的收集与使用信息。根据你是否登录、是否使用特定功能，我们收集的信息类型会有所不同。

### **2.1 你主动提供的信息**

​            1.     账号与身份信息（如适用）

​                ● 当你使用第三方账号登录（例如 Apple 登录）时，我们可能会获得该第三方返回的必要标识信息，用于完成登录与账号管理。

​            2.     你在使用过程中输入/导入的数据

​                ● 例如你在本应用内记录的账单、分类、标签、备注、导入的文件内容等。这些数据一般存储在你的设备本地或按你启用的同步能力存储于服务器侧（如有）。

### **2.2 我们自动收集的信息**

为保障本应用正常运行、诊断崩溃、提升稳定性与安全性，我们可能会自动收集以下信息（在取得你的授权同意后才会进行相关 SDK 的正式初始化与上报）：

​                ● 设备信息：设备型号、设备名称、操作系统版本、应用版本、语言设置等。

​                ● 设备标识：本应用生成的设备标识与 IP 地址，用于云同步的设备归属识别、故障诊断与安全保障；我们不会采集 IDFA、MAC 地址等广告标识。

​                ● 网络信息：网络类型、运营商信息（如系统可获取）、网络请求失败信息等，用于优化连接质量与稳定性分析。

​                ● 日志信息：启动、崩溃/异常堆栈、性能数据、页面访问路径等，用于定位问题与提升性能体验。

### **2.3 权限与功能对应关系（概述）**

本应用在提供特定功能时，可能会申请或使用设备权限。不同系统版本的权限名称与弹窗可能不同，实际以系统提示为准：

​                ● 网络权限：用于联网请求、同步、统计分析等。

​                ● 相册/文件访问（如你使用导入导出、选择文件、分享、保存图片等）：用于让你选取或保存文件。

​                ● 购买/订阅能力（如你使用内购）：用于完成支付、查询订阅状态等。

我们不会在与你选择的功能无关的场景下，主动请求超出必要范围的权限。

## **3. 第三方 SDK 说明与信息共享**

为实现崩溃诊断能力，本应用集成了第三方 SDK（Sentry）。该 SDK 仅在你已同意本政策、且应用界面语言为非中文时才会初始化；条件不满足时，我们不会调用其初始化接口。

### **3.1 Sentry SDK（崩溃诊断）**

我们集成 Sentry（服务商：Functional Software, Inc.，数据存储于欧盟区域）用于收集崩溃诊断信息，以定位并修复闪退与异常。Sentry 可能收集：

● 崩溃与异常信息：崩溃堆栈、异常类型与描述、线程与寄存器等诊断信息

● 设备与运行环境：设备型号、操作系统版本、应用版本与构建号、界面语言

● 崩溃上下文：崩溃发生时间、发布版本标识（release）与构建号（dist）

我们不会向 Sentry 发送你的记账记录、账户标识、广告标识（如 IDFA）或联系方式，也不会将其用于跨应用追踪、广告投放或用户画像。相关数据在 Sentry 侧保留 90 天。
