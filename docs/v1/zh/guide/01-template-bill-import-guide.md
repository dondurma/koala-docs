# 模版账单导入指南

## 📋 概述

考拉记账支持从外部文件导入账单数据，方便您快速迁移历史账单记录。目前支持以下导入方式：

- **模版文件导入**：使用标准格式的 CSV 文件导入
- **微信账单导入**：直接导入微信导出的账单文件
- **支付宝账单导入**：直接导入支付宝导出的账单文件
- 貔貅记账App账单导入：直接导入貔貅app导出的csv格式的账单文件
- iCost记账App账单导入：直接导入iCost App导出的xlsx文件格式的账单文件

---

## 📁 支持的文件格式

- **CSV 文件**（`.csv`）：支付宝、貔貅、模版账单
- **Excel 文件**（`.xlsx`、`.xls`）：微信账单、iCost账单

## 🚀 快速开始

### 步骤 1：进入导入页面

1. 打开考拉记账 App
2. 点击底部导航栏的 **"设置"** 图标
3. 在设置页面中找到 **"账单导入"** 选项
4. 点击进入账单导入页面

### 步骤 2：选择导入来源

在导入页面中，您需要选择账单的来源类型：

- **模版文件**：适用于标准格式的 CSV 文件
- **微信**：适用于微信导出的账单文件
- **支付宝**：适用于支付宝导出的账单文件
- 貔貅记账：适用于貔貅记账app导出的账单文件
- iCost：适用于iCost app导出的账单文件

> ⚠️ **重要**：请务必选择正确的导入来源，否则可能导致数据解析失败。

### 步骤 3：选择文件

1. 点击 **"文件路径"** 选项
2. 在文件选择器中选择要导入的文件
3. 确认文件已选择（会显示文件名）

> 📝 **注意**：
> - 文件必须保存在设备本地（可通过文件管理器访问）
> - 确保文件格式正确（CSV 或 xlsx）
> - 确保文件未损坏

### 步骤 4：关联账本

1. 点击 **"关联账本"** 选项
2. 选择要将账单导入到哪个账本
3. 确认账本选择

> 💡 **提示**：如果只有一个账本，系统会自动关联到默认账本。

### 步骤 5：解析文件

1. 点击右上角的 **"解析"** 按钮
2. 等待系统解析文件（可能需要几秒钟）
3. 解析成功后，会自动跳转到预览页面

> ⚠️ **如果解析失败**：
> - 检查文件格式是否正确
> - 检查是否选择了正确的导入来源
> - 检查文件是否损坏
> - 尝试重新导出文件

### 步骤 6：预览和编辑

解析成功后，您可以在预览页面中：

- **查看所有账单记录**：按日期分组显示
- **编辑单条记录**：点击记录可以修改分类、金额、时间等
- **删除无效记录**：长按记录可以删除
- **批量操作**：可以选择跳过无效记录

> 📝 **建议**：在导入前，先预览数据，确保数据正确后再导入。

### 步骤 7：导入数据

1. 在预览页面确认数据无误后
2. 点击 **"导入"** 按钮
3. 等待导入完成（可能需要几秒钟）
4. 导入成功后，会显示导入结果

> ✅ **导入成功**：所有有效记录已导入到账本中，您可以在账单列表中查看。

## 📝 模版文件格式说明

如果您想使用模版文件导入，需要按照以下格式准备 CSV 文件：

### CSV 文件格式要求

1. **文件编码**：支持 UTF-8 或 GBK 编码
2. **分隔符**：使用逗号（`,`）分隔
3. **表头**：第一行必须包含表头

### 标准格式示例

```csv
日期,类型,金额,分类,账户,备注,标签
2024-01-01,支出,100.00,餐饮,现金,午餐,工作餐
2024-01-02,收入,5000.00,工资,银行卡,月薪,
```

### 字段说明

| 字段 | 说明 | 必填 | 示例 |
|------|------|------|------|
| 交易日期 | 账单日期，格式：yyyy/MM/dd | ✅ | 2026/01/01 |
| 交易分类 | 支出或收入 | ✅ | 支出 / 收入 |
| 收支大类 | 一级分类名称                                           | ✅    | 伙食        |
| 收支小类 | 二级分类名称，所属于一级分类的子分类 | ✅ | 早餐 |
| 流入金额 | 账单金额，数字格式，如果“交易分类”为“收入”就在此栏填写 | ✅    | 100.00      |
| 流出金额 | 账单金额，数字格式，如果“交易分类”为“支出”就在此栏填写 | ✅    | 15          |
| 资金账户 | 账户名称，尽量填写app中已存在的账户名称                | ✅    | 默认账户    |
| 备注     | 账单备注                                               | ❌    | 午餐        |
| 标签     | 标签名称，多个用逗号分隔 | ❌ | 工作餐,聚餐 |

### 下载模版文件

1. 在导入页面点击 **"下载模版文件"** 按钮
2. 系统会下载一个示例 CSV 文件
3. 您可以参考模版文件的格式来准备自己的数据

## ⚠️ 注意事项

### 1. 数据格式要求

- **日期格式**：必须为 `YYYY/MM/DD` 格式（如：2026/01/01）
- **金额格式**：必须为数字格式，支持小数点（如：100.00）
- **交易分类**：必须为 "支出" 或 "收入"
- **分类和账户**：必须在 App 中已存在，否则导入时会自动创建

### 2. 数据验证

导入前，系统会自动验证数据：

- ✅ **有效记录**：格式正确，可以正常导入
- ⚠️ **无效记录**：格式错误，需要修改后才能导入
- ❌ **跳过记录**：可以选择跳过无效记录，只导入有效数据

### 3. 重复数据处理

- 建议在导入前先检查是否有重复数据

### 4. 大量数据导入

- 如果数据量很大（超过 1000 条），建议分批导入
- 导入过程中请保持 App 在前台运行
- 导入完成后，建议手动同步一次数据

## 🔧 常见问题

### Q1：解析失败怎么办？

**A：** 请检查以下几点：
1. 文件格式是否正确（CSV 或 xlsx）
2. 是否选择了正确的导入来源
3. 文件是否损坏
4. 文件编码是否正确（建议使用 UTF-8）

### Q2：导入后数据不完整？

**A：** 可能的原因：

1. 部分记录格式错误，被系统跳过
2. 分类或账户不存在，需要先创建
3. 建议在预览页面检查无效记录

### Q3：可以导入图片吗？

**A：** 目前不支持导入图片。

### Q4：导入后可以修改吗？

**A：** 可以。导入后，您可以在账单列表中编辑或删除任何记录。

### Q5：支持批量导入多个文件吗？

**A：** 目前不支持。每次只能导入一个文件。如果需要导入多个文件，请逐个导入。
