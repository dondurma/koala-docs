# 预算管理说明

## 📋 概述

预算管理是**会员功能**。你可以给某个月设一个总预算，也可以给具体分类单独设预算，在概览页直接看到「这个月还能花多少」。

## 🚀 打开入口

进入 **"设置" → "预算管理"**。

> 📝 非会员点入口会提示「会员专属功能」，开通会员后即可使用。

## 💰 设置月预算

1. 点「月预算」右侧的**铅笔**图标
2. 用计算器输入金额，点「完成」
3. 想清空时输入 0 并完成，会二次确认「清空本月预算」

> 📝 单月预算上限为 9,999,999.99。预算按月份独立，换月不会互相影响。

## 🗂 设置分类预算

1. 点「添加分类预算」
2. 选择 **一级分类** 或 **二级分类**，再点具体分类
3. 输入金额并完成

规则：

- 同一棵分类树**只能设一层**：已经给「伙食」设了预算，就不能再给它的子分类设；反过来也一样，冲突时会直接提示。
- 分类行会显示「已消费 / 预算」和进度条，**点进去**可以看这个分类本月的账单明细。

## 📊 概览页进度条

概览页「月度收支概览」卡片下方会显示预算金额、百分比和进度条：

- **低于 50%**：安全色
- **50% ~ 100%**：预警色
- **超过 100%**：超支色，并显示「超支」

点一下这块区域可以直接进入同月份的预算管理。三种颜色都可以在预算设置里自定义。

## 🔁 结余结转与超支扣除

进 **"设置" → "预算管理" → 右上角滑杆图标**，里面有四个开关：

- **预算开关**：关闭后概览页不再显示预算进度条（数据仍然保留）
- **分类预算计入月预算**：分类预算的总和会加到月预算上，影响概览的总额与百分比
- **结余结转到下期**：本月没花完的钱带到下个月
- **超支从下期扣除**：本月超支的部分从下个月扣掉

> 📝 只有**已结账的月份**才会把结余真正传给下个月。当月只显示「本月剩余 ¥xx · 月末结算后转入下月」这样的预计提示。
> 📝 结转起点是你**第一次打开该开关的那个月**，不会回溯更早的月份。

## 📱 多设备同步

登录账号后，预算会随账号同步：

- 重开 App、停留在「概览」页时会自动同步，不必手动刷新
- 预算为会员功能，未登录时无法使用

## 🔧 常见问题

### Q1：概览页为什么看不到预算进度条？

先确认三件事：预算开关是否打开、当月是否设过预算、当前账号是否为会员。三者缺一都不会显示。

### Q2：为什么某个月的预算改了，别的月份没变？

预算按月独立存储，需要每个月分别设置。

### Q3：结转为什么没把更早月份的结余算进来？

结转起点固定为「首次打开结余结转的那个月」，属预期行为；需要更早的结余时，只能从起点月开始累积。

### Q4：删掉分类后，它的预算还在吗？

删除分类时会一并清掉对应预算，两端设备同步后都不再显示。
