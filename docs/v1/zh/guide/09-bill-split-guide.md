# 账单拆分说明

## 1. 这是什么功能

当一笔消费同时包含多个用途（例如“超市购物”里既有水果也有日用品），可以把这一笔账单拆成多笔子账单，让分类统计更准确。

拆分完成后：

- 您会看到多笔“子账单”（每笔有自己的分类、金额、备注）。
- 原始那笔账单会变成“拆分容器”，不再参与列表展示与统计汇总，避免金额重复计算。

## 2. 适用场景

- 一笔付款包含多个类别（餐饮 + 日用品、交通 + 停车等）
- 需要更精细的分类统计、预算对比
- 同一张小票想拆给不同的分类/标签

## 3. 如何使用

1. 进入“账单列表”找到要拆分的账单
2. 对该账单进行左滑操作，选择“拆分”
3. 在“拆分账单”页面中：
   - 点击子项的“分类”选择需要的收支项
   - 点击“金额”填写每个子项的金额
   - 备注可选填（用于补充说明）
   - 需要更多项时，点击“添加一项”
4. 确保“剩余待分配金额”为 0（表示子项合计刚好等于原始账单金额）
5. 点击右上角“完成/保存”提交

## 4. 使用规则与注意事项

- 子项金额合计必须等于原始账单金额，否则无法保存。
- 每一条子项都需要选择分类，且金额必须大于 0。
- 拆分后的统计口径以子账单为准；原始账单不再计入统计。
- 拆分支持多级拆分：子账单也可以再次拆分；最终统计以最末级子账单为准。
- 拆分与报销互斥：已标记“可报销/待报销/已报销”的支出账单不能进行拆分；已拆分的账单也无法开启报销流程。建议先确定这笔支出是否需要走报销，再决定是否拆分。

## 5. 常见问题

### Q1：拆分后原始账单去哪了？

为了避免金额重复统计，原始账单会被标记为“拆分容器”，通常不会在列表中展示；实际统计会以拆分后的子账单为准。

### Q2：能只拆一部分吗？

可以。您可以把其中一项保留为“其他/原分类”，金额填写为剩余金额即可。核心要求是所有子项金额合计等于原始金额。

### Q3：拆分后还能改吗？

一般建议直接修改拆分后的子账单（金额/分类/备注等）。如果需要重新拆分，通常做法是先删除相关子账单再重新操作。
