# 会员说明

## 📋 概述

考拉记账提供会员服务（按月/按年订阅或一次性买断），用于解锁多账本、多币种、账单导出、账单拆分、定时记账等进阶能力；同时免费用户也能使用记账、云同步、快捷记账等核心功能。

## 💎 会员权益

开通会员后可解锁：

- **多账本**：创建与管理多个账本
- **多币种**：记录非本位币账单
- **账单导出**：将账单导出为 CSV
- **账单拆分**：把一笔账单拆成多笔子账单
- **定时记账**：按周期自动生成账单
- **无限记账次数**：不受免费额度限制

其中，**快捷记账、云同步**对所有用户开放，无需会员。

## 🚀 开通与恢复

### 开通会员

1. 打开考拉记账 App，进入 **"设置"**
2. 点击页面顶部的用户卡片（未登录需先登录 Apple 账号）
3. 进入会员页，选择 **按月** 订阅、**按年** 订阅或 **永久会员**（一次性买断）
4. 按 App Store 提示完成支付

> 💡 **提示**：会员价格以 App Store 实际展示与扣费为准；按年订阅通常会显示"折合每月"金额。

> ⚠️ **仅针对已有订阅的用户**：如果你当前正在按月/按年订阅，购买永久会员不会自动替你取消该订阅，Apple 也不会退还已付订阅费；请先在系统 **"设置 → Apple ID → 订阅"** 中取消，否则订阅到期仍会继续续费。此前从未订阅过的用户无需这一步。

### 恢复购买

换机或重装后：进入会员页，点击右上角 **"恢复购买"**，按提示恢复会员状态（以 App Store 的订阅状态为准）。

### 取消订阅

订阅由 App Store 管理，可在系统 **"设置 → Apple ID → 订阅"** 中取消。取消后，当前已付费周期内仍可使用会员权益，到期后不再续费。

## 🔄 会员状态

- 会员权益以 App Store 的购买/订阅状态为准；永久会员长期有效
- 若「恢复购买」后权益未生效，请确认登录的 Apple 账号与购买时一致，并稍后重试

## 🔧 常见问题

### Q1：会员有订阅和永久会员两种，我该选哪个？

两种权益相同，区别只在付费方式：按月/按年订阅适合先试用一段时间、随时可以取消；永久会员付一次长期有效，适合确定长期使用、不想管理续费的人。价格以 App Store 展示为准。

注意：如果此前已在订阅中，购买永久会员不会自动取消那个订阅，也不会退还已付订阅费，请先在 App Store 取消订阅，否则它到期仍会续费；此前从未订阅过的用户不涉及这一步。

### Q2：免费用户有哪些限制？

免费用户可使用记账、云同步、快捷记账等功能，但账单总数为 300 条，且无法使用多账本、多币种、账单导出、账单拆分、定时记账、报销、退款、账单筛选。

### Q3：换手机后会员还在吗？

订阅记录由 App Store 保存，换机或重装后登录购买时的 Apple 账号，点击"恢复购买"即可恢复（永久会员同样适用）。
