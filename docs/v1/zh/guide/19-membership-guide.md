# 会员说明

## 📋 概述

考拉记账提供会员订阅，用于解锁多账本、多币种、账单导出、账单拆分、定时记账等进阶能力；同时免费用户也能使用记账、云同步、快捷记账、报销等核心功能。

## 💎 会员权益

开通会员后可解锁：

- **多账本**：创建与管理多个账本
- **多币种**：记录非本位币账单
- **账单导出**：将账单导出为 CSV
- **账单拆分**：把一笔账单拆成多笔子账单
- **定时记账**：按周期自动生成账单
- **无限记账次数**：不受免费额度限制

其中，**快捷记账、云同步、账单报销、退款**对所有用户开放，无需会员。

## 🚀 开通与恢复

### 开通会员

1. 打开考拉记账 App，进入 **"设置"**
2. 点击页面顶部的用户卡片（未登录需先登录 Apple 账号）
3. 进入会员页，选择 **按年** 或 **按月** 订阅
4. 按 App Store 提示完成支付

> 💡 **提示**：会员价格以 App Store 实际展示与扣费为准；按年订阅通常会显示"折合每月"金额。

### 恢复购买

换机或重装后：进入会员页，点击右上角 **"恢复购买"**，按提示恢复会员状态（以 App Store 的订阅状态为准）。

### 取消订阅

订阅由 App Store 管理，可在系统 **"设置 → Apple ID → 订阅"** 中取消。取消后，当前已付费周期内仍可使用会员权益，到期后不再续费。

## 🔄 会员状态

- 会员有效期以 App Store 订阅状态为准
- 若「恢复购买」后权益未生效，请确认登录的 Apple 账号与购买时一致，并稍后重试

## 🔧 常见问题

### Q1：为什么会员不采用一次性买断？

会员制更利于长期持续维护：持续修复问题、打磨体验、适配系统更新与新机型，并长期投入同步、数据安全、性能等能力建设。

### Q2：免费用户有哪些限制？

免费用户可使用记账、云同步、快捷记账、报销、退款等功能，但账单总数为 1000 条，且无法使用多账本、多币种、账单导出、账单拆分、定时记账。

### Q3：换手机后会员还在吗？

订阅状态由 App Store 保存，换机或重装后登录购买时的 Apple 账号，点击"恢复购买"即可恢复。
