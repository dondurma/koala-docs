# 微信账单导入教程

## 📋 概述

本教程将指导您如何从微信导出账单，并导入到考拉记账 App 中。

---

## 📱 第一步：在微信中导出账单

### 步骤 1：打开微信账单页面

1. 打开微信 App
2. 点击右下角的 **"我"** 标签
3. 点击 **"服务"**（或 **"支付"**）
4. 点击右上角的 **"钱包"** 图标
5. 点击右上角 **"账单"** 进入账单页面

> 📝 **注意**：不同版本的微信，入口可能略有不同。如果找不到，可以尝试在微信搜索框搜索"账单"。

### 步骤 2：导出账单

1. 在账单页面，点击右上角的 **"..."** 或 **"筛选"** 按钮，并在弹出的底部弹框中点击“下载账单”
2. 在“下载账单”页选择“用于个人对账”选项
3. 选择接收方式可以选择“微信”或者“邮箱”（根据个人习惯），并点击确定
4. 选择要导出的时间范围（如：最近一个月、最近三个月等），并点击确定

> 💡 **提示**：
> - 建议一次导出不超过 3 个月的数据，避免文件过大
> - 如果需要导出更长时间的数据，可以分多次导出

### 步骤 3：导出账单前验证

1. 选择完成后，点击“下一步”
2. 会根据微信提示完成认证环节
3. 等待微信处理（可能需要几秒钟）

> ⚠️ **重要**：
> - 导出后，微信会通过邮件或微信发送账单文件
> - 您需要先设置微信的邮箱地址（如果未设置）
> - 或者选择"保存到文件"（如果支持）

### 步骤 4：保存文件到设备

1. 如果选择邮件发送：
   - 打开邮箱，找到微信发送的邮件
   - 下载附件（CSV 或 Excel 文件）
   - 保存到设备本地（可以通过文件管理器访问）

2. 如果选择"保存到文件"：
   - 文件会保存到设备的下载文件夹
   - 记住文件保存的位置

> 📝 **文件位置提示**：
> - iOS：文件通常保存在"文件"App 的"下载"文件夹
> - Android：文件通常保存在"下载"文件夹或"微信"文件夹

---

## 📱 第二步：在考拉记账中导入

### 步骤 1：进入导入页面

1. 打开考拉记账 App
2. 点击底部导航栏的 **"设置"** 图标
3. 在设置页面中找到 **"账单导入"** 选项
4. 点击进入账单导入页面

### 步骤 2：选择导入来源

1. 点击 **"导入来源"** 选项
2. 在弹出的列表中选择 **"微信"**
3. 确认选择

> ⚠️ **重要**：必须选择"微信"，否则系统无法正确解析文件格式。

### 步骤 3：选择文件

1. 点击 **"文件路径"** 选项
2. 在文件选择器中找到并选择微信导出的账单文件
3. 确认文件已选择（会显示文件名）

> 📝 **文件格式**：
> - 支持 CSV 格式（`.csv`）
> - 支持 Excel 格式（`.xlsx`、`.xls`）
> - 文件名通常包含"微信"或"WeChat"字样

### 步骤 4：关联账本

1. 点击 **"关联账本"** 选项
2. 选择要将账单导入到哪个账本
3. 确认账本选择

> 💡 **提示**：如果只有一个账本，系统会自动关联到默认账本。

### 步骤 5：解析文件

1. 点击右上角的 **"解析"** 按钮
2. 等待系统解析文件（可能需要几秒钟）
3. 解析成功后，会自动跳转到预览页面

> ⚠️ **如果解析失败**：
> - 检查文件格式是否正确
> - 检查是否选择了"微信"作为导入来源
> - 检查文件是否损坏
> - 尝试重新从微信导出文件

### 步骤 6：预览和编辑

解析成功后，您可以在预览页面中：

- **查看所有账单记录**：按日期分组显示
- **编辑单条记录**：点击记录可以修改：
  - 分类（支出/收入分类）
  - 金额
  - 时间
  - 账户
  - 标签
  - 备注
- **删除无效记录**：长按记录可以删除
- **批量操作**：可以选择跳过无效记录

> 📝 **建议**：
> - 在导入前，先预览数据，确保数据正确
> - 检查分类是否正确匹配
> - 检查金额是否正确
> - 如有需要，可以手动调整分类和账户

### 步骤 7：导入数据

1. 在预览页面确认数据无误后
2. 点击 **"导入"** 按钮
3. 等待导入完成（可能需要几秒钟）
4. 导入成功后，会显示导入结果

> ✅ **导入成功**：所有有效记录已导入到账本中，您可以在账单列表中查看。

## 📋 微信账单文件格式说明

### CSV 格式（标准格式）

微信导出的 CSV 文件通常包含以下列：

| 列名 | 说明 | 示例 |
|------|------|------|
| 交易时间 | 交易发生时间 | 2024-01-01 12:00:00 |
| 交易类型 | 交易类型 | 微信红包 / 转账 / 消费等 |
| 交易对方 | 交易对方信息 | 张三 / 商户名称 |
| 商品 | 商品描述 | 午餐 / 购物等 |
| 收/支 | 收入或支出 | 收入 / 支出 |
| 金额(元) | 交易金额 | 100.00 |
| 支付方式 | 支付方式     | 零钱 / 银行卡            |
| 当前状态 | 支付是否成功 | 支付成功/已转账/已到账   |
| 交易单号 | 交易单号     | 4200001234567890         |
| 商户单号 | 商户单号     | 1234567890               |
| 备注     | 备注信息     | 备注内容                 |

### Excel 格式

Excel 格式的列名和内容与 CSV 格式相同，只是文件格式不同。

## ⚠️ 注意事项

### 1. 文件格式要求

- **文件编码**：建议使用 UTF-8 编码（微信导出通常为 UTF-8）
- **文件格式**：支持 CSV 和 Excel 格式
- **文件大小**：建议单个文件不超过 10MB

### 2. 数据映射

系统会自动将微信账单字段映射到考拉记账字段：

- 交易时间（row[0]）→ **账单日期**（转日期字符串）
- 交易类型（row[4]，含“支出/收入”）→ **账单类型**（支出/收入）
- 交易分类（row[1] 主类、row[3] 子类）→ 一级分类/二级分类 
- 金额（row[5]）→ **账单金额**
- 收/付款方式（row[6]）→ **账户**（按名称查找/创建）
- 交易对方（row[2]）、当前状态（row[7]）、交易单号（row[8]）、商户单号（row[9]）、备注（row[10]）→ **账单备注**（拼接）

### 3. 分类匹配

- 系统会尝试自动匹配分类，但可能不完全准确
- 建议在预览页面检查分类是否正确
- 如有需要，可以手动调整分类

### 4. 账户匹配

- 系统会尝试根据"支付方式"匹配账户
- 如果账户不存在，系统会自动创建
- 建议在导入前先创建好常用账户

### 5. 重复数据处理

- 建议在导入前先检查是否有重复数据

### 6. 不要手动修改账单

- 不要手动修改微信账单，包括但不限于修改、删除表头名称或者或新增列，这会导致解析账单失败

## 🔧 常见问题

### Q1：找不到"导出账单"选项？

**A：** 可能的原因：
1. 微信版本较旧，不支持导出功能
2. 入口位置不同，可以尝试：
   - 在账单页面点击右上角的"..."按钮
   - 在"钱包"页面查找"账单"选项
   - 在微信搜索框搜索"账单导出"

### Q2：导出后收不到邮件？

**A：** 请检查：
1. 微信是否绑定了邮箱地址
2. 邮箱地址是否正确
3. 邮件是否被放入垃圾箱
4. 可以尝试选择"保存到文件"方式

### Q3：解析失败怎么办？

**A：** 请检查：
1. 文件格式是否正确（CSV 或 Excel）
2. 是否选择了"微信"作为导入来源
3. 文件是否损坏
4. 文件编码是否正确（建议使用 UTF-8）

### Q4：导入后分类不正确？

**A：** 这是正常现象，因为：
1. 微信的分类和考拉记账的分类可能不完全匹配
2. 系统会尝试自动匹配，但可能不完全准确
3. 建议在预览页面手动调整分类，或导入后批量修改

### Q5：可以导入图片吗？

**A：** 目前不支持。微信账单不包含图片信息，导入后也无法添加图片。

### Q6：支持导入多长时间的数据？

**A：** 理论上没有限制，但建议：
1. 单次导入不超过 3 个月的数据
2. 如果数据量很大，可以分多次导入
3. 导入过程中请保持 App 在前台运行

---

## 💡 使用技巧

1. **定期导入**：建议每月导入一次，保持数据同步
2. **分类整理**：导入后，建议检查并整理分类，方便后续统计
3. **账户管理**：导入前先创建好常用账户，避免自动创建不规范的账户名
4. **数据备份**：导入前建议先备份现有数据，以防万一
