# 支付宝账单导入教程

## 📋 概述

本教程将指导您如何从支付宝导出账单，并导入到考拉记账 App 中。

---

## 📱 第一步：在支付宝中导出账单

### 步骤 1：打开支付宝账单页面

1. 打开支付宝 App
2. 点击底部导航栏的 **"我的"** 标签
3. 点击 **"账单"** 进入账单页面

> 📝 **注意**：不同版本的支付宝，入口可能略有不同。如果找不到，可以尝试在支付宝搜索框搜索"账单"。

### 步骤 2：导出账单

1. 在账单页面，点击右上角的 **"..."** 按钮
2. 选择 **"开具交流流水证明"** 或 **"账单导出"**
3. 选择**“用户个人对帐”**，并点击**“申请”

### 步骤 3：选择交易流水范围

1. 选择交易类型，“全部交易”/“收入”/“支出”
2. 选择要导出的时间范围（如：最近一个月、最近三个月等）
3. 选择接收方式，“支付宝”/“邮箱”

> 💡 **提示**：
>
> - 建议一次导出不超过 3 个月的数据，避免文件过大
> - 如果需要导出更长时间的数据，可以分多次导出
> - 导出后，如果选择接收方式为“邮箱”，支付宝会通过邮件发送账单文件
> - 您需要先设置支付宝的邮箱地址（如果未设置）
> - 或者选择"保存到文件"（如果支持）

### 步骤 4：保存文件到设备

1. 如果选择邮件发送：
   - 打开邮箱，找到支付宝发送的邮件
   - 下载附件（CSV 文件）
   - 保存到设备本地（可以通过文件管理器访问）

2. 如果选择"保存到文件"：
   - 文件会保存到设备的下载文件夹
   - 记住文件保存的位置

> 📝 **文件位置提示**：
> - iOS：文件通常保存在"文件"App 的"下载"文件夹
> - Android：文件通常保存在"下载"文件夹或"支付宝"文件夹

---

## 📱 第二步：在考拉记账中导入

### 步骤 1：进入导入页面

1. 打开考拉记账 App
2. 点击底部导航栏的 **"设置"** 图标
3. 在设置页面中找到 **"账单导入"** 选项
4. 点击进入账单导入页面

### 步骤 2：选择导入来源

1. 点击 **"导入来源"** 选项
2. 在弹出的列表中选择 **"支付宝"**
3. 确认选择

> ⚠️ **重要**：必须选择"支付宝"，否则系统无法正确解析文件格式。

### 步骤 3：选择文件

1. 点击 **"文件路径"** 选项
2. 在文件选择器中找到并选择支付宝导出的账单文件
3. 确认文件已选择（会显示文件名）

> 📝 **文件格式**：
> - 支持 CSV 格式（`.csv`）
> - 文件名通常包含"支付宝"或"Alipay"字样

### 步骤 4：关联账本

1. 点击 **"关联账本"** 选项
2. 选择要将账单导入到哪个账本
3. 确认账本选择

> 💡 **提示**：如果只有一个账本，系统会自动关联默认账本。

### 步骤 5：解析文件

1. 点击右上角的 **"解析"** 按钮
2. 等待系统解析文件（可能需要几秒钟）
3. 解析成功后，会自动跳转到预览页面

> ⚠️ **如果解析失败**：
> - 检查文件格式是否正确
> - 检查是否选择了"支付宝"作为导入来源
> - 检查文件是否损坏
> - 尝试重新从支付宝导出文件

### 步骤 6：预览和编辑

解析成功后，您可以在预览页面中：

- **查看所有账单记录**：按日期分组显示
- **编辑单条记录**：点击记录可以修改：
  - 分类（支出/收入分类）
  - 金额
  - 时间
  - 账户
  - 标签
  - 备注
- **删除无效记录**：长按记录可以删除
- **批量操作**：可以选择跳过无效记录

> 📝 **建议**：
> - 在导入前，先预览数据，确保数据正确
> - 检查分类是否正确匹配
> - 检查金额是否正确
> - 如有需要，可以手动调整分类和账户

### 步骤 7：导入数据

1. 在预览页面确认数据无误后
2. 点击 **"导入"** 按钮
3. 等待导入完成（可能需要几秒钟）
4. 导入成功后，会显示导入结果

> ✅ **导入成功**：所有有效记录已导入到账本中，您可以在账单列表中查看。

## 📋 支付宝账单文件格式说明

### CSV 格式（标准格式）

支付宝导出的 CSV 文件通常包含以下列：

| 列名 | 说明 | 示例 |
|------|------|------|
| 交易时间    | 交易创建时间     | 2024-01-01 12:00:00          |
| 交易分类    | 账单的收支名称   | 餐饮美食/日用百货            |
| 交易对方    | 交易对方信息     | 张三 / 商户名称              |
| 对方账号    | 对方的支付宝账号 | xxx@163.com                  |
| 商品说明    | 商品描述         | 午餐 / 购物等                |
| 收/支       | 收入或支出       | 收入 / 支出                  |
| 金额        | 交易金额         | 100.00                       |
| 收/付款方式 | 何种方式的账户   | 余额宝                       |
| 交易状态    | 交易状态         | 交易成功 / 已退款            |
| 交易订单号  | 交易单号         | 2024010112345678901234567890 |
| 商家订单号  | 商家订单号       | 1234567890                   |
| 备注        | 备注信息         | 备注内容                     |

> 📝 **注意**：不同版本的支付宝，列名可能略有不同，但主要内容相同。

## ⚠️ 注意事项

### 1. 文件格式要求

- **文件编码**：建议使用 UTF-8 编码（支付宝导出通常为 UTF-8 或 GBK）
- **文件格式**：仅支持 CSV 格式（`.csv`）
- **文件大小**：建议单个文件不超过 10MB

### 2. 数据映射

系统会自动将支付宝账单字段映射到考拉记账字段：

- 交易时间（CSV 第1列 / row[0]）→ 本地账单时间 （仅取日期， yyyy-MM-dd ）
- 交易分类（第2列 / row[1]）→ 本地账单父子分类 （父子同名）
- 交易对方（第3列 / row[2]）→ 本地账单备注 （追加一行“交易对方:xxx”，表头名随源文件）
- 对方账号（第4列 / row[3]）→ 本地账单备注  （追加一行“对方账号:xxx”，表头名随源文件）
- 商品说明（第5列 / row[4]）→ 本地账单备注 （追加一行“商品说明:xxx”，表头名随源文件）
- 收/支（第6列 / row[5]）→ 本地账单类型（收入/支出）
- 金额（第7列 / row[6]）→ 本地账单金额
- 收/付款方式（第8列 / row[7]）→ 本地账户名称 （按名称查找账户，不存在则创建后写入）
- 交易状态（第9列 / row[8]）→ 本地账单备注（追加一行“交易状态:xxx”，表头名随源文件）
- 交易订单号（第10列 / row[9]）→ 本地账单备注（追加一行“交易订单号:xxx”，表头名随源文件）
- 商家订单号（第11列 / row[10]）→ 本地账单备注 （追加一行“商家订单号:xxx”，表头名随源文件）
- 备注（第12列 / row[11]）→ 本地账单备注（作为原始备注；若为 / 或空则忽略，再叠加上述追加项）

### 3. 分类匹配

- 系统会尝试自动匹配分类，但可能不完全准确
- 建议在预览页面检查分类是否正确
- 如有需要，可以手动调整分类

### 4. 账户匹配

- 系统会尝试根据"交易来源地"或其他信息匹配账户
- 如果账户不存在，系统会自动创建
- 建议在导入前先创建好常用账户

### 5. 重复数据处理

- 如果导入的记录与现有记录重复（基于交易号），系统会自动跳过
- 建议在导入前先检查是否有重复数据

### 6. 退款处理

- 如果账单包含退款记录，系统会尝试识别并处理
- 退款记录通常标记为"已退款"或"退款成功"
- 建议在预览页面检查退款记录是否正确

## 🔧 常见问题

### Q1：找不到"导出账单"选项？

**A：** 可能的原因：
1. 支付宝版本较旧，不支持导出功能
2. 入口位置不同，可以尝试：
   - 在账单页面点击右上角的"..."按钮
   - 在"我的"页面查找"账单"选项
   - 在支付宝搜索框搜索"账单导出"

### Q2：导出后收不到邮件？

**A：** 请检查：
1. 支付宝是否绑定了邮箱地址
2. 邮箱地址是否正确
3. 邮件是否被放入垃圾箱
4. 可以尝试选择"保存到文件"方式

### Q3：解析失败怎么办？

**A：** 请检查：
1. 文件格式是否正确（CSV）
2. 是否选择了"支付宝"作为导入来源
3. 文件是否损坏
4. 文件编码是否正确（建议使用 UTF-8 或 GBK）

### Q4：导入后分类不正确？

**A：** 这是正常现象，因为：
1. 支付宝的分类和考拉记账的分类可能不完全匹配
2. 系统会尝试自动匹配，但可能不完全准确
3. 建议在预览页面手动调整分类，或导入后批量修改

### Q5：可以导入图片吗？

**A：** 目前不支持。支付宝账单不包含图片信息，导入后也无法添加图片。

### Q6：支持导入多长时间的数据？

**A：** 理论上没有限制，但建议：
1. 单次导入不超过 3 个月的数据
2. 如果数据量很大，可以分多次导入
3. 导入过程中请保持 App 在前台运行

### Q7：为什么只支持 CSV 格式？

**A：** 支付宝目前只支持导出 CSV 格式的账单文件。如果将来支持 Excel 格式，我们会及时更新。

## ⚠️ 注意事项

### 1. 文件格式要求

- **文件编码**：建议使用 UTF-8 编码（微信导出通常为 UTF-8）
- **文件格式**：仅支持 CSV格式
- **文件大小**：建议单个文件不超过 10MB

### 3. 分类匹配

- 系统会尝试自动匹配分类，但可能不完全准确
- 建议在预览页面检查分类是否正确
- 如有需要，可以手动调整分类

### 4. 账户匹配

- 系统会尝试根据"支付方式"匹配账户
- 如果账户不存在，系统会自动创建
- 建议在导入前先创建好常用账户

### 5. 重复数据处理

- 建议在导入前先检查是否有重复数据

### 6. 不要手动修改账单

- 不要手动修改支付宝账单，包括但不限于修改、删除表头名称或者或新增列，这会导致解析账单失败

## 💡 使用技巧

1. **定期导入**：建议每月导入一次，保持数据同步
2. **分类整理**：导入后，建议检查并整理分类，方便后续统计
3. **账户管理**：导入前先创建好常用账户，避免自动创建不规范的账户名
4. **数据备份**：导入前建议先备份现有数据，以防万一
5. **退款处理**：导入后，建议检查退款记录是否正确处理
