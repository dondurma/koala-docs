# 貔貅账单导入指南

## 📋 概述

本指南将指导您如何从 **貔貅记账** 导出账单，并导入到 **考拉记账** App 中。

考拉记账当前支持导入 **貔貅记账导出的 CSV 账单文件**（仅 CSV）。

---

## 📱 第一步：在貔貅记账中导出账单

不同版本的貔貅记账，入口可能略有差异，但思路一致：进入“数据导出/导出账单”，选择时间范围与导出格式后保存文件。

### 步骤 1：进入导出入口

1. 打开 **貔貅记账** App
2. 进入 **我的**
3. 找到 **数据导出 / 导出账单**（名称可能略有不同）

### 步骤 2：选择导出时间范围

1. 选择要导出的时间范围（如：最近一个月、最近三个月）
2. 确认范围后开始导出

> 💡 **提示**：
> - 建议一次导出不超过 3 个月，避免文件过大导致解析变慢
> - 数据量很大时，可以分多次导出后分批导入

### 步骤 3：选择导出格式并保存文件

1. 选择导出格式：**CSV**
2. 将导出的 CSV 文件保存到设备本地（或通过“分享/保存到文件”）
3. 记住文件保存位置，便于后续导入

---

## 📱 第二步：在考拉记账中导入

### 步骤 1：进入导入页面

1. 打开考拉记账 App
2. 点击底部导航栏的 **“设置”**
3. 在设置页面中找到 **“账单导入”**
4. 点击进入账单导入页面

### 步骤 2：选择导入来源

1. 点击 **“导入来源”**
2. 在列表中选择 **“貔貅记账”**

> ⚠️ **重要**：必须选择“貔貅记账”，否则可能导致文件格式校验失败或字段解析错误。

### 步骤 3：选择文件

1. 点击 **“文件路径”**
2. 选择从貔貅记账导出的 **CSV** 文件
3. 确认文件名已显示

### 步骤 4：关联账本

1. 点击 **“关联账本”**
2. 选择要导入的目标账本
3. 确认账本选择

### 步骤 5：解析并预览

1. 点击右上角 **“解析”**
2. 解析成功后进入预览页
3. 预览页可对单条记录进行编辑/删除，也可以批量跳过无效记录

### 步骤 6：导入

1. 预览确认无误后点击 **“导入”**
2. 等待导入完成

## 📋 貔貅账单文件格式说明（CSV）

考拉记账对貔貅账单 CSV 的校验点：

- 第一行必须是表头
- **表头列数必须为 10 列**
- 内容使用英文逗号 `,` 作为分隔符（CSV 标准）

### 列定义（按顺序）

| 列序号 | 列含义 | 说明 |
|------|------|------|
| 1 | 日期 | 支持 `yyyy-MM-dd` / `yyyy/MM/dd`，且年份需 ≥ 2016；否则视为无效日期 |
| 2 | 父分类 | 用于匹配考拉记账的收支项目父类名称 |
| 3 | 交易分类 | 文本需包含“支出”或“收入”关键字；包含“收入”则按收入导入，否则按支出导入 |
| 4 | 子分类 | 用于匹配考拉记账的收支项目子类名称 |
| 5 | 流入金额 | 收入金额列（允许带 `-`，导入会自动去除符号） |
| 6 | 流出金额 | 支出金额列（允许带 `-`，导入会自动去除符号） |
| 7 | 币种代码 | 例如 `CNY` / `USD`；为空时使用目标账本的默认币种 |
| 8 | 账户 | 账户名称（用于匹配考拉记账账户；不存在时导入阶段会尝试创建） |
| 9 | 标签 | 多个标签用逗号分隔（同时支持中文逗号 `，`） |
| 10 | 备注 | 备注文本 |

### 导入映射（考拉记账）

- 日期 → 账单日期
- 交易分类（含支出/收入关键字）→ 账单类型
- 父分类 + 子分类 → 收支项目（匹配不到会被标记为不完善数据）
- 流入/流出金额 → 金额（由账单类型决定取哪一列）
- 账户 → 账户（按名称匹配；不存在会在导入时创建）
- 标签 → 标签（按名称匹配/创建并绑定到记录）
- 备注 → 备注
- 币种代码 → 账单货币（按 code 匹配；匹配失败使用账本默认币种）
- c
- 日期（row[0]）→ 账单日期
- 父类（row[1]）→ 一级分类 （并匹配/创建 parentCategoryId 等）
- 交易分类（row[2]，含“收入/支出”）→ 账单类型（收入/支出）
- 子类（row[3]）→ 二级分类 （并匹配/创建 childCategoryId 等）
- 流入金额（row[4]）/流出金额（row[5]）→ 账单金额 （按 type 取其一）
- 货币代码（row[6]）→ 货币单位 （按 code 查）
- 账户（row[7]）→ 账户名称（按名称查找/创建）
- 标签（row[8]）→ 标签（解析/创建标签后入库）
- 备注（row[9]）→ 备注

## ⚠️ 注意事项

1. **不自动去重**：重复导入同一份文件会生成重复账单记录，请避免多次导入同一时间段。
2. **收支项目匹配**：按“父分类 + 子分类”名称匹配；若匹配失败，预览页会提示不完善，需要手动选择正确的收支项目后再导入。
3. **账户有效性**：账户名称为空或仅包含符号时，会被视为无效数据并提示补全。
4. **文件编码**：CSV 支持 UTF-8/GBK；若出现乱码，建议用 UTF-8 重新导出或转换编码后再导入。

## 🔧 常见问题

### Q1：提示“表头长度不对”？

**A：** 请确认导出的 CSV 第一行表头为 **10 列**。常见原因：

1. 使用了非貔貅记账导出的 CSV，列数不一致
2. 用 Excel/WPS 二次编辑后出现多余分隔符导致列数变化
3. 另存为 CSV 时选择了不兼容格式（例如带分号分隔）

### Q2：导入后金额不对或为 0？

**A：** 请确认：

1. “交易分类”列包含“支出/收入”关键字（决定取“流入金额”还是“流出金额”）
2. 对应金额列有值且为数字格式（带 `-` 也可以，会自动去掉）

### Q3：分类匹配不上怎么办？

**A：** 在导入预览页点进单条记录手动选择收支项目；或者先在考拉记账里创建好与貔貅导出文件同名的收支项目后再重新解析。
