# 轻敲手机背面教程

## 1. 打开手机「设置」，选择「辅助功能」

![1-辅助功能|400](./images/1-辅助功能.png)


## 2. 在「辅助功能」页面中找到「触控」并点击

![2-触控|400](./images/2-触控.png)


## 3. 在「触控」页面找到「轻点背面」并点击进入，选择「轻点两下」或者「轻点三下」

![3-轻点背面|400](./images/3-轻点背面.png)

## 4. 在「轻点两下」或「轻点三下」页面找到页面底部的快捷指令下的「考拉快捷记账」并选中

![4-选择快捷指令|400](./images/4-选择快捷指令.png)
