# 账单报销说明

## 1. 这是什么功能

“报销”用于记录一笔支出后，后续由他人/公司把钱补回来的场景（例如差旅、办公用品、垫付费用等）。

在考拉记账中，报销的核心逻辑是：

- 您先记一笔“支出”，并标记为“可报销”
- 当这笔支出完成报销时，系统会自动生成一笔“报销入账”的收入账单，把金额加回到您指定的账户

这样做的好处是：

- 原支出仍然保留（方便追溯消费用途）
- 报销回款也有记录（方便核对到账账户与时间）
- 统计口径清晰：支出与报销入账分别记录

## 2. 适用场景

- 公司报销（交通、住宿、餐饮、办公用品等）
- 朋友/家人代付后转账给你（也可按报销方式记录）
- 垫付款项需要后续收回

## 3. 如何使用

### 3.1 创建“可报销”的支出

1. 新增一笔支出账单
2. 在创建/编辑页面中勾选“报销”（或类似的“可报销/待报销”选项）
3. 保存后，该账单在列表中会显示“待报销/已报销”等状态提示

### 3.2 对支出执行“报销”

1. 在账单列表找到“待报销”的支出
2. 对该账单进行左滑操作，选择“报销”
3. 在报销页面中设置：
   - 金额：默认等于原支出金额，可改为实际报销金额
   - 时间：默认今天，可改为实际到账日期
   - 入账账户：选择报销款实际打入的账户
   - 备注：可选
4. 点击“完成/保存”

保存后，会新增一笔“报销入账”的收入账单，用于记录回款。

## 4. 使用规则与注意事项

- 只有“支出”且已标记为“可报销”的账单才能进行报销。
- 拆分与报销互斥：已拆分的账单（包含拆分后的子账单/拆分容器）无法开启报销流程；已标记为可报销的支出也无法再进行拆分。建议先确定是否需要报销，必要时可先拆分清楚费用构成，再对需要报销的部分单独记录为可报销支出。
- 已经生成过“报销入账”的支出，默认不支持重复报销（避免重复入账）。
- 如果您删除了“报销入账”那笔收入记录，原支出会回到“待报销”状态（可再次执行报销）。
- 报销入账会计入收入统计；原支出仍会计入支出统计，这是为了让收支流向更清晰。

## 5. 常见问题

### Q1：报销和退款有什么区别？

- 退款：针对一笔账单发生退回，通常用于抵消原账单影响（新增一笔负数记录）
- 报销：针对一笔“可报销的支出”，后续收到补回款（新增一笔报销入账的收入记录）

### Q2：报销款打到别的账户怎么办？

在报销页面里把“入账账户”改为实际到账账户即可。

### Q3：我只报销了部分金额怎么记？

把报销金额改为实际报销金额即可。未报销的差额仍然会保留在原支出上，方便您后续核对。
