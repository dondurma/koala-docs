# 心情打卡说明

## 📋 概述

考拉记账在概览页提供「心情卡片」，让你在记账之余顺手记录每天的心情，并以月视图回顾。适合想同时关注消费与情绪状态、或希望坚持每日打卡的用户。

## 🚀 如何记录心情

1. 打开考拉记账 App，进入底部导航栏的 **"概览"** 页面
2. 找到 **"心情卡片"**（当月且今天尚未记录时，卡片底部会出现三个选项）
3. 点击 **开心 / 一般 / 难过** 中的任意一个，即可记录今天的心情

> 📝 **注意**：
> - 每天只能记录一次（以自然日为准）
> - 已记录当天心情后，当天不再显示选择项，且**不支持在 App 内修改或删除**
> - 只能记录「当天」的心情，不支持补记或修改历史日期

## 📅 查看月视图

心情卡片会展示当月的记录情况：

- 顶部显示当月**已记录天数 / 总天数**以及今天的心情
- 下方以网格展示当月每一天：已记录的日子按心情着色（开心 / 一般 / 难过各一种颜色），未记录的日子为浅色
- 未来的日期不参与展示

> 💡 **提示**：当概览页切换到其他月份时，卡片会显示该月的记录情况（不显示「今日」信息）。

## 🎨 个性化设置

进入 **"设置" → "个性化"**，可以调整心情相关选项：

- **显示心情卡片**：开关控制概览页是否显示心情卡片（默认显示）
- **心情颜色**：自定义「开心 / 一般 / 难过」三种心情对应的颜色

> 📝 **注意**：心情颜色在「统计页分享 → 心情记录」生成的热力图中同样生效。

## 📤 分享心情记录

1. 打开底部导航栏的 **"统计"** 页面
2. 在页面底部点击 **"分享当前页 >"**
3. 在弹出的菜单中选择 **"心情记录"**
4. 生成心情热力图后，通过系统分享面板发送或保存

> ⚠️ **注意**：
> - 「心情记录」分享仅在时间维度为「按月」或「按年」时可用（自定义时间范围下不显示该选项）
> - 心情记录与账单数据互相独立，不影响账单统计

## 🔄 多设备同步

- **登录账号后**：心情记录会随账号同步，多设备登录同一账号即可看到相同的心情记录
- **未登录时**：心情记录只保存在本机，卸载或换设备后无法恢复

> 📝 心情记录按账号归属同步，与账本数据相互独立。

## 🔧 常见问题

### Q1：记录错了心情能改吗？

目前每天仅记录一次，记录后不支持在 App 内修改或删除。请在记录前确认。

### Q2：能补记前几天的心情吗？

目前只支持记录「当天」的心情，不支持补记或修改历史日期。

### Q3：为什么概览页看不到心情卡片？

请检查 **"设置" → "个性化" → "显示心情卡片"** 是否已开启。

### Q4：换设备后心情记录还在吗？

已登录并完成同步的情况下，重新安装后登录同一账号会随账号同步恢复；未登录时数据只在本机。
