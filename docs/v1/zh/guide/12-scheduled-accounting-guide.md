# 定时记账说明

## 1. 这是什么功能

“定时记账”用于把一些固定、重复发生的收支（例如房租、水电、会员订阅、工资等）设置成规则，让系统按规则自动生成账单，减少重复手动录入。

## 2. 适用场景

- 每月房租、房贷、信用卡还款
- 每周通勤交通费、固定餐补
- 每月订阅服务（视频会员、网盘等）
- 每月固定收入（工资、补贴等）

## 3. 如何使用

1. 进入“设置”页面，找到“定时记账”
2. 新建一条定时规则，填写：
   - 收支类型：支出 / 收入
   - 分类（收支项）
   - 金额
   - 账户
   - 标签、备注（可选）
   - 执行周期：每天 / 每周 / 每月（按规则选择具体日期或星期）
   - 起止时间：开始时间必填，结束时间可选（用于到期自动停止）
3. 保存后，规则会出现在定时记账列表中
4. 到达触发时间后，系统会按规则生成账单

## 4. 使用规则与注意事项

- 定时记账生成的账单与普通手动账单一致：会参与列表展示与统计汇总。
- 如果您长期不打开 App，部分设备可能无法做到“严格准点”生成；下次打开 App 时，系统会补齐到期但尚未生成的账单（避免漏记）。
- 建议定期检查规则列表，确认金额、分类、账户仍符合当前实际情况（例如房租涨价、换卡等）。
- 暂停/终止规则后将不再继续生成账单；恢复启用后会从下一次周期继续执行。

## 5. 常见问题

### Q1：定时记账生成错了怎么办？

定时记账生成的账单可以像普通账单一样编辑或删除。若经常出错，建议直接调整对应的定时规则（金额/周期/账户等）。

### Q2：规则改了，之前生成的账单会自动跟着变吗？

不会。规则修改只影响后续生成的账单；历史账单保持不变，便于追溯。

### Q3：同一天会生成多笔吗？

如果您设置了多条规则，系统会分别生成对应的账单。对于同一条规则，系统会尽量避免重复生成。
