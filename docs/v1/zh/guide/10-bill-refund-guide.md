# 账单退款说明

## 1. 这是什么功能

“退款”用于记录一笔账单发生退款后的资金变化，并自动抵消统计口径的金额影响。

系统的做法是：在原账单基础上，新增一笔“金额为负数”的退款记录。

- 原账单是支出：退款记录也是“支出”，但金额为负数，用于抵消原支出
- 原账单是收入：退款记录也是“收入”，但金额为负数，用于抵消原收入

同时，退款记录会自动带上“退款”标签，方便后续筛选与核对。

## 2. 适用场景

- 购物退款、退货退款
- 账单部分退款（只退一部分金额）
- 收入回退（例如打款撤回、收款退回）

## 3. 如何使用

1. 进入“账单列表”找到要退款的账单
2. 对该账单进行左滑操作，选择“退款”
3. 在退款页面中设置：
   - 金额：默认等于原账单金额，可改为部分退款金额
   - 时间：默认今天，可改为实际退款发生的日期
   - 标签：默认继承原账单的标签，并自动追加“退款”标签
   - 备注：可选，用于补充说明
4. 点击“确定/完成”保存

保存后，列表会新增一笔退款记录，用于抵消对应的金额影响。

## 4. 使用规则与注意事项

- 退款金额建议填写“实际退回的金额”，不需要手动加负号。
- 支出退款与收入退款都会按“负数金额”的方式记录，因此在统计中会自动抵消。
- 支持多次退款：同一笔账单如果分多次退款，可以重复操作多次，每次生成一笔退款记录。
- 如果您删除了退款记录，对应的抵消效果也会消失（统计会回到未退款状态）。

## 5. 常见问题

### Q1：部分退款怎么记？

在退款页面把金额改为实际退款金额即可。您也可以多次退款，每次填各自的退款金额。

### Q2：退款会影响原账单吗？

原账单本身不会被修改金额；退款是以“新增一笔退款记录”的方式实现的。这样可以保留原始消费记录，同时让统计结果可解释、可追溯。

### Q3：怎么快速找到所有退款？

退款记录会自动带“退款”标签，您可以在筛选/搜索中按标签筛选查看。
