# 更新纪录

> 本页面用于记录考拉记账每次上架版本的更新内容。并按时间倒序维护（最新版本放在最前面）。

## 2026-10-05 v1.1.0（32）
### 新增功能

1. 新增「牛皮纸」主题：复古纸张质感，整个 App 更有味道。
2. 新增复古字体、倒角大小设置，风格随手可调。
3. 新增多款个人卡片背景，个人主页随心装扮。
4. 新增账单小票：一键把账单做成精美小票，分享更方便。
5. 完善使用指南，并在多个页面标题栏加上「?」帮助入口。
6. 收支项按使用频率自动排序，常用的排在前面。
7. 云同步状态更直观：有数据未同步时会给出提示。
8. 更新了 App 图标。

### 修复问题

1. 大幅提升账单导入的解析速度，大文件导入不再久等。
2. 修复部分界面显示与文案细节。

## 2026-09-26 v1.0.7（31）
### 修复问题

1. 报销入账的账单不会再莫名消失，换机、重装后也还在。
2. 换账号登录后，新账号的同步不会再沿用上一个账号的失败记录。
3. 修复同步偶尔长时间卡住不动、或整批账单一直拉不下来的问题。
4. 修复个别分类、标签、转账改动一直同步不上去、或两台设备上显示不一致的问题。
