# 更新纪录

> 本页面用于记录考拉记账每次上架版本的更新内容。并按时间倒序维护（最新版本放在最前面）。

## 2026-10-28 v1.1.3（36）
### 新增功能

1. 新增「永久会员」：解锁会员时可以选按月、按年或一次买断，会员中心也能直接升级，买断后长期有效。
2. 会员页新增「兑换优惠码」，有兑换码就能直接开通会员。
3. 账户的转账记录可以按月查看，切换上一月、下一月，一键回到本月。
4. 牛皮纸主题下所有开关换成复古方括号样式，和纸质风格更统一。

### 修复问题

1. 拆分账单时连点「完成」不会重复拆分；只填一项时不能保存，避免误改原账单。
2. 某个账户数据异常时，其他账户和转账仍会正常同步，不会整轮卡住；同步状态里也能看到被跳过的数量。
3. 修复部分记录同步成功却一直显示待同步、反复重试的问题。
4. 删除账单、转账或账户后，余额和相关数据在另一台设备上不会再残留或重复扣减。
5. 「记一笔」的默认日期会跟随正在查看的日期，在历史月份记完也能马上看到。
6. 购买会员后若状态确认失败，页面不再卡住，会提示「会员状态同步中」并返回；未登录时点会员入口也不会再进入购买流程。
7. 深色模式下弹框底色和按钮圆角做了统一，看起来不再突兀。
8. 设置页、记账页里部分开关所在的行不再比相邻行高，整行点一下也能切换。
9. 账户账单和转账记录加载失败时会给出提示，点一下就能重试。
10. 搜索账单时快速连续输入，搜索结果不会再被上一次的结果覆盖。

## 2026-10-14 v1.1.2（34）
### 新增功能

1. 支持自定义账户图标：新建或编辑账户时，可以挑一个图标，也能输入自定义表情。
2. 新增「按键震动」开关：点数字键盘会轻微震动，可在设置里随时关闭；按键轻点也会显示按下效果。
3. 个人卡片背景焕新：新增「疏枝 / 繁叶 / 素笺 / 哑光陶土 / 牛皮纸 / 浅色原木」等款式，也可以选「无」。

### 修复问题

1. 编辑账单时，可以直接取消「可报销」标记了。
2. 已生成报销入账的账单，取消「可报销」标记时会提示无法取消，避免账目对不上。

## 2026-10-12 v1.1.1（33）

### 修复问题

2. 修复线性记账切换大类后，右侧子分类偶尔还停留在上一个分类的问题。
3. 修复货币与汇率页切换语言后分组显示错乱的问题。

6. 修正部分界面文案。
7. 修复注销账号后重新进入，底部导航栏按钮点了没反应的问题。
