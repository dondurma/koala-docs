# 注销账户说明

注销账户会清空该账号在云端与本机的所有数据，请在操作前确认你已理解并接受以下影响。

## 会发生什么

- 云端数据：清空该账号的云同步数据（包括但不限于账本、账单、分类、标签等）。
- 本机数据：清空该账号在当前设备上的本地数据（包括离线数据）。
- 不可撤销：注销执行后无法恢复已删除的数据。

## 会员订阅是否受影响

注销账户不会影响你的订阅有效期。

如果你是付费会员，注销后重新登录，并在应用内点击「恢复购买」，仍可恢复会员状态（以应用商店的订阅状态为准）。

## 建议

- 如你需要保留数据，请先在应用内完成导出/备份（如有）。
- 注销后再重新登录将视为新环境，你需要重新同步/导入数据。
