# 账单导入注意事项

导入账单前，请先了解以下几点，避免中途中断或数据不完整。

## 一次不要导入太多

- 单次导入建议**不超过 1000 条**；超过请**分批导入**（例如每次 500~1000 条）。
- 免费用户全账本账单总数上限为 **300 条**，会员不限。数据量较大时，导入前请确认剩余可记账条数。

## 数据量较大时请耐心等待

- 解析与导入都需要时间。条数越多，等待越久；接近或超过 1000 条时可能需要较长时间（几十秒甚至更久）。
- 期间请不要认为「卡住了」，耐心等待进度完成即可。

## 导入过程中不要退出页面

- 导入进行中，请**停留在当前页面**：不要返回、不要切换到其它 App、不要锁屏或强制关闭 App。
- 中途退出可能导致**本次导入中断**，出现只导入了一部分、或需要重新导入的情况。

## 导入完成后

- 导入完成后，建议手动同步一次，确保数据已上传。
- 请在账单列表中抽查几条，确认金额、分类、日期无误。
